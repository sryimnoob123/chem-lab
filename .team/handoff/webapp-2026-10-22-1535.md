## 4. 环境坑（会再踩，记死）

| 坑 | 现象 | 解法 |
|---|---|---|
| **PGlite 被强杀就坏** | `Aborted()` wasm 崩，`/api/*` 500 | `mv .pgdata .pgdata-broken-$(date +%H%M%S)` → `PGLITE_DIR=./.pgdata node db/init.mjs` → `node db/seed-demo.mjs` |
| **PGlite 单进程独占** | 跑 seed 时 dev 还开着 → 崩 | 先停 dev → 跑脚本 → 再起 dev |
| **`rtk npm run dev` 会自己退** | 进程 exited，端口没服务 | 直接 `node node_modules/next/dist/bin/next dev --port 3000` |
| **dev 多开会抢 3000** | 表现成「服务反复挂」 | 只留一个实例，`netstat -ano \| grep :3000` 查残留 |
| **Playwright headless 不 hydrate** | 所有 onClick 无效，假阴性 | 交互验证必须用 `browser_exec`（真浏览器） |
| **`npx eslint` 被 rtk shim 干扰** | 虚假报错 | 用 `node_modules/.bin/eslint` |
| **生产模式 PGlite 起不来** | `npm run start` 下 `/api` 500 | 演示走 dev；线上扣子必须注入真库 |
