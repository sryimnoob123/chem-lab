### 可跳过

`[data-demo-id="demo-action-skip"]` 在动作期间常驻（各套采样命中率 9%~19%，因为只在动作层存在时才在）。点它：**424ms 内动作层全部卸载 + 步号 1→2**，且不再补播 drain（本轮新修，见问题 6）。

### 拖动期间不动画

拖器皿、拖试剂瓶、按住试剂瓶只移动不松开 —— 三个时刻采样：`[data-action-layer]` 0、`[data-bench-pour]` 0、挂在动作层里的 WAAPI 动画 0。动作只在 `dispatch` 之后由 `ActionLayer` 播，拖拽本身不触发。

## 本轮修的 8 个问题（都在边界内：只修这轮实测出来的）

1. **四套动画不播** — `app/exp/[id]/workbench.tsx` 的 `onUseReagent` 接受分支原来是 `choose(verdict.choiceId)`，直接推进、不播动作；`components/exp/scene/actions/for-choice.ts` 的 `actionForChoice` 没有 `calibrate`/`compute` 两个 case（exp01 第 2/3 步就是这个类型），返回 null → 点天平直接跳状态、读数瞬间跳变。
   → 改成 `chooseWithAction(..., actionForChoice(...))`；补 `calibrate → read`、`compute → weigh`。
2. **C6 定容动画从未播过** — exp01 第 5 步 type 是 `dilute`（洗瓶淋洗），而 C6 的 `buildDrops`（悬滴+摇匀）挂在 `addDrops` 上，可玩实验里没有一步用 `addDrops`。
   → 第 5 步 type 改 `addDrops`，文案点名「容量瓶」（`expectedVesselId` 靠文案认器皿，否则会判成锥形瓶拒收）；`TOOL_TYPES` 的 `wash-bottle`/`dropper` 补 `addDrops`。
3. **液面与状态脱钩** — `bench-scene.tsx` 的 `levelOf` 只看本地的 `pours` 计数。
   → workbench 把 `entities[].liquid.level / 容量` 归一后当 `entityLevels` 传下去（只对 exp01 生效，exp03/exp09 行为不变）；`bench-scene` 有实体液位就以它为准。同时补了三处 `entityPatch.liquid`（第 4 步烧杯 30mL、第 6 步锥形瓶 25mL、第 7 步烧杯 100mL）—— 原来这些步骤只有 `note`，状态里没有任何液位。
4. **动作层的液体起点跟台面不一致** — `buildRinse`/`buildStir`/`buildDrops` 的 `levelStart` 默认写死 0 / 0.5 / 0.55。
   → `ActionLayer` 新增 `levelOf` prop，三套动作都从台面真实液位起画；drops 播完让 `pours +1`，动作层一卸液面不掉回去。
5. **读数首帧闪负数** — `countUp()` 里首帧 `now` 可能早于 `start`，实测闪出 `-0.2605 g`。→ `Math.max(0, …)` 夹住。
6. **点「跳过」还会补播 drain** — 跳过本来是要立刻到终态，结果动作层卸载后 `bench-scene` 又接了一条 1388ms 的排水。→ `scene-stage` 传 `skipDrainRef`，跳过路径直接 `sendHome()`。
7. **玻璃棒太细、摆幅太小** — 3.2 单位宽在 1440 下只有 2.5px、±9px 摆动看不出来。→ 加粗到 4.6、摆幅 ±14、角度 ±9°。
8. **`.pgdata` 损坏**（环境问题，不是代码）— PGlite 起库就 `RuntimeError: Aborted()`，所有 `/api/runs` 500。已把坏目录改名保留现场（跑完删了）→ `npm run db:init && npm run db:demo` 重建（40 名学生 / 26 已完成）。

## 交付四 · 互动细节走查（`interaction.json`）

### 拖拽手感

- **跟随延迟**：拖动由 `use-bench-drag` 写 DOM `transform`（不走 React state），rAF 每帧同步；按住移动时采样 `document.getAnimations()` 里没有动作层动画 → 不抢渲染。
- **放下回弹**：`sendHome()` 400ms 缓动滑回基准位；`e2e/wash-return.spec.ts` 的「回位是走回去的，不是瞬移」仍然绿。
