## 三条硬坑（别再踩）
1. **PGlite 不能 `taskkill /F`**：强杀后目录损坏，独立进程再打开直接 `Aborted()`。
   仓库里 `22 个 .pgdata-broken-*` 都是这么来的。停 dev server 优先 Ctrl+C / `process_manage kill` 后**重建库**，别指望复用。
2. **Playwright headless 不 hydration**：元素无 `__reactProps`、所有 onClick 无效、HMR ws 握手失败。
   所有交互验证必须用 `browser_exec`（真浏览器）；Playwright 只能做静态截图/几何断言。
3. **dev server 只能用 `npm run dev`**：`npx next dev -p 3000` 被 rtk 包装后报 `unknown option '-p'`；
   `node next/dist/bin/next dev` 报 `stdin is not a tty` 后退出。
