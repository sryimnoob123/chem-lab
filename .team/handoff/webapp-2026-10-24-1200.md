## 硬坑（这一轮新踩的，别再踩）

1. **CSS 打不过 `benchReuse` 的 `!important`**：`.benchReuse :global(svg)` 是 `width/height:100% !important`，
   在 scene/workbench 两处 CSS 里写媒体查询都不生效（实测 computed 仍 390px）。要改必须
   `svg[role="img"]`（多一个属性选择器）+ `!important`，或者干脆走 inline style。
2. **flex 子项会压缩**：就算 width 设成 1020px，父层 `display:flex` 会把它压回容器宽；要 `flex: 0 0 auto` + `min-width`。
3. **bench-scene 返回 fragment 会挤没场景**：`<>stage + dock</>` 在 `benchReuse` 的 flex 布局里，
   场景被挤到看不见（截图整块空白）。窄屏控件必须绝对定位在 stage 内部。
4. **窄屏试剂架在 stage 底部 absolute**：底部新增任何条状 UI 都要同步把 `.rack` 的 `bottom` 抬高，
   否则两层叠字（截图里「碳酸钠」和「锥形瓶」糊在一起）。
5. **playwright 的 `PLAYWRIGHT_BROWSERS_PATH` 不能用 `$HOME`**：MSYS 会展开成 `/c/Users/...`，
   node 把它当相对路径 → `\c\Users\...` 报 ENOENT。写 `C:/Users/.../ms-playwright`。
6. **`restart-prod.ps1` 的 [5/5] 会卡住**（Invoke-WebRequest 逐个大文件校验），用 `timeout 100` 包住，
   服务其实已经起来了 —— 判据仍是 `curl -s -o /dev/null -w "%{http_code}"` = 200。
