# 设计落地清单：首页与登录页（给 design-lead）

> 依据：`.team/notes/research-market.md`（PhET / Labster / ChemCollective / ilab-x / 欧倍尔 / 润尼尔）。
> 只改 `app/page.tsx`、`app/login/page.tsx` 及对应样式，不动业务逻辑与 `data-demo-id`。

## 10 条可执行做法

### 1. 首页删掉三张说明卡，首屏改成"实验入口"
- **现状**：`app/page.tsx:11-43` 的 `CARDS`（"十个实验，同一套操作规范 / 做错会出真实后果 / 过程性评价 100%"）+ `:110-123` 渲染，占了首屏下半屏。
- **改成**：删除 `CARDS` 与 `.cover-cards` 区块；首屏改为 3~4 张**实验卡**（实验编号、名称、"可进入/待开放"状态），底部一行"查看全部 10 个实验 →"链到 `/experiments`（该页已有完整目录）。
- **为什么**：PhET 首屏就是仿真缩略图网格、ilab-x 首屏是项目/课程入口；说明性内容在成熟产品里从不占首屏。用户要的"套上来"就是这一步。

### 2. 文案压缩到首屏可见 ≤40 字
- **现状**：H1 两行约 20 字 + 副文两行约 46 字 + 3 个 stats + 3 张卡标题/描述 + 页脚 telemetry（`V 0.04 mL`、`0.1 mL 分度`、`7 步操作`、`14 个陷阱`）。
- **改成**：H1 保留"把每一次读数，写进同一本台账。"（品牌句，14 字）；副文压到一行 ≤24 字，例如"10 个实验 · 从称量到滴定 · 记录可复盘"；删掉英文 kicker 或缩成 10px 辅助信息；stats 只保留"10 个实验 / 36 学时"两个数字徽标。
- **为什么**：Labster 首屏只有 H1 + 一句副文；PhET 用"1.8 billion / 173 / 132 / 3702"四个数字替代描述。数字比形容词省字且更有说服力。

### 3. 主 CTA 只留一个
- **现状**：`app/page.tsx:102-109` 同时有主按钮"登录开始实验"与次级"看自动演示 →"；顶栏另有"进入平台"和 DemoLaunch。
- **改成**：全页主 CTA 只保留一个"进入平台 / 开始实验"（桌面前者用顶栏按钮，hero 内不再放第二个主按钮）；"看自动演示"降级为文字链或图标按钮，放次行右侧。
- **为什么**：Labster 把两个 CTA 改成一个后 demo 表单提交 +145%（[GrowthHit 案例](https://growthhit.com/?case_study=case-study-labster-2026)）；PhET 主入口是 Browse/搜索，不是多个按钮并列。

### 4. 首页信息架构改成三段式
- **现状**：封面 = 顶栏 + Hero（kicker/标题/副文/stats/双 CTA）+ 三卡 + 页脚（motto/telemetry/学院），信息层级偏"介绍页"。
- **改成**：① Hero（H1 + 一行副文 + 一个 CTA）→ ② 实验目录（前 3~4 张实验卡 + "查看全部 10 个"）→ ③ 页脚（课程号 03600004 · 2026 秋 · 能源科学与技术学院）。删除 `.cover-telemetry` 与 `READY` 状态（内部彩蛋，学生读不懂）。
- **为什么**：Labster = Hero → Explore → How it works → 社会证明；PhET = Hero + 数字 → Browse → 网格。三段式足够，说明性板块一律不进首页。

### 5. 校园轮播换成"实验场景"静态主视觉
- **现状**：`components/portal/campus-slides.tsx` 4 张校园实景轮播（9s 推近 + 1.4s 淡入），首页 `dim=0.42` 暗场。
- **改成**：首页改静态单图（可用 `CampusSlides tone="paper"` 或直接一张自有实验室/仪器照片），最多 300ms 淡入一次；登录页再保留暗场校园图。图片优先用**自己拍的实验台/滴定管/天平**，不用校园风景当首图。
- **为什么**：PhET 用仿真缩略图、Labster 用 3D 实验场景、欧倍尔用设备渲染图——视觉要证明"这里能做实验"，不是"这里是大学"；自动轮播在现代产品里已被静态 hero 取代（欧倍尔式轮播是反例）。

### 6. 登录页改"品牌左 / 表单右"分栏
- **现状**：`app/login/page.tsx:57-184` 整页 `CampusSlides dim=0.66` 背景 + 居中 430px 白卡（含 520ms 上浮动画）。
- **改成**：桌面 `grid-template-columns: 55% 45%`：左侧品牌视觉（校徽 + 课程名 + 一行照片/色块），右侧白卡表单（圆角 16px、无额外说明）；移动端隐藏左栏，白卡上移，顶部只留校徽 + 课程名。
- **为什么**：Labster 用独立 `my.labster.com` 登录页、ilab-x 用独立登录页，都是"品牌 + 表单"两件事；没有一家在登录页写平台介绍。

### 7. 登录页删掉解释性文案，只留字段与错误
- **现状**：brand 文案"河南大学 · 无机及分析化学实验"、tab"学生登录/教师登录"、placeholder"与教务名单一致""课程负责人发放"、页脚"03600004 · 2026 秋"。
- **改成**：brand 压到"河南大学 · 化学实验"或只留校徽 + 课程名；placeholder 保留最短提示（"学号""姓名""教师口令"），删除"与教务名单一致"这类解释；错误提示就地一行（已有）；页脚保留"返回门户"+课程号。
- **为什么**：ilab-x 登录页只有"账号登录/账号密码/短信验证码 + 验证码 + 注册/忘记密码"，零说明文案；登录页的目标是让人 3 秒内登进去。

### 8. 表单与跳转保持最简，不新增字段
- **现状**：学生 2 字段（学号、姓名）、教师 1 字段（口令），提交后跳 `/experiments` 或 `/teacher`。
- **改成**：不改字段与接口；首字段 `autoFocus`；提交按钮通栏、高度 ≥44px；登录成功后直接落到 `/experiments`（已是）；"返回门户"保留为文字链。
- **为什么**：ilab-x 登录字段 ≤3；Labster 登录与营销站分离、无多余步骤。减少字段和解释就是"成熟"。

### 9. 视觉与动效降噪（保留 1 个入场、删连锁淡入）
- **现状**：首页 6 个元素按 80ms 阶梯淡入（`animationDelay` 0~780ms），登录卡 520ms 上浮；卡片有 hover 但无碍。
- **改成**：首屏只给 3 个元素做 stagger（H1 → 副文 → CTA，总时长 ≤500ms）；删除 stats/卡片的阶梯 `animationDelay`；卡片 hover 统一 `translateY(-2px)` + 阴影，不超过 160ms；`prefers-reduced-motion` 下全部关闭。
- **为什么**：PhET 卡片 hover 放大预览、Labster 静态 hero + 局部视频；没有任何一家把首屏做成 6 段动画秀。动效服务于"可点"，不服务于"解释"。

### 10. 移动端首屏只留"一句话 + 一个按钮 + 三张卡"
- **现状**：390 宽下 Hero 的 stats、双 CTA、三卡、页脚 telemetry 全部纵向堆叠，首屏需要滚动很久。
- **改成**：390 宽隐藏 stats、kicker 与 telemetry；H1（≤2 行）+ 副文（1 行）+ 主 CTA + 前 3 张实验卡（1 列、触控 ≥44px）；"看自动演示"收进页脚；不自动轮播。
- **为什么**：ilab-x 与 PhET 移动端都是列表优先；Labster 移动端首屏只有 H1 + CTA。移动端首屏不是"完整介绍"，是"立刻开始"。
