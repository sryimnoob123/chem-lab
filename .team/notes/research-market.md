# 成熟产品调研：化学/STEM 虚拟实验平台的首页与登录

- 调研日期：2026-10-21 ｜ 方法：`web_search` + `web_fetch`（部分站点 JS 渲染，抓到的文本可能不完整，结论以可抓取部分为准，链接供复核）
- 目的：回答"首页/登录页该放什么、说明性文字怎么处理"，给 design-lead 可直接套用的做法

## 1. PhET Interactive Simulations（全球标杆，免费）

| 维度 | 事实 |
|---|---|
| 首屏 | 大标题 "PhET Interactive Simulations" + 一行 "Over 1.8 billion simulations delivered"；紧接着是 Browse 入口与仿真缩略图网格（科目：Physics / Math & Statistics / Chemistry / Earth & Space / Biology）。标题层级 h1 + 分区 h2，首屏可见文案 ≈40 词，无按钮型 CTA（入口是 Browse/搜索）。[首页](https://phet.colorado.edu/en/) [Browse](https://phet.colorado.edu/en/simulations/browse) |
| 说明文字 | 使命、教师资源、研究等长文全部移到 Teaching / Research / About 二级页；首页用 3 个数字替代描述：173 个仿真 / 132 种语言 / 3702 份教师活动 |
| 信息架构 | 顶栏（Simulations · Studio · Teaching · Initiatives · Donate + 搜索 + Sign in/Register）→ Hero + 数字 → 科目 Browse → 仿真网格 → 教师资源/社区 → 资助方页脚 |
| 视觉动效 | 白底 + 蓝绿强调色；**仿真缩略图本身就是主视觉**；卡片 hover 放大/预览；几乎无大视频、无自动轮播 |
| 登录页 | 顶栏 "Sign in / Register" 进独立页（JS 渲染，抓取仅得标题 "Sign In"）；核心仿真**无需登录即点即用**，账号只服务收藏与教学活动提交 |
| 可借鉴 | ①用"成品缩略图"当首屏视觉；②数字代替形容词；③搜索 + 科目筛选作为主入口；④登录不是门槛 |
| 坑 | 信息密度极大（183+ 仿真），没有筛选会失控；10 个实验的课程平台不能照搬网格规模 |

## 2. Labster（商业 3D 虚拟实验室）

| 维度 | 事实 |
|---|---|
| 首屏 | H1 "Build Confidence That Keeps STEM Students Moving Forward" + 一句副文（≈12 词）；**两个 CTA**：主 "Book a Demo"、次 "See It In Action"；下方三段：Explore Virtual Science Labs / See How Labster Works / Grow Your STEM Program。h1 + 分区 h2，首屏可见文案 ≈35 词。[首页](https://www.labster.com/) |
| 说明文字 | 不写功能长文；"Capabilities / Efficacy / Partnerships" 全部收进 mega menu；效果靠数字、案例、研究卡片；"为什么有效"只给链接入口 |
| 信息架构 | 顶栏 mega menu（Virtual Labs / Why Labster / About / Resources / Getting Started）→ Hero → 三段价值 → 高校 logo 墙 → 案例/研究 → 重复 CTA → 页脚 |
| 视觉动效 | 3D 实验场景/人物图为主视觉；深色品牌色；视频藏在 "See It In Action" 入口，**不自动播放**；卡片 hover 轻 |
| 登录页 | 与营销站分离，独立域名 `my.labster.com`，标题 "Login To Your Account"（正文 JS 渲染）；官网顶栏 Login 直达 |
| 可借鉴 | ①单一主 CTA（有 A/B 案例：两个 CTA 改成一个，demo 表单提交 +145%，[GrowthHit](https://growthhit.com/?case_study=case-study-labster-2026)）；②社会证明放 logo 墙；③"怎么用"拆成 3 个链接块 |
| 坑 | 商业 SaaS 的 demo 转化导向；课程平台不需要 "Book a Demo"，应换成 "开始实验" |

## 3. ChemCollective（CMU，化学虚拟实验室）

| 维度 | 事实 |
|---|---|
| 首屏 | H1 "Resources to Teach and Learn Chemistry" + 3~4 行介绍段落（≈60 词）+ 直接进入 Virtual Labs 小节（内嵌滴定操作示例）。h1 + h2，无 CTA。[首页](https://chemcollective.org/) |
| 说明文字 | 几乎所有信息**直接写在正文**：Virtual Labs / RealChem / OLI Chemistry 各一段；把"怎么用"写成教师用途（pre-lab、作业替代、课堂活动） |
| 信息架构 | 单栏长页：Virtual Labs → RealChem → OLI Chemistry → 联系；无强 CTA、无营销区块 |
| 视觉动效 | 学术站点风格，文字+截图/视频为主，无卡片动效；可信但吸引力弱 |
| 登录页 | 无账号体系，虚拟实验室打开即用（以抓取页面为准） |
| 可借鉴 | ①"教师怎么用"可以压成 3 个用途短语；②实验截图直接展示能力；③内容可信度靠机构署名 |
| 坑 | 典型"文字墙"，正是用户明确不要的介绍性写法；不可照搬 |

## 4. 实验空间 ilab-x（国家虚拟仿真实验教学课程共享平台）

| 维度 | 事实 |
|---|---|
| 首屏 | 无营销 hero；顶部导航后直接是数据与入口：热门实验、推荐课程、一流课程（国家级 1684 / 省级 1568）、实验课程（全部 4990）、实验类型（基础练习 1178 / 综合设计 2644 / 研究探索 1079）。导航 + 数据块，首屏几乎无说明文案，CTA = 登录/注册 + 项目卡。[首页](https://www.ilab-x.com/) |
| 说明文字 | 几乎无说明文字，用**分类计数、排行榜、参与高校列表**承载信息；申报/规则说明在二级页 |
| 信息架构 | 数据概览 → 热门实验 → 课程分类 → 类型统计 → 共享排行 → 参与高校 → 页脚 |
| 视觉动效 | 蓝白政务/平台风格；列表 + 数据块 + 小缩略图；基本无动效；重密度 |
| 登录页 | 独立登录页：账号登录 / 账号密码 / 短信验证码切换 + 图形验证码 + 注册/忘记密码，**无任何说明文案**。[登录页](https://www.ilab-x.com/login) |
| 可借鉴 | ①首屏用"数字 + 入口"而非解释；②登录页字段少、模式切换清晰；③课程平台天然适合"目录"而非"介绍" |
| 坑 | 视觉陈旧、信息过载；课程平台应保留品牌感与呼吸感 |

## 5. 欧倍尔（国内商业虚拟仿真厂商）

| 维度 | 事实 |
|---|---|
| 首屏 | 轮播大图 + "选择欧倍尔解决方案 / 3D技术、AR增强现实技术、VR虚拟现实技术 / 引领仿真教学新革命"（两行 ≈30 字）；下方"品牌优势 / 技术优势 / 质量保证 / 服务优势"四段长文。h1 缺失、多为视觉标题，CTA 以轮播/产品入口为主（以抓取为准）。[官网](http://www.bjober.com/) [产品中心](http://www.bjoberj.com/html/cp/) |
| 说明文字 | 说明基本以**段落直写**；产品能力放产品中心二级页；新闻与案例承接 |
| 信息架构 | Hero 轮播 → 解决方案选择 → 四大优势（长文）→ 产品中心 → 新闻 → 案例 → 资质 → 页脚 |
| 视觉动效 | 深色科技蓝、3D 设备渲染图、轮播；B2B 企业站风格 |
| 登录页 | 官网首页无面向学生的登录入口（以抓取首页为准），登录在各产品平台内部 |
| 可借鉴 | ①3D/设备渲染图作为能力证明；②解决方案按行业/专业分入口 |
| 坑 | 长段落 + 自动轮播，是用户点名不要的"介绍性"风格；不可学 |

## 6. 润尼尔（国内商业虚拟仿真厂商）

| 维度 | 事实 |
|---|---|
| 首屏 | 四块业务入口（虚拟仿真实验教学 / VR教育应用 / VR专业人才培养 / 实验室信息化管理），每块一句说明（1~2 行 ≈30 字）；顶部导航，CTA = 各业务入口。[官网](https://www.rainier.net.cn/) |
| 说明文字 | 说明直写但控制在每块 1~2 行；新闻中心、关于我们放二级页 |
| 信息架构 | 四块业务 → 新闻中心 → 关于我们/联系 |
| 视觉动效 | 企业站蓝白、卡片+图标，动效少 |
| 登录页 | 独立登录/管理平台（rainiersoft.cn 登录页），官网首页不解释登录 |
| 可借鉴 | "一图一句"的业务入口；单块文案长度可控 |
| 坑 | 仍是"介绍公司"逻辑，不是"学生开始实验"逻辑 |

## 对比结论

1. **首屏只做一件事：给入口。** PhET 给仿真网格、ilab-x 给项目列表、Labster 给单一 CTA；没有一家把"平台理念/评分规则/事故后果"写在首屏。
2. **说明性文字三种归宿**：移到二级页（PhET）、收进 mega menu（Labster）、替换成数字与分类计数（PhET 3 个数字、ilab-x 4 组计数）。"直接写一段"是 ChemCollective/欧倍尔的做法，也是被用户否掉的做法。
3. **视觉证明 > 文字描述**：PhET 用仿真缩略图、Labster 用 3D 场景、欧倍尔用设备渲染图；文字只留标题 + 一句副文。
4. **登录页共识**：独立页（Labster、ilab-x）或弹层（ilab-x 登录弹层），字段 ≤3、切换身份用 tab、无营销长文；PhET 甚至不强制登录。
5. **动效克制**：没有一家现代产品用自动轮播大图当首屏主视觉（欧倍尔属旧式 B2B 反例）；hover 放大/预览、进场轻淡入是主流。
6. **国内平台可借"数据入口"，不可借"长段落"**：ilab-x 的计数块、润尼尔的一图一句可以借；欧倍尔的四段优势文案不能借。
7. **对本项目**：10 个实验的规模，适合「PhET 的实验卡网格 + Labster 的单一 CTA + ilab-x 的数字入口」混合；首页结论是"目录 + 主张 + 一个按钮"，不是"介绍页"。
