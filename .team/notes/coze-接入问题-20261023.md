## 二、卡点（要拿出去问的）

1. **延迟**：单轮问答 5.6s，真实评分 prompt 更长（要送方案 JSON + 要求输出分项），预计 7~9s；目标 5s 内。
2. **模型不可枚举**：`GET /v1/models` 返回 404；`model_info_config.model_id` 只认**数字 ID**（名字形式报 `code 4000 Request parameter error`），不知道从哪个接口列空间可用模型。
3. **OAuth 服务端应用入口缺失**：该账号「API 管理 → 授权」只有「个人访问令牌」，没有 OAuth 应用入口，企业 JWT（`/api/permission/oauth2/token`）走不通。
4. **PAT 限制**：30 天到期 + 撞过「个人访问令牌创建数量已达上限」（`code 777042091`，删掉一个过期令牌才建成功）。
5. **异步协议**：`/v3/chat` 必须发起→轮询→取消息三轮；`stream:true` 实测没收到任何 SSE 事件（事件序列为空）。
6. **结构化输出未验证**：评分要稳定 JSON，不知道扣子侧是否支持 `response_format` / JSON schema。
7. **配额**：账号页显示「总积分 0，2026-11-29 到期」，不确定调模型是否受限、QPS 多少。

## 五、三个决策问题的结论（2026-10-23 查证）

### 1. 效果是否与扣子平台一致
同一个 `bot_id`、同一模型、同一人设 → **内容质量一致**。差在四点：
- API 调的是**发布版本**，平台调试页看的是草稿；改完 bot 必须重新 `publish` 才生效
- 平台网页是**流式**，所以体感快；我们走异步轮询，体感 = 总耗时
- 平台网页带会话上下文（`context_round: 3`），我们每次新建会话 → 助教连续追问会"失忆"，
  要一致得复用 `conversation_id`
- 平台里若模型选了"深度思考"一样会慢；我们已在 bot 配置里关掉

### 2. 计费
- 官方文档：**个人版/团队版/企业版都不收智能体调用费**（只有"专业版"收，且该计费项已下架）；
  模型等消耗按**积分**抵扣，企业版积分不足时从火山引擎现金账户扣
- 模型单价参考火山方舟（豆包 Seed 2.0 pro，≤32K 输入）：输入 3.2 元/百万 token、输出 16 元/百万 token、缓存命中 0.64
- 我们估算（一次评分 ≈ 输入 1.5k + 输出 300 token）：约 **0.01 元/次**；200 次 ≈ 2 元。
  **需向平台确认**：1 积分抵多少 token / 一次调用扣多少积分

### 3. 有效期与长期运营
| 凭据 | 官方有效期 | 我们账号现状 |
|---|---|---|
| PAT 个人访问令牌 | **1~30 天，不能永久**（官方 FAQ 明确） | 已建一个 30 天（11-22 到期），且撞过创建数量上限 |
| **SAT 服务访问令牌** | **可设永久**，企业版功能 | 入口被"功能访问控制"挡住 → **需企业超级管理员开通** |
| OAuth 应用（JWT） | access_token 900s~24h，自动刷新 | 账号「授权」页无 OAuth 应用入口 |
| 企业订阅 | 包年包月 + 按量 | 页面显示「总积分 0，2026-11-29 到期」← 长期运营的真正风险 |
| 火山方舟直连（备选） | API Key 长期有效 | 需 `ARK_API_KEY`，按 token 计费，不依赖扣子订阅 |

**结论**：演示用现在这套够（5.6s）；长期运营必须解决两件事——① 超管开通 SAT（永久令牌）或 OAuth 应用入口；
② 确认 2026-11-29 到期后的续费/积分安排。兜底方案是火山方舟直连（最快、计费透明、不受令牌策略影响）。
