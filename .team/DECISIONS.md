## 14. 红线：dev 在跑时不许碰 .pgdata（2026-10-20 19:35）
PGlite 是单进程独占，dev 运行时跑 `db/init.mjs` / `db/seed-demo.mjs` / 任何直连脚本 / 另起 dev 做 e2e，会把数据目录写坏（已实际发生一次，靠重建恢复）。
规矩：①改库前先 `taskkill /T /F` 结束 next 进程树；②需要独立库就把 `PGLITE_DIR` 指到临时目录；③坏库保留现场不删。

## 15. 应用结构：门户 → 登录（学生/教师）→ 实验选择 or 后台（2026-10-20 19:35）
`/` 门户（无翻页感、无分屏 deck）；`/login` 学生填学号+姓名、教师走口令，登录后分流：学生 → `/experiments`（实验选择），教师 → `/teacher`（后台）。
实验页 `/exp/[id]` 是应用内页，顶部带返回，不用营销排版。

## 16. 并发上限收到 8 个 agent（2026-10-20 22:55）
今天内存爆过一次（同时开 5~8 个队友 + 多实例 Playwright 截图）。规矩：
①**同时在跑的 agent ≤8**，默认只开 3~4 个，完成即退；
②Playwright/截图串行跑，不并发多实例；
③大扇出（如 10 个实验定义）用 workflow 分批，一次 ≤5。

## 17. 交互手感标准：SLG 手游级（2026-10-20 23:10）

用户要求：点试剂瓶 / 点锥形瓶 / 拖到试管，每一下都要有 100~300ms 的即时反馈（缩放、发光、轻微震感），点了立刻有反应，不许「点了等跳转」。

规矩：
1. 按下 ≤100ms 必须有可见变化（:active + CSS，禁用 JS 定时器做按下态）；
2. 动作完成 100~300ms 收束（弹一下 / 抖一下），不做无谓等待；
3. 投错目标给**拒收抖动 + 规范文案**，不许静默；
4. 时长收敛成 CSS 变量（--press-in / --press-out / --pop / --shake），不散落硬编码；
5. prefers-reduced-motion 下保留颜色与描边变化，只取消位移。

## 18. 每一步两条分支：成功 / 失败 / 可重做（2026-10-20 23:20）

用户要求：每一步都要有成功和失败两条分支。对了给漂亮的正反馈动画（液体变色、气泡上升、沉淀缓降、视觉脉冲）；错了给有教学意义的失败动画，并明确告诉学生为什么错（例：滴定管不能直接投加固体会堵塞），失败后能重做。

规矩：
1. 成功分支 = 器皿脉冲（360ms）+ 现象动画（变色 600 / 气泡 stagger 90 / 沉淀缓降 900）+ 事件条 --jade-600 + 一句「为什么对」；
2. 失败分支 = 器皿抖动 240ms + 对应事故特效 + 事件条 --danger **固定两行**：第一行「错在哪」≤20 字，第二行「为什么」（机理/规范）；
3. 失败后必须给「重做本步」按钮（44px），点了回到该步开始时的快照，可重新选择；只有 L4（terminate）才终止实验，且终止页也要有重新演示入口；
4. 所有文案取自 experiments/<id>/definition.ts 的 feedback，UI 不得自行编写化学解释；
5. 演示钩子：demo-feedback-ok-<step>、demo-feedback-fail-<step>、demo-retry-<step>。

## D-031 ~ D-034 · 前测分数落库（2026-10-24）

起因：二轮 E1 全链路 8/8 走通，报告页三段分却是 `预习 0 / 操作 100 / 报告 92`（总分 86）。
根因是 `quiz_answers` 表**只有读路径**（`lib/persist/report.ts` + `lib/persist/score.ts`），
前测（`components/exp/bopbps-gate.tsx`）只把「通过」写进 localStorage，答案从不提交；
于是真实学生分数上限 90，而 `?auto=1` 演示靠 `finishRun` 的 override 反而更高。

| # | 决策 | 为什么 | 证据 / 落点 |
|---|---|---|---|
| D-031 | 前测答案走「**run 创建后补写**」，`quiz_answers.run_id` 保持 notNull，不改 schema | 另一条路（`run_id` 允许为空）要加迁移 + 补 studentNo/experimentId 归属列，等于把「作答归属」做成两套；而门禁通过后操作台立刻建 run，补写窗口只差一次点击 | 门禁提交 → localStorage（`lib/pedagogy/quiz-store.ts`）→ `workbench.bootstrap` 拿到 runId 后 `POST /api/runs/[id]/quiz`；交卷前再补一次覆盖「重做前测」 |

### 忘了就会复发的点

1. **`quiz_answers.run_id` 是 notNull，但没有外键** —— 别因为「run 还不存在」就往里写空 UUID，报告页读不到、教师端也对不上。
2. **重启 dev/standalone 前删掉 `.pgdata-*` 临时库**，同一目录双进程会让全套 DB 接口 500（页面靠兜底渲染，看起来像业务 bug）。
3. **预习分不再有特例**：谁再想在展示层给预习「补 10 分」，先看 D-033 —— 从答案算，不从分数改。
