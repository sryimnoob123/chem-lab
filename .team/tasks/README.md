# tasks/ —— 任务卡（谁认领谁自己写）

Lead **不派活、不写死分工**。Lead 只给目标、硬约束、验收标准；拆分由团队自己提、自己认领。

认领后在这里建 `<名字或角色>.md`，内容 ≤20 行：

```markdown
# <任务名>

认领人：<角色名>
独占文件：<列出来，保证和别人的不重叠>

## 目标（≤5 条）
1.
2.

## 对上游/下游的接口
- 我从谁那里要什么：
- 我给谁什么（签名/类型/文件路径）：

## 验收
- 命令 + 期望输出：
```

规矩：
- **同一文件同一时间只能有一个 owner**；抢同一个文件 = Lead 叫停。
- 共享文件（`AGENTS.md`、`db/schema.ts`、`strings.ts`、`package.json`、`*.config.*`）只有 Lead 能改。
- 跨角色接口一旦定下，写进 `../DECISIONS.md`，别只口头说。
