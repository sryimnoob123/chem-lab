## 阶段 C · 动画演出（"关掉声音也知道刚做了什么"）

- [x] C1 洗涤：进水 → 刷子搅动（液体跟转）→ 倒水（drain 已有）→ 沥干
      （`actions/rinse.tsx` variant=wash：水带画出 → 液面 0→0.62 → 刷子伸进去来回三次 → 倒水 → 水珠沿内壁滑落。

- [x] C2 搅拌：玻璃棒画圈，液体跟转，颗粒逐渐消失
      （`buildStir`：棒斜插并绕圈、液面一条 dasharray 弧线跟着转、5 颗颗粒缩到 0；**1620ms**）
- [x] C3 加试剂：举瓶 → 倾斜（瓶口不动）→ 液柱 → 液面上升
      （`bench-pour.tsx`：FLY 飞到位 → TILT 倾斜（瓶口锚点不动）→ 液柱 strokeDash → RISE 液面抬升 + 涟漪；
      瓶身随后淡出。drain 与倾倒共用同一套 `data-pour-*` 钩子）
- [x] C4 转移：吸液（管内液柱上升）→ 提起 → 放液
      （`actions/transfer.tsx`：源液面下降 → 管身提起、管尖挂一滴 → 移到目标 → 放液、目标液面上升；**1980ms**）
- [x] C5 称量：读数跳动 → 稳定（现在可能直接显示）
      （`buildWeigh`：秤盘下沉 4.5 → 回弹（760ms）+ 横梁 ±1.6° 摆动；读数由 `countUp()` 用 rAF 从 0 滚到目标值，
      cubic-out 收束；总 **900ms**。截图第 5 步 1.0599 g 已确认滚动后落位）
- [x] C6 定容：液面上升 → 滴到刻度（悬滴）→ 摇匀
      （`buildDrops` 本轮加两段：`data-a="hang"` 悬滴 —— 涨大 → 挂住 → 落下（560ms，delay 1240）；
      `data-a="swirl"` 摇匀 —— 液面弧线左右摆两下（620ms，delay 1300）；总 **1920ms**
- 统一要求：0.5~2 秒，可跳过但默认播完；**拖动期间不动画**
      （实测六条动作 ms：rinse 1900 / stir 1620 / drops 1920 / transfer 1980 / weigh 900 / drain 自带。
      动作只在 `dispatch` 之后由 `ActionLayer` 播，拖拽/点选本身不触发 —— 拖动期间不会冒出动画）
