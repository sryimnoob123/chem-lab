## 第二段：实验台，七步全流程（2 分钟，核心）

**地址**：`http://localhost:3000/exp/exp01?force=1`

进页面先讲布局（10 秒）：
- 左上 = **任务看板**：这一步干什么、判据是什么
- 中间 = **实验台**：器皿 + 洗涤槽
- 下方 = **工具托盘**：软毛刷、抹布、洗瓶、玻璃棒、量筒、移液管、洗耳球
- 左中 = **试剂架**：碳酸钠、蒸馏水、硫酸

**七步每步只点一下：**

| 步 | 你怎么做 | 屏幕上会出什么 |
|---|---|---|
| 1 认领洗涤 | 把**容量瓶**（或烧杯）**拖进洗涤槽** | 「容量瓶已倒置晾干：内壁无水珠」→ 跳第 2 步 |
| 2 天平调平内校 | **点分析天平** | 「空载 0.0000 g，已内校」→ 跳第 3 步 |
| 3 差减称量 | **点分析天平** | 记 m₁ − m₂ → 跳第 4 步 |
| 4 溶解转移 | 点**洗瓶**（选中）→ 再点**烧杯** | 「进入第 5 步 · 容量瓶定容与摇匀」 |
| 5 定容摇匀 | 点**洗瓶** → 再点**容量瓶** | 「进入第 6 步 · 移液管润洗、移取与放出」 |
| 6 移液放出 | 点**移液管** → 再点**容量瓶** | 「进入第 7 步 · 浓硫酸稀释」 |
| 7 稀硫酸配制 | 点**玻璃棒** → 再点**烧杯** | 「✓ c(H₂SO₄)=0.50 mol/L」，右侧出「实验完成 · 100 操作分」 |

**工具怎么用**：点工具选中（会高亮）→ 再点器皿。或者直接从工具拖到器皿上。

**拖动规则**（讲一句就行）：器皿拖到**洗涤槽**才算洗，松手自动弹回原位，不会留在半路。

**关键话术**：
> 「每一步只做一件事，做完立刻给判据 —— 学生不会不知道自己错在哪。」

## 第三段：负反馈（1 分钟，演示重点）

三种做法，**故意做错**给老师看。

### ① L1 轻微违规（−2 分）
拿**抹布**（或软毛刷）点**容量瓶** → 在容量瓶内壁擦

画面：
- 右上「⚠ L1 · 提醒」
- 事故条：「内壁擦出纤维 → 体积不准」
- 三段式：**错在哪 / 为什么 / 怎么办**（换蒸馏水重冲 3 次，倒置晾干；本步不废）
- 底部「−2 分」

### ② L3 严重事故（−8 分 + 碎裂动画）
拿**玻璃棒**戳**容量瓶**（当作搅洗）

画面：
- **瓶壁裂开 + 碎片飞散**
- 右上「⚠ 器皿破裂」
- 事故条：「瓶壁裂纹 → 容量瓶报废」，理由「薄壁量出式器皿，一戳就裂」
- 底部「−8 分 · 重做本步」

### ③ L4 终止级（演示页里看）
本地实验台里 L4 是「水入酸」，需要第 7 步才能触发。想稳定演示就去**失败动画页**（第四段）。

**关键话术**：
> 「错误不是扣分了事，是告诉你错在哪、为什么、怎么改。严重到一定程度实验直接终止。」

## 第四段：失败动画演示页（1 分钟）

**地址**：`http://localhost:3000/fx-demo`

左边 8 条，右边播。每条都写了**触发条件**和**后果**：

| 动画 | 触发条件 | 后果 |
|---|---|---|
| 爆炸 L4 | 把水倒进浓硫酸 | 剧烈放热、液体冲溅，终止 |
| 有毒气体 L3 | 开放台面做产气反应，不进通风橱 | 气体扩散，须撤离 |
| 着火 L4 | 有机溶剂靠近明火 | 容器口起火，湿布/沙土覆盖 |
| 暴沸 L3 | 加热未加沸石 | 液体冲出，烫伤 |
| 器皿破裂 L3 | 热瓶骤冷 / 玻璃棒戳洗 | 裂纹扩散，刻度失效 |
| 灼伤 L2 | 徒手取热坩埚 | 皮肤烫伤，冲淋 15 分钟 |
| 仪器事故 L3 | 天平超载 / 液体入内 | 传感器失准，须报修 |
| 重金属污染 L2 | 含铅汞废液倒下水道 | 环境污染 |

**关键话术**：
> 「这些不是随便放的动画，每一条都对应一个真实错误操作 —— 学生做错了才会看到。」

## 出问题时的应急

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面白屏 / 404 | dev 挂了 | 重启：`npm run dev`，等 30 秒 |
| 接口 500 | PGlite 库坏了（强杀 dev 导致） | `mv .pgdata .pgdata-broken-$(date +%H%M%S)` → `PGLITE_DIR=./.pgdata node db/init.mjs` → `node db/seed-demo.mjs` → 重启 dev |
| 教师端空表 | 演示数据没播 | 停 dev → `node db/seed-demo.mjs` → 起 dev |
| 点了没反应 | 当前步不该点那个 | 看左上任务看板的「下一步」 |
| 拖动没反应 | 只认洗槽，别的地方会弹回 | 拖到洗涤槽 |
