## 二、演示顺序（约 12 分钟）

### 0 · 开场 30 秒
首页 → 滚动到三个精做实验：**称量配制 / 醋酸电离常数 / 酸碱标定**
一句话：三个实验覆盖「称量·配制」「平衡·常数」「滴定·标定」三类基本操作。

### 1 · exp01 称量配制（约 4 分钟）
1. 点「开始实验」→ 进入实验台
2. 按左下角「下一步」提示走前 3 步（称量、转移、洗涤）
3. **第 4 步「溶解」是重头戏**：把试剂架上的蒸馏水**拖**到烧杯
   - 抓起时试剂瓶微缩 + 半透明
   - 移到烧杯上出现**虚线框「松手加入」**
   - 松手 → 吸附 → **倒入动画播完**才推进到下一步
4. **提示三级阶梯**：点右下角灯泡
   - 第 1 次 → `H1 1/3`（方向：想想该用哪种器皿）
   - 第 2 次 → `H2 2/3`（具体：用蒸馏水）
   - 第 3 次 → `H3`（高亮：右侧主按钮描边 + 箭头），之后显示「已用完」
5. 故意做错一次 → 看**事故横幅**（黄色 L2，标扣几分，1.6~2.4 秒自动收）

### 2 · exp03 醋酸电离常数（约 4 分钟）
1. 第 1 步拖蒸馏水到锥形瓶 → **被拒收**（三行红字讲清为什么不能加，本步不动）
2. 按正确路径：移液 → 加指示剂 → 滴定 → 读 pH → 填报告
3. 讲一句：这个实验的分数线是「电离常数 Kₐ 与文献值对照」

### 3 · exp09 酸碱标定（约 4 分钟）
1. 第 2 步「酸入水」：拖**浓盐酸**到烧杯（注意方向：酸入水，不是水入酸）
2. 第 5 步「加酚酞」：拖酚酞到锥形瓶 → **液体变粉**，能看液面高光和气泡（2.5D 质感）
3. 交卷 → 报告页
   - 三段分：预习 10% / 操作 40% / 报告 50%
   - 操作分下面一行：**「提示 k 次（−X 分）」**——现场讲「主动求助会被如实记录，但只扣 1/3/5 分，不否定整次实验」

## 四、讲稿要点（三句话）

1. **三段分**：预习占 10%、操作占 40%、报告占 50%，每一步操作都进时间线，交卷时服务端重放算出分数。
2. **三类扣分**：违规（操作不对）、事故（危险动作，L1 提醒 / L2 扣分 / L3 严重 / L4 终止）、提示（主动求助，1/3/5 三级）。
3. **教学闭环**：操作 → 即时反馈 → 报告 → 教师端能看到全班每一步。
