## 二、正式演示（5–6 分钟，五段）

| 段 | 地址 | 你要做的 | 屏幕上该出现什么 |
|---|---|---|---|
| ① 课前测 | `/exp/exp01` | 答 **3 题**（没有第 4 题）：**D / B / C** → 提交 | 逐题出「答案 + 为什么」；**全对才解锁**操作台，答错点「重新作答」 |
| ② 七步 | `/exp/exp01?force=1` | ①容量瓶拖进洗涤槽 → ②点天平 → ③再点天平 → ④洗瓶→烧杯 → ⑤洗瓶→容量瓶 → ⑥移液管→容量瓶 → ⑦玻璃棒→烧杯 | 每步底部出一句结果（「容量瓶 100 mL 已倒置晾干」…「实验完成」）；步骤数 01→07；洗涤动画约 2.5 秒才推进 |
| ③ 负反馈 | 同上，第 1 步 | 抹布→容量瓶（L1）；再玻璃棒→容量瓶（L3） | L1：底部 −2 分、事故条「内壁擦出纤维 → 体积不准」；L3：**点完约 0.6 秒**才炸，瓶身碎裂 + 碎片飞散，右上「L3 · −8 分 重做本步」 |
| ④ 交卷→报告 | 右上「交卷」 | 交卷后落到**后测页**，答 **B / B / A** → 提交 → 点「进入报告与评分」 | 报告页：**86 / 100**（零事故 + 7/7 + 后测 3/3）、总结一句、时间线逐条「通过」、后测逐题解析 |
| ⑤ 教师端 | `/teacher` | 直接打开（**没有口令页**）；点任一学生看明细 | 40/26/84.9、事故分布、五维雷达、学生台账；明细页有分数尺与事故日志 |

> 讲台上**不要念死分数**：报告总分 = 预习 10% + 操作 40% + 报告 50%，随事故与后测变化。
> 彩排实测：7/7 完成但有 1 次 L1（−2）→ **85 分**。念「三段分」和「7/7、零事故」就够。

## 三、讲稿三句话

1. **一步一个判据**：每一步只做一件事，做完立刻告诉你对错与依据。
2. **错误有后果**：违规 −2 / 数据作废 −5 / 事故 −8 重做 / 危险动作终止，每条都写「错在哪 / 为什么 / 怎么办」。
3. **教学闭环**：操作 → 即时反馈 → 报告 → 教师端看全班分布。

## 四、兜底（现场出问题照这个做）

| 现象 | 处理 |
|---|---|
| 页面白屏 / 404 | 等 5 秒（dev 首次编译 1–3 秒）；仍白屏就重启 dev，页面出来再点 |
| 教师端数字变成 84.6 / 47 次事故 | 彩排留下的实验记录污染了均值 → 重跑第 1 步 seed，刷新页面 |
| 某一步点了没反应 | 看底部一行「现在该做：…」照着做；工具要先点选中（高亮）再点器皿 |
| 器皿拖了没洗上 | 必须松手在**洗涤槽**里；拖到别处会弹回原位 |
| 前测做完没进实验台 | 没全对。点「重新作答」，答案 D / B / C |
| 报告分数比预期低 | 后测没答或答错（报告页可以直接补答），或中途有事故扣分 |
