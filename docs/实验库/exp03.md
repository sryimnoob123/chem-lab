## 2. 实验目的（三维，每条可判定）

- **知识**：能写出 CH₃COOH 的电离方程式与 Kₐ 表达式，说明 α 随 c 减小而增大、Kₐ 只随温度改变的原因。
- **技能**：能独立完成 4 个浓度点的系列稀释与 pH 计两点校准，使 Kₐ 平均值与文献值 1.8×10⁻⁵（25 ℃）相对误差 ≤10%，α 随稀释呈单调递增。
- **素养**：能说出冰醋酸（腐蚀 + 蒸气刺激）必须在通风橱内量取的规范，并在电极破损、样液泼溅到仪器两种情形下正确处置。

## 3. 原理（≤150 字 + 关键公式）

CH₃COOH 在水中部分电离：CH₃COOH ⇌ H⁺ + CH₃COO⁻（简写 HAc ⇌ H⁺ + Ac⁻）。
设初始浓度 c、电离度 α，则平衡时 [H⁺]=[Ac⁻]=cα、[HAc]=c(1−α)：

  Kₐ = cα² / (1 − α)，α = [H⁺] / c × 100%

pH 计测得 pH 后 [H⁺]=10⁻ᵖᴴ，代入即得 α 与 Kₐ。稀释使 c 减小、α 增大，但 Kₐ 在定温下为常数——这正是"测定"的判据。25 ℃ 时 Kₐ(CH₃COOH)=1.8×10⁻⁵，pKₐ=4.76。

变量：c 为醋酸的分析浓度（mol·L⁻¹）；α 无量纲，报告用 %；Kₐ 无量纲（标准态近似）。

## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

```
[前测1][K1] 25 ℃ 时 0.100 mol·L⁻¹ CH₃COOH 溶液测得 [H⁺]=1.3×10⁻³ mol·L⁻¹。其电离度 α 与电离常数 Kₐ 约为：
A. α=1.3%，Kₐ=1.7×10⁻⁵
B. α=1.3%，Kₐ=1.7×10⁻⁶
C. α=13%，Kₐ=1.7×10⁻⁵
D. α=1.3%，Kₐ=1.7×10⁻³
答案：A
解析：α=[H⁺]/c=1.3×10⁻³/0.100=1.3%；Kₐ=cα²/(1−α)=0.100×(0.013)²/0.987≈1.7×10⁻⁵。
B 把 Kₐ 算成 α² 的数量级、漏掉 c 与 (1−α)，C 把 α 的小数与百分数混用，D 把 Kₐ 当成 cα。
```

```
A. 在实验台敞口量取冰醋酸，直接向其中加水
```

```
[前测3][S2] pH 计读数显示 3.02 并在缓慢上升（30 s 内变化 0.02），此时应该：
A. 立刻记录 3.02，误差不大
B. 继续等读数稳定（30 s 内变化 ≤0.01）后再记录，并记下稳定值
C. 用手晃动电极让它"快点稳定"
D. 重新校准仪器再测
答案：B
解析：玻璃电极响应有 10~60 s 的平衡过程，漂移中读数会带来 0.05~0.2 pH 的系统偏差，直接放大到 Kₐ 上。
C 晃动电极会使球泡与液膜不稳定、且易碰壁破损；D 属过度处置，应先等稳定。
```

```
[后测1][K1] 把同一支 CH₃COOH 溶液由 0.100 mol·L⁻¹ 稀释到 0.010 mol·L⁻¹（温度不变），下列说法正确的是：
A. α 减小，Kₐ 增大
B. α 增大，Kₐ 基本不变
C. α 与 Kₐ 都增大
D. α 与 Kₐ 都不变
答案：B
解析：稀释促进弱酸电离，α 增大（本例约由 1.3% 升到 4.2%）；Kₐ 只与温度有关，定温下为常数。
A、C 混淆了"平衡移动"与"平衡常数改变"；D 忽略了浓度对 α 的影响。
```

```
[后测2][A1] 测完 4 份样品后，复合 pH 电极的正确处置是：
A. 用蒸馏水冲净后直接放在台面上晾干
B. 用蒸馏水冲净、滤纸吸干，浸入 3 mol·L⁻¹ KCl 保护液
C. 长期浸泡在蒸馏水中以免球泡干裂
D. 用待测液冲洗后插回仪器接口，不取出
答案：B
解析：球泡靠水化凝胶层响应，干放会脱水失效；泡蒸馏水会使内充 KCl 被稀释流失、斜率下降。
A、C 分别造成脱水与水化层破坏，D 让电极长期浸在弱酸中且接口受潮。
```

```
[后测3][S2] 用 pH 4.00 与 6.86 两点校准后，去测 pH≈2.9 的醋酸溶液。下列判断正确的是：
A. 完全不能测，必须换仪器
B. 可以测，但样品落在校准区间之外属外推，结果偏差可能偏大，应在报告中说明
C. 校准无效，需要重新校准成 2.00 与 4.00 两点
D. 只要多测几次取平均即可消除外推误差
答案：B
解析：两点校准确定的是斜率与零点，区间外属线性外推，酸端偏差通常在 0.02~0.1 pH。
A 过度否定；C 无 2.00 标准缓冲液且没必要；D 平均消除的是随机误差，不能消除系统性的外推偏差。
```

```
[迁移][S3] 若把本实验的 CH₃COOH 换成 ①同浓度的 HCl，或 ②0.100 mol·L⁻¹ CH₃COOH 中加入少量 CH₃COONa 固体，请说明：
(1) pH 与 α 各自怎么变、为什么；
(2) 还能不能用"Kₐ=cα²/(1−α)"算 Kₐ，若不能应怎么改；
(3) 你的方案要改哪些器材/步骤，测几个浓度点才够。
评分要点：①HCl 完全电离，α≈100%，公式失效（cα²/(1−α) 分母趋 0），应改用 pH 直接求 [H⁺] 或改做滴定；
②同离子效应使电离平衡左移，α 减小、pH 升高，但 Kₐ 不变，仍可用 Kₐ=[H⁺]²/(c−[H⁺]) 但要考虑 NaAc 引入的 Ac⁻ 初浓度，
需用 Kₐ=[H⁺]([H⁺]+c₀(Ac⁻))/(c−[H⁺])，c₀(Ac⁻) 为 NaAc 引入的初浓度；③至少 3~4 个浓度点，器材不变，步骤增加"称量 NaAc 并溶解"。
```

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`；L4 触发即终止，操作分记 0 并强制安全复盘。
- 结果误差分档（以待核的文献值 Kₐ=1.8×10⁻⁵ 为基准，|相对误差|）：
  - ≤10%：满分
  - 10%~25%：−5
  - >25%：−15
- 结构性校验（不通过即按 L2 计，不重复扣分）：α 必须随 c 减小单调递增；4 组 Kₐ 的相对平均偏差 ≤10%；校准斜率在 95%~105%。
- 报告分：数据完整性 30%（4 组 pH 双读数、温度、校准记录齐全）+ 计算正确 30%（[H⁺]、α、Kₐ、平均值与偏差）+ 误差分析 20%（能说出温度、活度系数、外推、读数漂移中的至少 2 项）+ 安全复盘 20%（能复述 H1 的处置与 H2/H3 的预防）。
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）。

## 11. AI 评估要点（举一反三）

1. **改浓度序列**：学生把 4 点改为 0.1 / 0.01 / 0.001 mol·L⁻¹ 三点时，0.001 mol·L⁻¹ 已接近水的自电离（[H⁺]≈10⁻⁶），Kₐ 会显著偏大——评估要点是能否识别"弱酸近似失效"的边界，而不是只报误差。
2. **改温度**：把恒温从 25 ℃ 改到 35 ℃，Kₐ 应增大（约 3%~5%），此时与 25 ℃ 文献值比较必然"超差"。评估要点是学生是否意识到"误差分档要以同温文献值为基准"，而非硬凑数据。
3. **改测量手段**：不测 pH 而用 NaOH 标准液滴定求 [H⁺]，或用电导率法求 α。评估要点是方案可行性（滴定会推动电离平衡、终点判断影响 α）、器材增减是否合理、以及"为什么 pH 法更适合弱酸稀溶液"。
