## 2. 实验目的（三维，每条可判定） （待老师核）

- **知识**：能写出本实验 5 个沉淀反应方程式，并用 Ksp 解释"为什么先除 SO₄²⁻、后除 Ca²⁺/Mg²⁺、最后除 CO₃²⁻"。
- **技能**：能独立完成溶解—沉淀—过滤—除碳酸根—蒸发结晶—抽滤干燥全流程，产品纯度检验 4 项全部合格，产率落在 65%~85%。
- **素养**：能说出可溶性钡盐的毒性（口服约 0.8~1 g 可致中毒）与皮肤接触处置，能在蒸发浓缩时主动判断"该停火的时刻"而非蒸干。

## 3. 原理（≤150 字 + 关键公式） （待老师核）

粗盐中 SO₄²⁻、Ca²⁺、Mg²⁺ 以可溶盐形式存在，用"沉淀—过滤"逐级除去：先加 BaCl₂ 使 SO₄²⁻ 成 BaSO₄；再以 NaOH 沉 Mg²⁺ 为 Mg(OH)₂、以 Na₂CO₃ 沉 Ca²⁺ 为 CaCO₃，同时把过量的 Ba²⁺ 沉为 BaCO₃；过滤后加 HCl 除去过量 CO₃²⁻；蒸发结晶得 NaCl。

- Ba²⁺ + SO₄²⁻ → BaSO₄↓　Ksp = 1.1×10⁻¹⁰
- Mg²⁺ + 2OH⁻ → Mg(OH)₂↓　Ksp = 5.6×10⁻¹²
- Ca²⁺ + CO₃²⁻ → CaCO₃↓　Ksp = 2.8×10⁻⁹
- Ba²⁺ + CO₃²⁻ → BaCO₃↓　Ksp = 5.1×10⁻⁹
- CO₃²⁻ + 2H⁺ → CO₂↑ + H₂O

产率 η = m(产品) / [m(粗盐) × w(NaCl)] × 100%，w 为粗盐中 NaCl 质量分数（教师提供）。

**数值自洽校验**：m理 = 5.0 × 0.9250 = 4.625 g；η = 3.2516 / 4.625 × 100% = 70.3% → 报 **70%**（2 位有效数字）。损失 4.625 − 3.2516 = 1.373 g，去向：母液残留（结晶未完全）+ 洗涤溶解 + 转移损失，报告须逐项说明。

## 9. 测验题（前测 3 / 后测 3 / 迁移 1） （待老师核）

```
[前测1][K1] 粗盐中含 SO₄²⁻、Ca²⁺、Mg²⁺，除杂试剂的加入顺序正确的是？
A. Na₂CO₃ → BaCl₂ → NaOH → HCl
B. BaCl₂ → NaOH → Na₂CO₃ → HCl
C. NaOH → HCl → BaCl₂ → Na₂CO₃
D. BaCl₂ → HCl → NaOH → Na₂CO₃
答案：B
解析：BaCl₂ 必须先加并过量，使 SO₄²⁻ 全部成 BaSO₄（Ksp 1.1×10⁻¹⁰）；再加 NaOH 沉 Mg²⁺，加 Na₂CO₃ 沉 Ca²⁺ 并顺带沉掉过量 Ba²⁺（BaCO₃ Ksp 5.1×10⁻⁹）；HCl 必须最后加，用来除去过量 CO₃²⁻ 和 OH⁻。若先加 Na₂CO₃，后加的 Ba²⁺ 会被 CO₃²⁻ 截留成 BaCO₃，除不尽 SO₄²⁻。
```

```

B. BaCl₂ → K₂CO₃ → HCl
C. HCl → BaCl₂ → K₂CO₃

答案：B
```

## 10. 判分口径 （待老师核）

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`；触发 L4 直接终止，本次实验记 0 分并进入安全复盘。
- 结果误差分档（纯度 4 项全合格的前提下）：
  - 产率 65%~85%：满分
  - 产率 55%~65% 或 85%~95%：−5
  - 产率 <55% 或 >95%：−15（>95% 通常意味着洗涤不足、杂质夹带）
- 纯度检验：SO₄²⁻、Ca²⁺、Mg²⁺、pH 四项，每不合格 1 项 −10，四项全不合格按产品不合格处理（结果分 0）。
- 报告分：数据完整性 30% + 计算正确 30% + 误差分析 20% + 安全复盘 20%。误差分析必须解释 1.373 g 损失的去向。
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）。

## 11. AI 评估要点（举一反三） （待老师核）

1. **换沉淀剂**：学生把 BaCl₂ 换成 Ba(OH)₂ 或 Ba(NO₃)₂ 时，追问"新增/失去了哪种离子的去除能力""Ba(NO₃)₂ 会引入什么杂质""饱和 Ba(OH)₂ 的浓度够不够把 SO₄²⁻ 降到检验不出"。判分看是否抓住"同离子/引入新杂质"这条线。
2. **改顺序**：学生把 Na₂CO₃ 提到 BaCl₂ 之前，追问"后加的 Ba²⁺ 去哪儿了""BaCO₃ 与 BaSO₄ 之间会不会发生沉淀转化（Ksp 5.1×10⁻⁹ vs 1.1×10⁻¹⁰）"，看能否用 Ksp 定量说明而不是背结论。
3. **改终点**：学生把"蒸至晶膜"改成"蒸干"，追问"杂质为什么会富集到晶体里""为什么产率反而可能升高但纯度下降"，把产率与纯度两个指标拆开评估。
