## 3. 原理（≤150 字 + 关键公式）

配离子由中心离子与配体以配位键结合，其稳定性用累积稳定常数 β 衡量：β 越大，游离中心离子浓度越低。降低游离配体浓度（加酸）或降低游离中心离子浓度（加沉淀剂、加更强配位剂）都会使配位平衡移动。当沉淀与配位竞争同一金属离子时，二者耦合为一个新平衡，其常数 `K = Ksp · β` 决定沉淀能否被溶解。多齿配体成环带来的熵增使螯合物比同原子数的单齿配合物稳定得多（螯合效应）。配位还改变电对的标准电势，从而改变物质的氧化还原能力。

```
β_n = [ML_n] / ( [M] · [L]ⁿ )                累积稳定常数，越大配离子越稳定
Cu²⁺ + 4NH₃ ⇌ [Cu(NH₃)₄]²⁺                    β₄ ≈ 2.1×10¹³
AgCl(s) + 2NH₃ ⇌ [Ag(NH₃)₂]⁺ + Cl⁻            K = Ksp(AgCl)·β₂ = 1.8×10⁻¹⁰ × 1.1×10⁷ ≈ 2.0×10⁻³
AgBr(s) + 2S₂O₃²⁻ ⇌ [Ag(S₂O₃)₂]³⁻ + Br⁻       K = Ksp(AgBr)·β₂ = 5.0×10⁻¹³ × 2.9×10¹³ ≈ 15
配位改变电极电势：E°'(ML_n/M) = E°(M) + (0.0592/n)·lg(β_低 / β_高)
螯合效应：β₂[Cu(en)₂]²⁺ / β₄[Cu(NH₃)₄]²⁺ = 4.0×10¹⁹ / 2.1×10¹³ ≈ 1.9×10⁶
```

变量：`[M]`、`[L]` 为平衡时的游离中心离子与游离配体浓度（mol·L⁻¹）；n 为配位数；Ksp 为溶度积；β₂ 中的下标指配位数；`E°'` 为配位体系的条件标准电势（V）；en 为乙二胺（双齿配体）。

25 ℃ 常用数据（待老师核，以教材附录为准）：

| 配离子 | β（25 ℃） | 配离子 | β（25 ℃） |
|---|---|---|---|
| [Cu(NH₃)₄]²⁺ | 2.1×10¹³ | [Ag(NH₃)₂]⁺ | 1.1×10⁷ |
| [Cu(en)₂]²⁺ | 4.0×10¹⁹ | [Ag(S₂O₃)₂]³⁻ | 2.9×10¹³ |
| [Fe(CN)₆]³⁻ | 1.0×10⁴² | [Co(NH₃)₆]²⁺ | 1.3×10⁵ |
| [Co(NH₃)₆]³⁺ | 2.3×10³⁴ | — | — |

| 溶度积 / 电势 | 值 | 溶度积 / 电势 | 值 |
|---|---|---|---|
| Ksp(AgCl) | 1.8×10⁻¹⁰ | E°(Co³⁺/Co²⁺) | +1.92 V |
| Ksp(AgBr) | 5.0×10⁻¹³ | E°([Co(NH₃)₆]³⁺/[Co(NH₃)₆]²⁺) | ≈ +0.10 V（教材值，待核） |
| Ksp(CuS) | 6.3×10⁻³⁶ | E°(O₂/OH⁻) | +0.401 V |
| Ksp(Cu(OH)₂) | 5.6×10⁻²⁰ | E°(Cu²⁺/Cu) | +0.3419 V |

关键推论：`K(AgCl 氨溶) ≈ 2.0×10⁻³` 偏小，必须用较浓氨水并过量——这是步 3、步 5 必须"逐滴加到刚好溶"的定量依据；`K(AgBr 硫代硫酸钠溶解) ≈ 15` 已足够大，因此银氨体系中先析出 AgBr、再用 S₂O₃²⁻ 即可溶回，而 AgI 的 `K = 8.5×10⁻¹⁷ × 2.9×10¹³ ≈ 2.5×10⁻³` 与之相差 4 个数量级，靠 S₂O₃²⁻ 溶不动（见 §11 延伸）。

| 步 3 氨水合计耗量 | 0.067 + 0.13 ≈ 0.20 mL，实测含终点保守与摇动损失 | 0.2~0.6 mL（判据） |
| 步 5 AgCl 的物质的量 | n = 0.10 × 0.50×10⁻³ | 5.0×10⁻⁵ mol |
| 步 5 氨溶所需游离 [NH₃] | [Ag(NH₃)₂⁺]=[Cl⁻]≈0.05；[NH₃]²=0.05×0.05/2.0×10⁻³=1.25 | [NH₃]≈1.1 mol·L⁻¹ |
| 步 5 氨水合计耗量 | 1.1×1.0×10⁻³ = 1.1×10⁻³ mol → 0.18 mL；加配位用 0.017 mL | ≈0.20 mL（实测 0.2~0.5 mL） |
| 步 5 AgBr 能否被 S₂O₃²⁻ 溶解 | K = Ksp(AgBr)·β₂ = 5.0×10⁻¹³ × 2.9×10¹³ | ≈15（远 >1，可溶） |
| 步 5 AgBr 溶解所需 [S₂O₃²⁻] | 设 [Ag(S₂O₃)₂³⁻]=[Br⁻]≈0.033：[S₂O₃²⁻]=0.033/√15 | ≈8.5×10⁻³ mol·L⁻¹（3~5 滴 0.50 mol·L⁻¹ 即足） |
| 步 7 乙二胺理论用量 | 0.50 mL 深蓝液含 Cu ≈3.8×10⁻⁵ mol，需 en 7.6×10⁻⁵ mol，0.50 mol·L⁻¹ → 0.15 mL | ≈3 滴（实测 3~8 滴） |
| 步 7 螯合取代常数 | K = 4.0×10¹⁹ / 2.1×10¹³ | ≈1.9×10⁶（几乎完全取代） |
| 步 6 Co 条件电势 | E°' = 1.92 + 0.0592 lg(1.3×10⁵ / 2.3×10³⁴) = 1.92 − 1.73 | +0.19 V |
| 步 6 自发判据 | ΔE = E(正) − E(负) = 0.401 − 0.19 | +0.21 V > 0，自发 |

> 自洽说明：`+0.19 V` 与教材常引的 `+0.10 V` 同量级，差异来自 β 数据版本（见 §12 待核第 7 项）。**两种取值都远低于 +0.401 V，故"配位后 Co(Ⅱ) 才被空气氧化"的结论不受影响**——这正是让学生学会"结论对参数不敏感时要敢于下判断"的地方。

## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

```
[前测1][K1] 已知 β₄[Cu(NH₃)₄]²⁺ = 2.1×10¹³。向 0.10 mol·L⁻¹ 的 [Cu(NH₃)₄]SO₄ 溶液中滴加
6 mol·L⁻¹ NaOH，下列判断正确的是：
A. 立即生成蓝色 Cu(OH)₂ 沉淀，因为溶液中含有 Cu²⁺
B. 不生成 Cu(OH)₂ 沉淀，因为 Cu²⁺ 已被 NH₃ 配位，游离 c(Cu²⁺) 极低
C. 生成 [Cu(NH₃)₄](OH)₂ 沉淀
D. 无法判断，需先知道所加 NaOH 的浓度
答案：B
解析：配离子与简单离子的区别正在于游离离子浓度。由 β₄ = [Cu(NH₃)₄²⁺]/([Cu²⁺][NH₃]⁴)，
c(Cu²⁺) 约为 10⁻¹⁶ mol·L⁻¹ 量级，远达不到 Cu(OH)₂ 沉淀（Ksp = 5.6×10⁻²⁰）所需的 J > Ksp。
A 把"含铜元素"误当"含自由 Cu²⁺"；C 碱式配合物可溶，不会析出；D 即便用很浓的 NaOH，
只要游离 c(Cu²⁺) 仍被 β₄ 压住，就不会沉淀——这正是本实验步 2 要建立的核心认识。
```

```
[前测2][A1] 关于银氨溶液（含 [Ag(NH₃)₂]⁺）的使用与处置，正确的是：
A. 配好后密封保存，下次实验继续用
B. 用剩的直接倒入水槽，用水大量冲走
C. 现配现用，不加热、不蒸干、不过夜；实验结束加稀盐酸破坏后转入含银废液桶
D. 加热蒸干回收金属银，既安全又不浪费
答案：C
解析：银氨溶液久置、浓缩或受热会析出氮化银 Ag₃N（"雷银"），受摩擦或受热即猛烈爆炸，
这是本实验唯一的 L4 事故。A、D 都在制造爆炸条件（D 正是 H1 的触发动作）；
B 让 Ag⁺ 进入下水，属重金属污染，同时把不稳定的银氨留在环境中。
```

```
[前测3][S1] 用最小分度为 0.1 mL 的 10 mL 刻度吸量管量取溶液，液面凹面最低点落在
2.6 与 2.7 之间、约偏向 2.6 一侧的三分之一处。正确的记录是：
A. 2.6 mL
B. 2.63 mL
C. 2.7 mL
D. 2.630 mL
答案：B
解析：仪器读数应估读到最小分度的下一位：分度 0.1 mL → 估读到 0.01 mL，得 2.63 mL
（3 位有效数字）。A、C 未估读；D 多估一位，刻度吸量管达不到 0.001 mL 的精度。
```

```
[后测1][K2] 已知 Ksp(AgBr) = 5.0×10⁻¹³、β₂[Ag(S₂O₃)₂]³⁻ = 2.9×10¹³、β₂[Ag(NH₃)₂]⁺ = 1.1×10⁷。
把 AgBr 沉淀加入 0.50 mol·L⁻¹ Na₂S₂O₃ 溶液中，下列判断正确的是：
A. 不溶解，因为 AgBr 的 Ksp 很小
B. 溶解，因 K = Ksp(AgBr)·β₂[Ag(S₂O₃)₂]³⁻ ≈ 15，配位剂过量时平衡显著右移
C. 溶解并同时生成黑色 Ag₂S 沉淀
D. 只能部分溶解，无论加多少 Na₂S₂O₃ 都会剩余沉淀
答案：B
解析：沉淀被配位溶解的判据是耦合常数 K = Ksp·β。本例 K ≈ 5.0×10⁻¹³ × 2.9×10¹³ = 15，
远大于 1，配位剂过量即可把沉淀溶完（摄影定影的原理）。
A 只看 Ksp 而忽略了配位项，正是本实验步 5 要纠正的错误；
C 混淆了 S₂O₃²⁻ 与 S²⁻，体系中无 S²⁻ 就不会生成 Ag₂S；
D 忽略了"配位剂过量可推动平衡"——只要 K > 1 且配体足够过量，就能溶完。
```

```
[后测2][A1] 某同学做完银氨实验后，把残液留在敞口试管里，打算"明天再处理"。正确评价是：
A. 可行，银氨溶液很稳定，放置一天没有影响
B. 可行，只要把试管放进通风橱就绝对安全
C. 不可行，残液久置会析出爆炸性 Ag₃N，且银属重金属，必须当日加酸破坏后回收
D. 不可行，应立刻加水稀释到很稀再倒入水槽
答案：C
解析：久置与浓缩是 Ag₃N 析出的两个条件，敞口放置同时在满足这两个条件；
干涸后管内残留的 Ag₃N 会在后续清洗、敲击时引爆，风险从"自己"转移到"下一个人"。
D 稀释不改变污染物总量，仍在向下水转移重金属。
```

```
[后测3][S1] 用 1 mL 带刻度滴管量取 6 mol·L⁻¹ 氨水，分度 0.05 mL，读数为 0.35 mL，
共滴入 7 滴。下列记录方式最恰当的是：
A. 7 滴
B. 0.35 mL
C. 0.35 mL（7 滴）
D. 0.4 mL
答案：C
解析：以刻度读数为准（0.35 mL，3 位有效数字，估读到 0.01 mL），滴数作为辅助记录保留，
便于核对"逐滴"操作是否规范。A 只有 1 位有效数字，无法用于误差比较；
B 丢失了滴数这一操作过程信息；D 少估一位，把 3 位有效数字降为 2 位。
```

**迁移题**

```
[迁移][K2+S2] 若把本实验步 5 的氨水换成 0.50 mol·L⁻¹ Na₂S₂O₃ 作为唯一的银配位剂，
现有 AgCl、AgBr、AgI 三种卤化银沉淀（Ksp 分别为 1.8×10⁻¹⁰、5.0×10⁻¹³、8.5×10⁻¹⁷，
β₂[Ag(S₂O₃)₂]³⁻ = 2.9×10¹³），请回答：
(1) 三种沉淀中哪些能被 S₂O₃²⁻ 溶解、哪些不能？请用 K = Ksp·β 定量排序并给出判据。
(2) 对"不能溶解"的那一种，你打算换什么试剂？写出你选择的定量依据。
(3) 若体系里同时存在 Ag⁺ 与 Co²⁺，银氨溶液的"现配现用、当日破坏"要求要不要改？为什么？
评分要点：
(1) 三种沉淀的耦合常数分别为：AgCl 5.2×10³、AgBr ≈15、AgI ≈2.5×10⁻³。
    前两者 K > 1 且数量级足够，可被过量 S₂O₃²⁻ 溶完；AgI 的 K < 1，
    溶解放大量受限于配体浓度（0.50 mol·L⁻¹ 下平衡溶解度仅 10⁻² mol·L⁻¹ 量级），
    实际表现为"几乎不溶"。判据是 K = Ksp·β，而不是单看 Ksp 大小。
(2) 可改用 Na₂S（生成 Ksp ≈10⁻⁵⁰ 量级的 Ag₂S，K = Ksp(Ag₂S)/Ksp(AgI) 极大，不可逆），
    或改用浓 KI 使 AgI 转化为可溶的 [AgI₂]⁻（需高浓度 I⁻）。
    答"用 NaCN"技术上成立但必须主动排除（剧毒、遇酸放 HCN），答对这一点为加分项。
(3) 不因 Co²⁺ 存在而放宽。银氨的不稳定性只取决于 [Ag(NH₃)₂]⁺ 本身，
    与共存离子无关；相反，Co²⁺ 废液需另按含钴重金属废液收集，
    若与银氨混装，反而让"当日破坏"这条要求更难执行。能识别"两类废液分开收集"为加分点。
```

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`；触发 L4 即终止本次实验，操作分记 0 并强制安全复盘。
- 现象分档（以 §6 判据为准，逐项核）：
  - 步 2 两管对比、步 3"先沉淀后溶解"、步 4 可逆/不可逆对照、步 5 三段现象、步 6 变色、步 7 螯合取代与反向验证，**六项齐全且描述可辨**：满分
  - 缺 1~2 项，或颜色描述含混（如只写"蓝色"不区分浅蓝/深蓝/紫蓝）：−5
  - 缺 3 项及以上，或关键对照（步 4 的 5 号管、步 7 的反向验证）未做：−15
- 耗量分档（步 3 氨水、步 5 氨水、步 7 乙二胺三项，与 §8 校验值比）：
  - 三项均在判据区间内且以 mL 记录（3 位有效数字）：满分
  - 有一项超出区间但量级正确，或有一项只记滴数：−5
  - 两项以上超出区间，或存在明显"凑数"痕迹：−15
- 结构性校验（不通过即按 L2 计，不重复扣分）：步 3 终态必须澄清深蓝；步 5 银氨必须在当日加酸破坏；步 7 补氨后颜色不得回蓝。
- 报告分：数据完整性 30%（§8 全部字段，含滴/mL 折算系数与各步颜色）+ 计算正确 30%（AgCl 氨溶 K、AgBr 硫代硫酸钠溶解 K、螯合取代 K、Co 的 E°' 与 ΔE）+ 误差分析 20%（能说出"氨溶 K 只有 10⁻³ 量级，必须过量"与"β 数据版本不同会让 E°' 差 0.1 V 但不改结论"中的至少 1 项）+ 安全复盘 20%（能复述 H1 的三条禁令与 H3 的废液去向）。
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）。

## 11. AI 评估要点（举一反三）

1. **改配位剂浓度**：学生把 6 mol·L⁻¹ 氨水改成 2.0 mol·L⁻¹ 去溶 AgCl，问"还能不能溶完"。评估要点是能否用 `K = Ksp·β₂ ≈ 2.0×10⁻³` 反推所需游离 [NH₃]（本例约 1.1 mol·L⁻¹），意识到"浓度降到 1/3 时体系已到溶解上限，必须加大体积或改用 Na₂S₂O₃"——而不是凭"氨水能溶氯化银"这句口诀下结论。答成"浓度低就多加点"而没有量级估算，说明只记住了现象没掌握判据。

2. **改卤离子**：让学生把步 5 的 KBr 换成 KI，问"后面还能不能用 Na₂S₂O₃ 溶回来"。评估要点是能否算出 `K(AgI) = 8.5×10⁻¹⁷ × 2.9×10¹³ ≈ 2.5×10⁻³ < 1`，从而判断"溶不动"，并指出这正是摄影定影液中碘离子干扰的化学原因。能同时说明"沉淀顺序不变（AgI 的 Ksp 更小，仍先析出），但溶解步骤失败"，是把"沉淀"与"溶解"两个方向的判据分开掌握的标志。

3. **改中心离子**：把 Cu²⁺ 换成 Ni²⁺ 做螯合比较，问"深蓝变紫蓝这个判据还成立吗"。评估要点是学生会不会先查 β 与颜色：Ni(en)₃²⁺ 为紫红色、β 更大，颜色变化方向不同但"螯合物更稳定"的结论一致；进一步追问"若改用 EDTA（六齿）会怎样"，答出"螯合环越多、ΔS 越有利、β 越大，但颜色变化可能不明显，需改用其他手段（如电动势或溶解度）验证"为优秀。这一问同时对应大纲"举一反三"。
