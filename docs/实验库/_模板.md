## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

统一格式：

```
[前测1][K1] 题干……
A. … B. … C. … D. …
答案：B
解析：……
```

- 前测：概念 / 安全 / 读数各 1 题；答错必须给解析，且不能进操作台
- 后测：同概念换情境（不许原题改写）
- 迁移：一道"如果换掉某个条件，你会怎么改"的开放题（对应 AI 评估的延伸一问）

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`
- 终点/结果误差分档：≤…满分；…−5；…−15
- 报告分：数据完整性 30% + 计算正确 30% + 误差分析 20% + 安全复盘 20%
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）

2~3 条延伸问题，写明"学生改了哪个参数会怎样"，供 `lib/llm.ts` 组 prompt 用。
