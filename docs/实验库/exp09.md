## 2. 实验目的（三维，每条可判定）

- **知识**：能用 c(NaOH)·V(NaOH) = c(HCl)·V(HCl) 推导"等体积移取时消耗体积比 = 浓度比"，并说明 0.1 mol/L 强酸强碱互滴的 pH 突跃（约 4.3~9.7）为何使酚酞与甲基橙都可作指示剂。
- **技能**：能独立完成"配液 → 滴定管洗涤润洗 → 装液排气泡调零 → 移取加指示剂 → 半滴滴定至终点"全流程，三次平行测定相对极差 ≤0.2%，相对极差与终点体积均在判分容差内。
- **素养**：能说出浓盐酸必须"酸入水、沿壁、通风橱、护目镜"以及"碱液只用碱式滴定管和聚乙烯瓶"的依据，并在酸/碱溅到皮肤时正确执行"大量流水冲洗 ≥15 min + 报告"。

## 3. 原理（≤150 字 + 关键公式）

酸碱标准溶液不能直接配制准确浓度（NaOH 吸潮、浓盐酸挥发），只能先粗配近似浓度，再用基准物质标定——本实验只做**粗配**与**相互滴定**，标定留给实验 10。

一元强酸与强碱按 1:1 定量反应，化学计量点时物质的量相等，故用同一移液管移取等体积酸液时，消耗碱液体积比即为浓度比。

**关键公式**：

- c(NaOH)·V(NaOH) = c(HCl)·V(HCl)（c 单位 mol/L；V 单位 mL 时两边同单位即可约去）
- c(NaOH)/c(HCl) = V(HCl)/V(NaOH)（V(HCl) 为移取体积，V(NaOH) 为消耗体积）
- 相对极差 = (V_max − V_min) / V_平均 × 100%
- 相对误差 E_r = |c_测 − c_参考| / c_参考 × 100%

**突跃与指示剂**：0.1 mol/L 强酸强碱互滴，化学计量点 pH = 7，突跃约 pH 4.3~9.7；酚酞变色 8.2~10.0、甲基橙变色 3.1~4.4，二者均落在突跃内，故都能用。【待老师核：指示剂是否由学生自选】

## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

```
[前测1][K1] 用 0.1000 mol/L NaOH 标准溶液滴定 25.00 mL 盐酸，达终点时消耗 NaOH 溶液 24.80 mL。
      该盐酸的浓度 c(HCl) 为：
A. 0.09920 mol/L
B. 0.1008 mol/L
C. 0.0992 mol/L
D. 0.1000 mol/L
答案：A
解析：化学计量点时 c(NaOH)·V(NaOH) = c(HCl)·V(HCl)，
      c(HCl) = 0.1000 × 24.80 ÷ 25.00 = 0.09920 mol/L。
      有效数字由 24.80 与 25.00 各 4 位共同决定，结果取 4 位；
      C 少一位属丢失准确度信息，B 把比值倒过来了。
```

```
[前测2][A1] 配制 0.1 mol/L 盐酸时，稀释浓盐酸的正确做法是：
A. 将水沿烧杯内壁缓缓倒入盛有浓盐酸的烧杯中，边加边搅拌
B. 在通风橱内、戴护目镜与手套，将浓盐酸沿壁缓慢注入水中，边加边搅拌
C. 在开放台面快速混合后立即盖住瓶口，减少酸雾逸出
D. 先分别量好浓盐酸与水的体积，再同时倒入烧杯
答案：B
解析：浓盐酸 ρ = 1.19 g/mL > 水，若"水入酸"，水浮在上层，
      溶解热（约 −75 kJ/mol HCl）集中在水层，局部瞬间过热并促使 HCl 急剧逸出，
      形成酸雾与液滴喷溅。必须"酸入水、沿壁、缓慢、搅拌"，并在通风橱内戴护目镜操作。
      C 未控温也未在通风橱内，D 等同随机混合，都会造成局部过热。
```

```
[前测3][K2] 滴定管最小分度为 0.1 mL。某次读数时，凹液面最低点位于 24.8 mL 刻度线下方约
      五分之二小格处，正确记录为：
A. 24.8 mL
B. 24.84 mL
C. 24.80 mL
D. 24.840 mL
答案：B
解析：滴定管读数须估读到最小分度的 1/10，即 0.01 mL，且必须记到小数点后两位。
      24.8 + 0.04 = 24.84 mL。A 少记一位、C 把估读当 0、D 多记一位（虚假精度）。
```

```
[后测1][K1] 用 0.2000 mol/L 盐酸滴定 20.00 mL 氢氧化钠溶液，达终点时消耗盐酸 19.60 mL。
      该 NaOH 溶液的浓度为：
A. 0.1960 mol/L
B. 0.2041 mol/L
C. 0.196 mol/L
D. 0.2000 mol/L
答案：A
解析：c(NaOH) = c(HCl)·V(HCl) ÷ V(NaOH) = 0.2000 × 19.60 ÷ 20.00 = 0.1960 mol/L。
      滴定方向反过来不影响计量关系，仍按"浓度 × 体积 = 浓度 × 体积"列式；
      B 是取倒数（0.2000 × 20.00 ÷ 19.60）的错误结果，C 位数不足。
```

```
[后测2][A1] 关于 0.1 mol/L NaOH 溶液的配制与保存，下列说法正确的是：
A. 应盛放在玻璃细口瓶中并配玻璃磨口塞，便于长期保存
B. 应盛放在聚乙烯瓶中，用橡胶塞或塑料螺纹盖，并贴标签注明浓度与日期
C. 碱式滴定管装碱前不必检查橡胶管与玻璃珠，只要不漏就行
D. 皮肤沾上碱液后，先用稀盐酸中和再用水冲洗
答案：B
解析：2NaOH + SiO₂ → Na₂SiO₃ + H₂O，碱液会腐蚀玻璃磨口使其黏结、瓶塞打不开，
      故碱液必须用聚乙烯瓶保存、用碱式滴定管量取（橡胶管+玻璃珠，用前须检查老化与卡阻）。
      D 尤其危险：酸碱中和放热，会加重组织损伤，正确做法是立即大量流水冲洗 ≥15 min 并报告。
```

```
[后测3][K2] 某次滴定初读数为 0.02 mL，终读数为 23.10 mL，消耗体积应记为：

```

      若实验室只剩 20.00 mL 移液管，且必须在 3 学时内给出 c(NaOH)/c(HCl)，请说明：
      ①你会改哪些参数（移取体积、指示剂、滴定方向、平行次数）；
      ②哪些量随之改变、哪些不变；
      ③若改用甲基橙，终点消耗体积会偏大还是偏小，为什么？
      （开放作答，AI 按"换算是否正确 + 不变量是否说清 + 误差方向是否判对"三点评估）
参考要点：①移取体积改为 20.00 mL，消耗 NaOH 体积按比例降至约 20.16 mL（仍在 50 mL 量程内，
      无需换管），指示剂仍用酚酞，平行次数不得少于 3 次（不能因赶时间减到 1 次）。

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`
- 终点/结果分档（以三次平行相对极差与该组浓度比相对参考值的偏差两项取较差者计）：
  - 相对极差 ≤0.2% 且比值偏差 ≤0.5% → 满分
  - 相对极差 0.2%~0.4%，或比值偏差 0.5%~1.0% → −5
  - 相对极差 0.4%~1.0%，或比值偏差 1.0%~2.0% → −15
  - 相对极差 >1.0% → 报告分不超过 60
- 报告分：数据完整性 30% + 计算正确 30% + 误差分析 20% + 安全复盘 20%
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）
- L4 触发即终止本次实验：操作分记 0，须完成安全复盘并重做。

3. **反向滴定**：改为用 HCl 滴定 NaOH（锥形瓶内放碱、滴定管装酸）时，指示剂、终点颜色变化方向、以及"碱液在锥形瓶中吸收 CO₂"带来的误差方向分别如何改变？请学生给出更换后的完整方案与理由。
