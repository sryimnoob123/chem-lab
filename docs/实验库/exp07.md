## 2. 实验目的（三维，每条可判定）

- **知识**：能写出分组分离所依据的溶度积判据、两性氢氧化物溶解反应与氨配离子生成反应；能说明 Na⁺ 黄色焰色为什么必须隔蓝色钴玻璃才能判定 K⁺；能解释为什么在 NH₄⁺ 存在下 Mg²⁺ 不与 CO₃²⁻ 共沉淀。
- **技能**：能独立完成"分组沉淀—离心—离心取液—溶解—特征鉴定"全流程，10 个离子的特征现象（焰色、沉淀颜色、溶液颜色）与教材判据一致，检出结论全对；离心后上清液不得夹带沉淀（目视澄清）。
- **素养**：能说出银氨溶液**不得久置、不得加热蒸干**的原因并当场用酸破坏；能说清含银、含汞、含六价铬三类废液各自的去向，并按类分装、贴签。

## 3. 原理（≤150 字 + 关键公式）

阳离子鉴定靠特征反应（焰色、特征颜色沉淀、特征颜色配离子）。混合体系中凭溶解度、两性与配位能力的差异**逐级分组**：每组沉淀一种、其余留在液相，用离心取液实现固液分离，再对分离后的部分做专一性鉴定。干扰不靠"多做几遍"，而靠控制介质酸度、加入配位掩蔽剂、或改变分离顺序来排除。

```
分组判据：J = c(Mᵐ⁺) · c(Aⁿ⁻)ᵐ > Ksp 即析出沉淀
两性分离：Al(OH)₃(s) + OH⁻ → [Al(OH)₄]⁻（Fe(OH)₃ 不溶于过量 NaOH）
氨配位：Cu²⁺ + 4NH₃ ⇌ [Cu(NH₃)₄]²⁺（深蓝，λmax ≈ 610 nm）
铬酸根形态：2CrO₄²⁻ + 2H⁺ ⇌ Cr₂O₇²⁻ + H₂O   K ≈ 4.3×10¹⁴
银氨破坏：[Ag(NH₃)₂]⁺ + Cl⁻ + 2H⁺ → AgCl↓ + 2NH₄⁺
雷爆银：2Ag₃N(s) → 6Ag + N₂↑（撞击/摩擦/受热起爆）
```

变量：c 为平衡浓度（mol·L⁻¹）；m 为阳离子电荷数；Ksp 为溶度积（25 ℃，待老师核）；λmax 为最大吸收波长（nm）。

| 难溶物 | Ksp | 难溶物 | Ksp |
|---|---|---|---|
| AgCl | 1.8×10⁻¹⁰ | BaCrO₄ | 1.2×10⁻¹⁰ |
| Ag₂CO₃ | 8.5×10⁻¹² | CaCrO₄ | 7.1×10⁻⁴ |
| MgCO₃ | 6.8×10⁻⁶ | CaC₂O₄ | 2.3×10⁻⁹ |

| CaCO₃ | 3.4×10⁻⁹ | Al(OH)₃ | 1.3×10⁻³³ |

> 翻译约定：本实验不涉及 `weigh`/`titrate`/`evaporate`/`filter`/`calibrate`；固液分离统一用 `centrifuge` + `transfer`（离心取液），不引入常压过滤，与实验 04 保持一致；`addDrops` 承担全部滴加、酸化复析与回检；`readInstrument` 承担离心机参数设定与离心管刻度读数；焰色与颜色判别统一用 `observe`；`dissolve` 用于沉淀在 HAc/HCl/NaOH 中的溶解；`heat` 仅用于步 6 的"微热赶 CO₂"，**其余步骤一律不加热**（银氨溶液禁止加热是 H5 的核心）。

## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

```
[前测1][K1] 在 Al³⁺ 与 Fe³⁺ 的混合液中，加入过量 NaOH 溶液并离心，下列判断正确的是：
A. Al³⁺ 与 Fe³⁺ 都转入溶液，因为 NaOH 是强碱
B. Al³⁺ 转入溶液、Fe³⁺ 留在沉淀，因为 Al(OH)₃ 具有两性
C. Fe³⁺ 转入溶液、Al³⁺ 留在沉淀，因为 Fe(OH)₃ 的 Ksp 更大
D. 两者都留在沉淀，必须再加氨水才能分离
答案：B
解析：Al(OH)₃ 是两性氢氧化物，OH⁻ 过量时生成可溶的 [Al(OH)₄]⁻ 而溶解；Fe(OH)₃ 不具两性，Ksp 仅 2.8×10⁻³⁹，始终留渣。
A 忽略了两性；C 把 Ksp 大小与"能否溶于碱"混为一谈，Fe(OH)₃ 的 Ksp 更小反而更难溶；D 与事实相反，氨水会把两者一起沉淀。
```

```
[前测2][A1] 用氨水把 AgCl 沉淀溶解得到澄清的银氨溶液后，正确的处置是：
A. 留到实验结束与其他废液一起倒掉
B. 加热浓缩或蒸干，回收其中的银
C. 立即加 HNO₃ 酸化破坏配离子，随即倒入含银废液桶
D. 加过量蒸馏水稀释后倒入水槽
答案：C
解析：银氨配离子久置或受热会生成 Ag₃N（雷爆银）等爆炸性银化物，对摩擦、撞击、受热极敏感，干燥过程会使其敏感度进一步升高，曾多次造成试管爆裂伤人。
A 是"久置"路径；B 同时触发"受热"与"干燥"两条最危险路径；D 只是稀释，Ag⁺ 总量不变，仍属重金属污染。
```

```
[前测3][S1] 10 mL 离心管的最小分度为 0.1 mL。离心后液面凹面最低点位于 4.6 与 4.7 两条刻线之间、距 4.6 约十分之三格，正确记录为：
A. 4 mL
B. 4.6 mL
C. 4.63 mL
D. 4.630 mL
答案：C
解析：仪器读数应估读到最小分度的下一位，分度 0.1 mL → 估读到 0.01 mL，得 4.63 mL（3 位有效数字）。
A、B 未估读；D 多估了一位，离心管刻度达不到 0.001 mL 的精度。
```

```
[后测1][K1] 某混合液含 Cu²⁺ 与 Zn²⁺。欲用一次"沉淀—离心取液"操作把两者分开，下列方案可行的是：
A. 加过量氨水：Cu²⁺ 与 Zn²⁺ 分别生成深蓝色与无色的氨配离子，两者都留在液相
B. 加过量 NaOH：Cu²⁺ 成 Cu(OH)₂ 沉淀留渣，Zn²⁺ 成 [Zn(OH)₄]²⁻ 转入液相
C. 加过量 3 mol·L⁻¹ HCl：两者都以氯配离子形式留在液相
D. 加过量 Na₂CO₃：两者都成碳酸盐沉淀，仍混在一起
答案：B
解析：Zn(OH)₂ 具两性，过量 NaOH 中生成可溶的 [Zn(OH)₄]²⁻；Cu(OH)₂ 不具两性，在稀 NaOH 中不溶，一沉一留即可分开。
A 是最常见的错误思路——氨水对两种离子都能配位，颜色不同只能用于**鉴定**，不能用于**分离**（两者同在液相，离心分不开）；本题把它放在 A 位，考的正是"能显色 ≠ 能分离"。
C 中 Cu²⁺、Zn²⁺ 与 Cl⁻ 的配位很弱，实际仍以水合离子留液，也不分开；D 生成碱式碳酸盐混合沉淀。
```

```

```
[迁移][K1/S1] 若在本实验的混合试液中再加入 0.10 mol·L⁻¹ Pb²⁺（PbCl₂ 的 Ksp = 1.6×10⁻⁵，PbCrO₄ 的 Ksp = 2.8×10⁻¹³，Pb(OH)₂ 具两性），请回答：
(1) 步 3 加 HCl 沉 AgCl 时，Pb²⁺ 会不会一起沉淀？对 Ag⁺ 的判定有什么影响？
(2) 步 6 用 K₂CrO₄ 检 Ba²⁺ 时，会不会出现假阳性？
(3) 你的方案要改哪几步、加什么试剂？请写出改后的分离顺序，并说明每一步靠什么判据。
评分要点：
(1) 会部分沉淀。n(Pb²⁺) = 1.0×10⁻⁴ mol，总体积约 1.15 mL 时 c(Pb²⁺) ≈ 0.087 mol·L⁻¹，
    J = 0.087 × (0.30)² = 7.8×10⁻³ ≫ Ksp(PbCl₂) = 1.6×10⁻⁵，故 PbCl₂ 白色沉淀与 AgCl 同时析出。
    影响：步 3 的"白色沉淀"不再专属于 Ag⁺；且 PbCl₂ **不溶于氨水**，加氨水后 AgCl 溶尽而 PbCl₂ 仍留白色残渣，学生会误以为"AgCl 没溶完"而继续加氨水，随后酸化的"白色复析"也无法单独证明 Ag⁺。
(2) 会。PbCrO₄ 黄色（Ksp 2.8×10⁻¹³）比 BaCrO₄ 更难溶，步 6 的黄色沉淀无法区分 Ba²⁺ 与 Pb²⁺，直接判 Ba²⁺ 即假阳性。
(3) 改法（任一条成立即给分）：
    ① 步 3 改用**稀 HCl 加热**沉 AgCl，热态离心取液：PbCl₂ 溶解度随温度上升明显（25 ℃ 约 0.03 mol·L⁻¹，100 ℃ 约 0.12 mol·L⁻¹），热离心可把 Pb²⁺ 留在液相、AgCl 留渣；冷后需回检滤液是否析出白色针状结晶（若析出即 Pb²⁺ 未除净）。
    ② 在步 6 之前插入"除铅"步：先加 H₂SO₄ 沉 PbSO₄（Ksp 1.6×10⁻⁸）——但 BaSO₄（1.1×10⁻¹⁰）更难溶，会与 PbSO₄ 一起沉掉，因此**必须在除铅之前先完成 Ba²⁺ 的分离**，顺序一旦颠倒，Ba 的判据就永久丢失。这条能答出来即说明理解了"分组顺序由 Ksp 决定"。
    ③ 利用两性差异：步 4 的过量 NaOH 中 Pb²⁺ 与 Al³⁺ 一同转入液相（[Pb(OH)₄]²⁻），Ba²⁺ 不成羟基配离子、仍留在碳酸盐组，于是 Pb 与 Ba 天然分开；随后对液相用 HAc 调 pH 后加 K₂CrO₄，黄色 PbCrO₄ 与 Ba 无关。这是最省步骤的方案（属加分项）。
    判据要写清：每一步都以"沉淀是否完全 + 上清液回检 + 特征现象专一性"三者共同支撑，不能只凭一种颜色下结论。

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`；L4 触发即终止，操作分记 0 并强制安全复盘。
- 结果分档（以 10 个离子的检出结论为准，正确结论以 §6 判据逐条核对）：
  - 10 个离子全对，且每个结论都有原始现象支撑：满分
  - 错 1 个（或现象记录缺 2 项以内）：−5
  - 错 2~3 个，或分组顺序正确但某步离心取液夹带沉淀：−15
  - 错 ≥4 个，或分组失败需重做：−25
- 结构性校验（不通过即按 L2 计，不重复扣分）：
  - 步 2 洗丝后空白焰色近无色（否则焰色结论不计分）；
  - 步 3 银氨溶液在酸化后 1 min 内倒入废液桶；
  - 步 5 上清液加 Na₂HPO₄ 得白色沉淀（证明 Mg²⁺ 未被共沉）；
  - 步 6 HAc 介质 pH 在 2.0~3.5 区间（偏低说明 HAc 加少了、偏高说明缓冲不足）；
  - 三类废液零混装、标签齐全。
- 报告分：数据完整性 30%（§8 全部字段，含 pH、滴数、时刻）+ 计算正确 30%（步 6 的 c(CrO₄²⁻) 与 Ba/Ca 沉淀判据、AgCl 理论质量）+ 误差分析 20%（能说出"为什么必须加 NH₄Cl""为什么用 HAc 不用 H₂SO₄""为什么 K⁺ 必须隔钴玻璃"中的至少 2 项）+ 安全复盘 20%（能复述 H5 的成因与"用完即毁"做法、H15 的三类废液去向）。
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）。

## 11. AI 评估要点（举一反三）

1. **改分离顺序**：学生把"(NH₄)₂CO₃ 沉碱土"提到"HCl 沉银"之前，问"会怎样"。评估要点是能否意识到 Ag⁺ 会以 Ag₂CO₃（Ksp 8.5×10⁻¹²）进入碱土沉淀，导致步 6 的黄色 BaCrO₄ 中混入 Ag₂CrO₄ 砖红、颜色判断失效；并能否说出"分组顺序由各组的溶解度差异决定，先沉谁后沉谁不是习惯问题"。加分点：主动指出若试液含 Pb²⁺，同样要重新排序。
2. **改 K₂CrO₄ 介质酸度**：学生把 HAc 换成 1 mol·L⁻¹ HCl，问"黄色沉淀还出得来吗、Ca 会不会跟着沉"。评估要点是能否用 α(CrO₄²⁻) = Ka₂/([H⁺]+Ka₂) 定量算：pH 由 2.3 降到 0 时 c(CrO₄²⁻) 下降约 2 个数量级，BaCrO₄ 仍可沉（判据余量够）但 CaCrO₄ 离析出更远，结论是"现象不变、判据更不灵敏"；若进一步加热，则 Cr(VI) 氧化 Cl⁻ 放 Cl₂，属安全越界。能区分"技术可行"与"该不该做"是加分点。
3. **改离子浓度**：把 Ag⁺ 从 0.10 mol·L⁻¹ 降到 0.010 mol·L⁻¹，问"银氨溶液的危险性变大还是变小"。评估要点是能否指出风险主要不取决于浓度而取决于**是否久置/加热/蒸干**——稀溶液同样会生成 Ag₃N，只是绝对量少；同时要意识到 AgCl 沉淀量降至 1.4 mg，步 3 的"白色复析"判据变弱，需靠延长静置或离心富集。只答"浓度低所以更安全"是危险答案。
