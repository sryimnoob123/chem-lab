## 2. 实验目的（三维，每条可判定）

- **知识**：能写出 Na₂CO₃ 标定 HCl 与双指示剂法两步滴定的计量关系式，并说明 V₁ 与 V₂ 的大小关系分别对应 NaOH、Na₂CO₃、NaHCO₃ 的哪一种组成。
- **技能**：能独立完成 3 份平行标定与 3 份平行双指示剂滴定，使 c(HCl) 的相对平均偏差 ≤0.3%、总碱度（以 Na₂CO₃ 计）与教师参考值的相对误差 ≤0.5%（待老师核基准与容差）。
- **素养**：能说出浓盐酸必须在通风橱内稀释、移液管严禁口吸的两条硬规矩，并在酸液溅到皮肤、热锥形瓶炸裂两种情形下按"先冲洗/先遮挡、再报告"的顺序正确处置。

## 3. 原理（≤150 字 + 关键公式）

HCl 不能直接配成准确浓度（浓盐酸挥发性强、含量不定），只能先配近似浓度再用基准物质标定。无水 Na₂CO₃ 纯度高、稳定、摩尔质量大，是最常用的基准物质；以甲基橙为指示剂滴至橙色，碳酸根被完全中和。

  Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
  c(HCl) = 2m(Na₂CO₃) / [M(Na₂CO₃) · V(HCl)]，M = 105.99 g·mol⁻¹

工业纯碱是 Na₂CO₃ 与少量 NaOH / NaHCO₃ / NaCl 的混合物，用**双指示剂法**分两步滴定：

  第一终点（酚酞，pH≈8.3）：Na₂CO₃ + HCl → NaHCO₃ + NaCl，耗 V₁
  第二终点（甲基橙，pH≈4.0）：NaHCO₃ + HCl → NaCl + H₂O + CO₂↑，耗 V₂

判读：V₁ = V₂ 只含 Na₂CO₃；V₁ > V₂ 含 NaOH，n(NaOH)=c·(V₁−V₂)；V₂ > V₁ 含 NaHCO₃，n(NaHCO₃)=c·(V₂−V₁)。总碱度一律以 Na₂CO₃ 计：

  w = [c(HCl) · (V₁+V₂)/2 · M(Na₂CO₃)] / [m(试样) · 25.00/250.0] × 100%

变量：c 为 HCl 标准液浓度（mol·L⁻¹）；m 为称样质量（g）；V₁、V₂ 为两终点消耗体积（mL）；w 为质量分数（%）。

## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

```
[前测1][K1] 称取 0.1500 g 已在 280 ℃ 干燥过的无水 Na₂CO₃，溶于水后以甲基橙为指示剂，滴至橙色时耗去 HCl 溶液 28.30 mL。c(HCl) 为（M(Na₂CO₃)=105.99 g·mol⁻¹）：
A. 0.1000 mol·L⁻¹
B. 0.05000 mol·L⁻¹
C. 0.2000 mol·L⁻¹
D. 0.100 mol·L⁻¹
答案：A
解析：Na₂CO₃ 与 HCl 的计量比为 1:2，c=2m/(M·V)=2×0.1500/(105.99×0.02830)=0.3000/2.9995=0.1000 mol·L⁻¹。
B 漏掉了计量比中的 2（按 1:1 算），C 把乘 2 当成了除 2，D 数值对但只有三位有效数字——m 与 V 都是四位，c 必须报四位。
```

```
[前测2][A1] 由 37% 浓盐酸配制 1000 mL 约 0.1 mol·L⁻¹ 的 HCl 溶液，下列做法正确的是：
A. 在实验台用移液管吸取浓盐酸，直接放入容量瓶后再加水至刻度
B. 在通风橱内戴护目镜与手套，用量筒量取浓盐酸后沿壁缓缓加入水中，搅拌、稀释至刻度
C. 先把水加到容量瓶刻度，再把浓盐酸沿壁加入
D. 在通风橱内把水沿壁加入盛有浓盐酸的烧杯
答案：B
解析：浓盐酸蒸气压高，敞口即持续逸出 HCl 气体，必须在通风橱内操作并戴护目镜；稀释时"酸入水、沿壁、边加边搅"，避免局部过热和飞溅。
A 既不在通风橱、又违反酸入水；C 顺序错——浓盐酸直接加进容量瓶难以混匀、局部浓度过高，正确做法是先在烧杯中稀释、冷却后再转移定容；D 虽在通风橱但顺序仍是"水入酸"，且浓酸先受热更易逸出。
```

```
[前测3][S2] 用 50 mL 酸式滴定管滴定，读取初读数时俯视、读取终读数时仰视，则算得的消耗体积 V=V终−V初 将：
A. 偏大
B. 偏小
C. 无影响
D. 无法判断
答案：A
解析：滴定管刻度自上而下增大。俯视时视线与刻度的交点落在凹液面实际位置的上方，对应数值偏小，故 V初 偏小；仰视时交点落在下方，V终 偏大。V=V终−V初 因此偏大。
B 是把量筒（刻度自下而上）的结论套到滴定管上；C 忽略了系统性的视差方向；D 方向其实可以判定。
```

```
[后测1][K1] 用 HCl 标准液对某工业纯碱试液做双指示剂法滴定，酚酞终点耗 V₁=15.20 mL，甲基橙终点又耗 V₂=15.20 mL。该试样中碱的组成是：
A. 只含 Na₂CO₃
B. 含 NaOH 与 Na₂CO₃
C. 含 Na₂CO₃ 与 NaHCO₃
D. 只含 NaHCO₃
答案：A
解析：Na₂CO₃ 先被中和到 NaHCO₃（耗 V₁），NaHCO₃ 再被中和到 H₂CO₃（耗 V₂），纯 Na₂CO₃ 两段等量，故 V₁=V₂。
若 V₁>V₂，多出的 V₁−V₂ 对应 NaOH（B）；若 V₂>V₁，多出的 V₂−V₁ 对应原有 NaHCO₃（C）；纯 NaHCO₃ 在第一终点前不显酚酞红色，V₁≈0（D）。
```

```
[后测2][A1] 标定时少量浓盐酸溅到前臂皮肤上，最恰当的处置顺序是：
A. 先用 NaHCO₃ 溶液中和，再用水冲
B. 立即用大量流水冲洗 ≥15 min，脱去污染衣物，同时呼叫老师并报告

D. 用纸巾擦净后继续滴定，实验结束后再处理
答案：B
解析：化学灼伤的第一原则是"稀释与移除"——大量流水既稀释酸又带走残余，冲洗越早越充分，损伤越轻；随后报告以便判断是否需要就医。
A 中和反应本身放热，会加重组织损伤且延误冲洗；C 干擦扩大损伤面、油脂封闭创面；D 延误处置，酸在皮肤上持续作用。

```

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`；L4 触发即终止，操作分记 0 并强制安全复盘。
- 标定平行性分档（相对平均偏差，3 份）：
  - ≤0.3%：满分
  - 0.3%~0.6%：−5
  - >0.6%：−15
- 结果误差分档（总碱度 w 与教师参考值的 |相对误差|，参考值待老师核）：
  - ≤0.5%：满分
  - 0.5%~1.5%：−5
  - >1.5%：−15
- 结构性校验（不通过即按 L2 计，不重复扣分）：标定必须 3 份且含煮沸驱 CO₂ 记录；双指示剂必须给出 V₁ 与 V₂ 两个独立读数；组分判断必须与 V₁/V₂ 的大小关系一致；w 必须乘 250.0/25.00 的稀释倍数。
- 报告分：数据完整性 30%（3 份标定 + 3 份滴定、室温、干燥条件、有效数字位数齐全）+ 计算正确 30%（c(HCl)、w、组分解析、偏差计算）+ 误差分析 20%（能说出称量吸湿、CO₂ 未驱尽、指示剂用量、读数视差中的至少 2 项）+ 安全复盘 20%（能复述 H1/H2 的处置与 H3/H4 的预防）。
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）。
- 设计分加成（本实验为设计性质，待老师核是否启用）：学生自行推算的浓盐酸体积、称样量区间、平行份数若在合理范围内，报告分 +5；若照抄示例数据，该项不计。

## 11. AI 评估要点（举一反三）

1. **换基准物质**：学生把无水 Na₂CO₃ 换成硼砂或邻苯二甲酸氢钾时，评估要点不是"能不能算"，而是能否由"计量比 + 目标消耗体积 20~35 mL + 天平精度"反推出合理的称样量，并识别硼砂含结晶水、需控制干燥温度（≤60 ℃ 或保干器保存）这一隐藏条件。
2. **换试样组成**：学生把试样改成 NaOH+Na₂CO₃ 混合碱后，V₁>V₂ 时若仍套用 `c(V₁+V₂)/2` 报"Na₂CO₃ 含量"，会把 NaOH 折算进 Na₂CO₃ 里——评估要点是能否区分"以 Na₂CO₃ 计的等效总碱度"与"真实 Na₂CO₃ 含量"，以及是否在报告里说明口径。
3. **换指示剂**：用溴甲酚绿-甲基红替代甲基橙、或第一终点改用百里酚蓝时，评估要点是变色范围与化学计量点的匹配度、以及"终点颜色描述"是否随之改写；若学生只换指示剂却不改判据文案，视为方案未闭环。
