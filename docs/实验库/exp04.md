## 2. 实验目的（三维，每条可判定）

- **知识**：能写出沉淀溶解平衡式与 Ksp 表达式，用 J 与 Ksp 的大小判断沉淀生成或溶解，并说明生成弱电解质、生成配离子、转化为更难溶盐三条溶解路径各自降低了什么离子的浓度。
- **技能**：能独立完成"沉淀—离心—洗涤—溶解—转化"全流程，AgCl 沉淀洗至末次洗液加 AgNO₃ 无浑浊，分步沉淀中先黄（AgI）后白（AgCl）的顺序可复现，实测滴数与理论值（10 / 20 滴）偏差 ≤2 滴。
- **素养**：能说出离心机配平与浓氨水必须在通风橱操作的规范，并在离心管破裂、含银废液处置两种情形下正确应对。

## 3. 原理（≤150 字 + 关键公式）

难溶电解质溶液中，离子浓度幂之积 J 与溶度积 Ksp 比较决定沉淀生成（J > Ksp）或溶解（J < Ksp）。降低任一构晶离子浓度即可使平衡右移——生成弱电解质、生成配离子或转化为更难溶的沉淀，都是"抽走离子"的三条路径。分步沉淀时，所需沉淀剂浓度越小者先析出；两种沉淀 Ksp 相差足够大时可完全分离。

```
J = c(Mᵐ⁺)ᵃ · c(Aⁿ⁻)ᵇ          与 Ksp 同式，取平衡值
转化：AgCl(s) + I⁻ ⇌ AgI(s) + Cl⁻        K = Ksp(AgCl) / Ksp(AgI)
配位溶解：AgCl(s) + 2NH₃ ⇌ [Ag(NH₃)₂]⁺ + Cl⁻   K = Ksp(AgCl) · β₂
分步沉淀：开始沉淀所需 c(Ag⁺) = Ksp / c(卤离子)
```

变量：c 为平衡浓度（mol·L⁻¹）；a、b 为沉淀溶解方程式中离子的化学计量数；β₂ 为配离子的累积稳定常数（无量纲）；K 为转化/溶解反应的标准平衡常数（无量纲，>10⁵ 视为能进行到底）。

25 ℃ 常用数据（待老师核，以教材附录为准）：

| 难溶物 | Ksp | 难溶物 | Ksp |
|---|---|---|---|
| AgCl | 1.8×10⁻¹⁰ | Mg(OH)₂ | 5.6×10⁻¹² |
| AgBr | 5.0×10⁻¹³ | BaSO₄ | 1.1×10⁻¹⁰ |
| AgI | 8.5×10⁻¹⁷ | BaCO₃ | 5.1×10⁻⁹ |
| Ag₂CrO₄ | 1.1×10⁻¹² | β₂[Ag(NH₃)₂]⁺ | 1.1×10⁷ |

代入即得：AgCl→AgI 转化 K = 1.8×10⁻¹⁰ / 8.5×10⁻¹⁷ ≈ 2.1×10⁶（能进行）；配位溶解 K = 1.8×10⁻¹⁰ × 1.1×10⁷ ≈ 2.0×10⁻³（偏小，须用较浓氨水并过量）；Mg(OH)₂ 溶于 NH₄Cl 的 K = Ksp / Kb²(NH₃·H₂O) = 5.6×10⁻¹² / (1.8×10⁻⁵)² ≈ 1.7×10⁻²（可行，需较浓 NH₄Cl）。

| exp04-H11 | 用 2.0 mol·L⁻¹ NaCl 代替 NH₄Cl 去溶解 Mg(OH)₂ | L1 | — | 无弱电解质生成，Cl⁻ 也不沉淀 Mg²⁺，只发生同离子效应，平衡不移动 | 沉淀不溶，误判"Mg(OH)₂ 不溶于盐溶液"，结论错误但数据未废 | 用 NH₄Cl：NH₄⁺ + OH⁻ → NH₃·H₂O 使平衡右移 | — | 3 |
| exp04-H12 | 含 Ag⁺、AgI 的废液与沉淀直接倾入水槽 | L3 | `heavy-metal` | Ag⁺ 对水生生物剧毒（μg·L⁻¹ 级即有毒性），AgI 虽难溶但长期可缓慢释放，且酸性废液会促溶 | 污染下水与水体，违反危废管理规定，需上报处置 | 全部含银液与沉淀倒入重金属废液桶，交有资质单位回收 | S011 | 9 |

**视觉键**（与 `lib/safety/fx.ts` 对齐）：`boil-over` `explosion` `toxic-gas` `burn` `glass-break` `fire` `heavy-metal` `device-accident`

> 本实验只启用 `glass-break`（H1）、`device-accident`（H4）、`toxic-gas`（H8）、`heavy-metal`（H12）四个键；`boil-over`/`explosion`/`burn`/`fire` 不启用——本实验无加热、无易燃物，硬造爆燃事故会失真。
> L4 唯一入口是 H4，且它是"离心分离"这一步的**自然后果**（学生手上恰好只有一支装样管时最容易发生），不依赖任何外部巧合。

## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

```
[前测1][K1] 25 ℃ 时 Ksp(AgCl)=1.8×10⁻¹⁰、Ksp(AgBr)=5.0×10⁻¹³。向 c(Cl⁻)=c(Br⁻)=0.10 mol·L⁻¹ 的混合液中逐滴加入 AgNO₃，首先析出的是：
A. AgCl，因为它的 Ksp 数值更大
B. AgBr，因为它开始沉淀所需的 c(Ag⁺) 更小
C. 两者同时析出，因为 c(Cl⁻)=c(Br⁻)
D. 无法判断，需知道 AgNO₃ 的加入速度
答案：B
解析：开始沉淀所需 c(Ag⁺)=Ksp/c(卤离子)。AgBr 需 5.0×10⁻¹²，AgCl 需 1.8×10⁻⁹，前者低约 360 倍，故先达到 Ksp。
A 把"Ksp 大"误当"先沉淀"；C 忽略了 Ksp 差异；D 混淆了"先后顺序"（由 Ksp 决定）与"混合程度"（由操作决定）。
```

```
[前测2][A1] 离心前发现只有一支离心管装了样品，正确做法是：
A. 时间短，单管离心无妨
B. 在转子对称孔放一支装等量蒸馏水的离心管配平后离心
C. 把样品管尽量靠近转子中心放置
D. 用手按住离心机机身再启动
答案：B
解析：转子高速旋转时，质量偏心会产生与转速平方成正比的离心力矩，轻则剧烈振动移位，重则转子与轴承损毁、离心管甩出。
A、C 没有消除不平衡；D 是用手对抗数百倍自重的力，只会让伤害落到人身上。
```

```
[前测3][S1] 10 mL 离心管最小分度为 0.1 mL，液面凹面最低点位于 3.4 与 3.5 两条刻线正中间，正确记录为：
A. 3 mL
B. 3.4 mL
C. 3.45 mL
D. 3.450 mL
答案：C
解析：仪器读数应估读到最小分度的下一位，分度 0.1 mL → 估读到 0.01 mL，得 3.45 mL（3 位有效数字）。
A、B 未估读；D 多估了一位，离心管达不到 0.001 mL 的精度。
```

```
[后测1][K1] 已知 Ksp(BaSO₄)=1.1×10⁻¹⁰、Ksp(BaCO₃)=5.1×10⁻⁹。向 c(SO₄²⁻)=c(CO₃²⁻)=0.010 mol·L⁻¹ 的混合液中逐滴加 BaCl₂，下列判断正确的是：
A. BaCO₃ 先沉淀，因为它的 Ksp 更大
B. BaSO₄ 先沉淀，所需 c(Ba²⁺)=1.1×10⁻⁸ mol·L⁻¹
C. 两者同时沉淀，因浓度相同
D. BaSO₄ 先沉淀，且沉淀完全时 BaCO₃ 一定还未开始沉淀
答案：B
解析：所需 c(Ba²⁺) 分别为 1.1×10⁻⁸（BaSO₄）与 5.1×10⁻⁷（BaCO₃），BaSO₄ 先析出。
A 方向反了；D 结论下得太早——本题 Ksp 只差 46 倍，SO₄²⁻ 沉淀完全（≤10⁻⁵）时所需 c(Ba²⁺)=1.1×10⁻⁵ 已高于 BaCO₃ 的起始值 5.1×10⁻⁷，两者会重叠，不能完全分离。这正是"Ksp 差得不够大就分不开"的判据。
```

```
[后测2][A1] 实验结束，台面上有：①含 Ag⁺ 与 AgI 沉淀的离心管残液 ②用过的 KI 溶液 ③清洗后的空管。正确处置是：
A. ①倒入水槽冲走，②③正常清洗
B. ①连同沉淀倒入重金属废液桶，②按含碘废液回收或交教师，③清洗沥干
C. ①加大量水稀释后倒入水槽
D. ①静置取上清液倒掉，沉淀留在管内晾干
答案：B
解析：Ag⁺ 属重金属污染物，即使稀释也不改变总量，必须按危废分类回收；含 I⁻ 废液氧化后可能析出 I₂，也应单独收集。
A、C 都是把污染物转移给下水；D 把沉淀留在敞口管内，干燥后扬尘且后续无人处置。
```

```
[后测3][S1] 用最小分度为 0.5 mL 的 10 mL 刻度离心管量取蒸馏水，液面在 4.0 与 4.5 之间、偏向 4.0 一侧约五分之一处。正确记录为：
A. 4 mL
B. 4.1 mL
C. 4.10 mL
D. 4.25 mL
答案：B
解析：分度 0.5 mL 只能估读到 0.1 mL，读到 4.1 mL（2 位有效数字）。
A 未估读；C 多估一位；D 把"正中间"当成了题目给的 1/5 处，读数位置判断错误。
```

```
[迁移][K2/S2] 若把本实验的"Cl⁻ / I⁻ 分步沉淀"改成莫尔法体系"Cl⁻ / CrO₄²⁻"（K₂CrO₄ 作指示剂，Ksp(AgCl)=1.8×10⁻¹⁰、Ksp(Ag₂CrO₄)=1.1×10⁻¹²），请回答：
(1) 谁先沉淀？砖红色 Ag₂CrO₄ 出现代表什么？
(2) 要保证 AgCl 沉淀完全（[Cl⁻]≤1.0×10⁻⁵ mol·L⁻¹）之后才出现砖红色，c(CrO₄²⁻) 应控制在什么范围？请写出推导。
(3) 你的方案要改哪些试剂与步骤？如果把 Cl⁻ 换成 Br⁻，还适用吗？
评分要点：
(1) AgCl 先沉淀；砖红色出现即 Ag⁺ 已过量、Cl⁻ 已沉淀完全，为滴定终点信号。
(2) AgCl 沉淀完全时 [Ag⁺]=1.8×10⁻¹⁰/1.0×10⁻⁵=1.8×10⁻⁵ mol·L⁻¹；
    此刻 Ag₂CrO₄ 刚开始沉淀要求 [Ag⁺]²·c(CrO₄²⁻)=Ksp，
    即 c(CrO₄²⁻)=1.1×10⁻¹²/(1.8×10⁻⁵)²≈3.4×10⁻³ mol·L⁻¹，故指示剂浓度应 ≲3×10⁻³ mol·L⁻¹ 量级（经典莫尔法取 5×10⁻³ 是工程折中，终点略提前）。
    若 c(CrO₄²⁻) 过大，砖红色会在 Cl⁻ 未沉淀完全时提前出现，结果偏低。
(3) 需增加 K₂CrO₄ 指示剂、以 AgNO₃ 作滴定剂（引入 `titrate` 原语），并控制溶液 pH 6.5~10.5（酸性下 CrO₄²⁻ 转 Cr₂O₇²⁻，碱性下析出 Ag₂O）。换成 Br⁻ 仍可用莫尔法（AgBr 先沉淀、砖红为终点），但 AgBr 吸附 Br⁻ 较强、终点须充分振摇；换成 I⁻ 或 SCN⁻ 则不适用（吸附严重、终点提前），须改用法扬斯法（吸附指示剂）。
```

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`；L4 触发即终止，操作分记 0 并强制安全复盘。
- 结果分档（以理论滴数 10 / 20 滴与实际现象为准）：
  - 分步沉淀滴数与理论偏差 ≤2 滴，且先黄后白顺序正确：满分
  - 偏差 3~5 滴，或顺序正确但颜色判断模糊：−5
  - 偏差 >5 滴、顺序颠倒，或 AgCl 未洗至无 Cl⁻：−15
- 结构性校验（不通过即按 L2 计，不重复扣分）：AgCl 沉淀量达到理论值 14 mg 的目测下限（沉淀层 ≥2 mm）；末次洗液加 AgNO₃ 无浑浊；黄色沉淀加氨水不溶。
- 报告分：数据完整性 30%（§8 全部字段，含离心参数与回检记录）+ 计算正确 30%（理论滴数、氨溶耗量、转化 K、Mg(OH)₂ 溶解 K）+ 误差分析 20%（能说出"Ksp 差得不够大不能完全分离""配位 K 小需过量氨水"中的至少 2 项）+ 安全复盘 20%（能复述 H4 的配平要求与 H12 的废液去向）。
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）。

## 11. AI 评估要点（举一反三）

1. **改氨水浓度**：学生把 6 mol·L⁻¹ 改成 2.0 mol·L⁻¹，问"还能不能溶完"。评估要点是能否用 K=Ksp·β₂≈2.0×10⁻³ 反推所需游离 [NH₃]（本例约 0.74 mol·L⁻¹），意识到"浓度降到 1/3 时体系已接近溶解上限，必须加大体积或改用 Na₂S₂O₃"——而不是凭"氨水能溶 AgCl"这句口诀下结论。
2. **改卤离子配比**：把 Cl⁻ 与 I⁻ 的物质的量之比由 1:1 改成 100:1，问"先沉淀的还是 AgI 吗、白颜色会不会提前出现"。评估要点是学生会不会用 c(Ag⁺)所需 = Ksp/c(X⁻) 逐项算：I⁻ 稀释 100 倍后所需 c(Ag⁺) 上升两个数量级，但仍是 6.8×10⁻¹³ 量级，远低于 AgCl 的起始值，顺序不变；而"沉淀完全所需滴数"会变，能区分"顺序"与"滴数"两个不同问题是加分点。
3. **改溶解剂**：让学生比较 NH₃·H₂O、Na₂S₂O₃、NaCN 三种配位剂溶 AgBr 的可行性（K 分别为 5.5×10⁻⁶、约 10⁻³ 量级、约 10⁴），并要求排除 NaCN。评估要点是能否用 Ksp·β 定量排序，同时主动指出 NaCN 剧毒、遇酸产生 HCN，属于"技术上可行但绝不能选"的方案——考查安全判断压过计算结果。
