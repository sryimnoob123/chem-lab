## 2. 实验目的（三维，每条可判定）

- **知识**：能对照天平指认横梁、三棱刀口、阻尼器、秤盘、环砝码/加码杆、光学投影屏、水平泡、地脚螺栓八个部件并说出作用；能由"感量 0.1 mg + 允许相对误差 0.1%"算出最小称样量 0.2 g，说明本实验为何取 0.4~0.5 g。
- **技能**：能在 3 学时内独立完成"调水平 → 预热 → 校准 → 归零 → 固定质量法称 0.5000 g → 递减法连续称三份约 0.4 g"，固定质量偏差 ≤0.0002 g、三份相对平均偏差 ≤0.1%，原始记录当场完成且无涂改。
- **素养**：能说出天平禁止超载（Max 200 g）与"热物不称、湿物不称、腐蚀物不直接接触秤盘"三条硬规矩，并在称量瓶滑落破碎、试样洒入天平箱两种情形下正确处置与报告。

## 3. 原理（≤150 字 + 关键公式）

**称量原理**：电光天平是等臂杠杆，被称物与砝码对支点的力矩平衡；10 mg 以下的质量由光学投影屏细读。三种用法对应三种记录方式：**可变质量称量**记示数本身；**固定质量称量法**先定目标质量，再补加试样至示值符合允差；**递减法**由同一容器相邻两次示数之差求转移量，无需凑准质量，适合多份、易吸潮或易挥发的试样。

**关键公式**：

- 递减法单份质量 m = m₁ − m₂（m₁、m₂ 为相邻两次示数，g；结果位数由绝对误差决定）
- 相对误差 E_r = |m_测 − m_标| / m_标 × 100%
- 最小称样量 m_min = 2d / E_r(允许)，d 为感量。取 d = 0.1 mg = 0.0001 g、E_r = 0.1%，得 **m_min = 0.2 g**
- 相对平均偏差 = (Σ|dᵢ| / n) / x̄ × 100%

**为什么减法的位数会"变少"**：m₁ − m₂ 的绝对误差是两次读数误差之和（约 ±0.0002 g），故 0.3998 g 只能保留到 0.0001 g，即 4 位有效数字。反过来把它写成 0.4 g 同样是错——那是把仪器的分辨力人为降到了 0.1 g。

**示例自洽**：0.5001 g 对 0.5000 g 的相对误差 = 0.0001 / 0.5000 = **0.02%** ✓；三份 0.3998 / 0.3998 / 0.3999 g，平均 0.3998 g，极差 0.0001 g，相对平均偏差 = 0.0000333 / 0.3998 = **0.008%** ✓。

## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

```
[前测1][K1] 一台分析天平铭牌标 Max 200 g、分度值 d = 0.1 mg。若要求称量相对误差 ≤0.1%，
           用这台天平称样的最小称样量为：
A. 0.02 g
B. 0.05 g
C. 0.20 g
D. 2.0 g
答案：C
解析：m_min = 2d / E_r = 2 × 0.0001 g ÷ 0.1% = 0.2 g。系数 2 来自"称量一次至少要读两次数
      （加样前后各一次）"，两次读数误差叠加。本实验固定质量法称 0.5000 g、递减法每份约 0.4 g，
      都大于 0.2 g，相对误差分别约 0.04% 与 0.05%，满足 ≤0.1% 的要求。
```

```
[前测2][A1] 下列做法中会直接损坏分析天平、导致本次实验终止的是：
A. 称量前调地脚螺栓使水平泡居中，预热 30 min 后做内校
B. 把约 500 g 的整瓶 NaCl 试剂瓶直接放到秤盘上称量
C. 把称量纸折角后放在秤盘中央，关侧门再读数
D. 称量结束后用软毛刷清扫秤盘上的固体粉末
答案：B
解析：天平最大载荷 200 g，整瓶试剂约 500 g，超载 2.5 倍。电光天平的横梁靠三棱刀口支承，
      机械天平没有电子过载保护，超载会使刀口崩裂、横梁变形，玻璃罩受震开裂——这是本实验
      唯一的 L4 事故。A、C、D 均为规范动作。
```

```
[前测3][S1] 用分析天平称量，示数在 0.4998 g ↔ 0.5002 g 之间反复跳动，正确做法是：
A. 取跳动范围的中间值 0.5000 g 记录
B. 等示数稳定（10 s 内变化 ≤0.0002 g）后读数；仍跳动则查侧门是否关严、有无气流或震动
C. 取第一次出现的数值，越早记越"原始"
D. 换一台天平反复称，直到出现正好 0.5000 g
答案：B
解析：跳动来自气流、桌面震动或侧门未关，属可消除的系统因素，先排除再读数。A 是人为编造
      平均值，C 把噪声当数据，D 是"凑数"，三者都违反原始记录规范（§7 H6）。
```

```
[后测1][K1] 若改用分度值 d = 0.01 mg 的微量天平，仍要求称量相对误差 ≤0.1%，
           则最小称样量变为：
A. 0.002 g
B. 0.020 g
C. 0.200 g
D. 2.00 g
答案：B
解析：m_min 与 d 成正比。d 由 0.1 mg 降到 0.01 mg（缩小 10 倍），m_min 同比例由 0.2 g
      降到 0.02 g（20 mg）。此时记录位数也要跟着变：示数应记到 0.00001 g。
      "仪器换了、位数不变"是典型错误——位数由仪器决定，不由习惯决定。
```

```
[后测2][A1] 要称取刚在 105 ℃ 烘箱中烘过 40 min 的基准物质，正确的做法是：
A. 趁热称量，热的时候不吸潮，数据最准
B. 放入干燥器冷却至室温后再称，冷却期间盖好盖子
C. 用冷水冲称量瓶外壁快速降温后立即称量
D. 直接放进天平箱里"借"天平箱当干燥器冷却
答案：B
解析：热物会在秤盘上方形成上升气流，浮力不断变化，示数持续单向漂移（且可能损伤传感器），
      属 L3 级 device-accident。C 的骤冷使薄壁玻璃产生热应力，称量瓶会开裂；D 既污染天平箱，
      也让天平长期处于非热平衡状态。正确路径只有"干燥器内冷却至室温"。
```

```
[后测3][S2] 递减法连续称量，四次示数依次为 18.2642、17.8644、17.4646、17.0647 g。
           第 2 份试样的质量应记为：
A. 0.4 g
B. 0.40 g
C. 0.3998 g
D. 0.39980 g
答案：C
解析：17.8644 − 17.4646 = 0.3998 g。两次读数各带 ±0.0001 g 的误差，差值的绝对误差约
      ±0.0002 g，故结果只能保留到小数点后 4 位，即 4 位有效数字。A、B 丢失了仪器本可分辨的
      位数（虚假"低精度"），D 多写一位属虚假精度——两者都会被判有效数字错误。
```

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`
- 结果误差分档（固定质量法偏差 |Δm| 与递减法相对平均偏差，取两者中较差者定档）：
  - |Δm| ≤ 0.0002 g 且 相对平均偏差 ≤ 0.05% → 满分
  - |Δm| ≤ 0.0005 g 且 相对平均偏差 ≤ 0.10% → −5
  - |Δm| ≤ 0.0010 g 且 相对平均偏差 ≤ 0.20% → −15
  - 超出上述范围 → 报告分不超过 60
- 步骤完整性：步 2 构造指认（八部件）、步 3 四项（调平/预热/校准/回测）、步 6 记录规范，缺一项 −3（最多 −9）。
- 报告分：数据完整性 30% + 计算与有效数字 30% + 误差分析 20% + 安全与记录规范 20%
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）
- L4 触发即终止本次实验：操作分记 0，须完成安全复盘并重做；天平损坏按 S008 走报修流程。

## 11. AI 评估要点（举一反三）

1. **换感量**：学生把 d 从 0.1 mg 改成 0.01 mg 或 1 mg 时，应能同时改三件事——最小称样量（同比例变化）、记录位数（示数小数位随 d 变）、方法选择（d 变大到 1 mg 时固定质量法先失效）。只改称样量而不改位数，说明把"有效数字"当成作文格式而非仪器属性。
2. **换称量方法**：学生把固定质量法改成递减法时，应能说出"递减法一次称多份、不与空气长时间接触、不要求凑准质量"，误差来源是两次读数叠加而非一次凑准；若学生断言"递减法一定更准"，要追问：当目标质量只有 0.05 g（小于 m_min）时，两种方法都不合格，问题在称样量而不在方法。
3. **换称量对象**：把 NaCl 换成易吸潮的 NaOH 或易挥发的浓盐酸时，应能判断误差方向——吸潮使 m₂ 偏大、差减值偏小；挥发使 m₂ 偏小、差减值偏大；并给出对策（加盖、快速转移、减少暴露时间、用称量瓶而非称量纸）。NaOH 还会腐蚀秤盘与天平箱，属 §7 H4 的升级情形。
