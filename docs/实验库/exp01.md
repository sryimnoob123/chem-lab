## 2. 实验目的（三维，每条可判定）

- **知识**：能说明分析天平 0.1 mg 感量与"称量结果记到小数点后 4 位"的对应关系，并算出本实验的最小称样量（0.2 g）。
- **技能**：能独立完成"调水平 → 校准 → 差减法称样 → 溶解转移 → 定容 → 移取"全流程，所配 c(Na₂CO₃) 与理论值 0.1000 mol/L 相对误差 ≤0.2%。
- **素养**：能说出稀释浓硫酸"酸入水、沿壁、搅拌、冷却"四条要点，并在溅液时正确执行"大量流水冲洗 ≥15 min + 报告"。

## 3. 原理（≤150 字 + 关键公式）

**配制**：由目标浓度与体积算称样量，固体溶解后定量转移至容量瓶定容；由浓溶液稀释时溶质物质的量不变。

**关键公式**：

- m = c × V × M（m 称样质量 g；c 目标浓度 mol/L；V 容量瓶体积 L；M 摩尔质量 g/mol，M(Na₂CO₃) = 105.99）
- c₁V₁ = c₂V₂（c₁、V₁ 为浓溶液浓度与取用体积；c₂、V₂ 为稀溶液）
- 相对误差 E_r = |c_测 − c_理| / c_理 × 100%
- 最小称样量 m_min = 2 × 感量 / 允许相对误差 = 2 × 0.0001 g / 0.1% = 0.2 g

**稀释热**：浓硫酸与水混合放热约 85 kJ/mol（H₂SO₄）【待老师核】，局部可使液温瞬间超过 100 ℃；水密度小、浮于酸面，若"水入酸"则热量集中在水层，先沸腾后爆溅。

## 9. 测验题（前测 3 / 后测 3 / 迁移 1）

```
[前测1][K1] 一台感量 0.1 mg 的分析天平，用差减法称取约 1 g 试样，结果应记为：
A. 1.1 g
B. 1.06 g
C. 1.060 g
D. 1.0599 g
答案：D
解析：感量 0.1 mg = 0.0001 g，差减法两次读数均须记到小数点后 4 位，故 1.0599 g。
      另：为使称量相对误差 ≤0.1%，最小称样量 = 2×0.0001 g ÷ 0.1% = 0.2 g，本实验取 1 g 左右满足要求。
```

## 10. 判分口径

- 操作分 = `clamp(100 − Σ违规扣分 − Σ事故扣分, 0, 100)`
- 终点/结果误差分档（以 c(Na₂CO₃) 相对误差计）：
  - ≤ 0.2% → 满分
  - 0.2% ~ 0.5% → −5
  - 0.5% ~ 1.0% → −15
  - > 1.0% → 报告分不超过 60
- 报告分：数据完整性 30% + 计算正确 30% + 误差分析 20% + 安全复盘 20%
- 提示扣分：用到 H2 及以上每次 −1（独立完成度）
- L4 触发即终止本次实验：操作分记 0，须完成安全复盘并重做。

1. **换容量瓶体积**：把 100 mL 换成 250 mL，称样量从 1.0599 g 变为 2.6498 g。请学生判断"称量相对误差减半、体积允差从 ±0.10 mL 放宽到 ±0.15 mL"两个方向相反的效应，谁主导。

3. **换固体形态**：若把无水 Na₂CO₃ 换成 Na₂CO₃·10H₂O，称样量应为 2.8614 g；但十水合物易风化失水，实际含水率低于理论值，会使所称 n 偏大、c 偏高。请学生判断误差方向并给出对策（配成溶液后标定，或改用基准无水物并干燥保存）。
