# 项目说明（会随需求更新，不是规范）

## 课程
《无机及分析化学实验》课程代码 03600004，36 学时 / 1 学分，面向化工、能源、材料专业大一第一学期。
10 个实验（验证 7 / 综合 2 / 设计 1），总成绩为过程性评价 100%：实验操作 40% + 实验报告 50% + 出勤预习 10%。

## 要做的事
围绕四个模块：① 理论预习 ② 平台模拟实验操作 ③ AI 评估学生自设方案 ④ 课程特色创新设计。
当前交付重点 = ② + ③。

## 学生画像
大一新生、非化学专业，**重实验规范与流程，不做机理级仿真**。

## 已定设计
- 2D 交互（SVG 画器材，状态机驱动液面/颜色/气泡/沉淀/读数），不做 3D。
- 违规操作给强负反馈（爆炸、有毒气体、溅出），并讲清正确做法；规则独立成层。
- 拼凑式方案设计（选试剂/浓度/步骤/指示剂 → 判可行 → AI 点评）留给学有余力的学生。
