# 三个视觉方向 · 对照与取舍

> 产物：`docs/design/directions/{a,b,c}/index.html`，每套 1440×900 / 390×844 两张截图。
> 结论：**B 的骨架 + C 的图注 + A 的台账**，不选“纯 A / 纯 B / 纯 C”。

## 一句话对照

| | A 台账 | B 仪器面板 | C 标本页 |
|---|---|---|---|
| 骨架 | 浅纸面，一列到底 | 左暗场舞台 + 右亮教学面 | 浅纸面，编辑排版 |
| 首页第一眼 | 10 个实验排成大表 | 一支滴定管占满左半屏 | 大标题 + 图注 + 手记 |
| 优点 | 信息密度高，教师一眼看完 | 仪器有存在感，像实验台 | 有“教材/标本”气质，图注清楚 |
| 风险 | 像后台表格，学生不想点 | 暗场面积大，字多时压抑 | 图注/引线在手机上容易糊 |
| 适合 | 教师端、实验目录 | 实验操作台 | 首页、原理说明 |

## 推荐方向：B 的骨架，C 的图注，A 的台账

- **B 的骨架**：左暗场 `--bench-ink` + 右亮面 `--paper`，1px `--bench-line` 分界，不用阴影、不用圆角。理由：一进实验就“离开网页”，进入操作台；暗场让玻璃器皿和液面成为主角。
- **C 的图注**：引线 + 3px 端点圆点 + `图 NN · <器材> <规格> · 正视无透视`，视线/凹液面用虚线。理由：化学实验的“看”需要被解释，图注比装饰更有用。
- **A 的台账**：实验/报告/教师三处用表，表头 `--paper-2`、44px 行高、数字右对齐 mono、当前行左侧 2px 河大蓝。理由：这是课程产品，不是艺术海报；台账让“做到哪、扣在哪”可查。

最终落地：
- `/` 只做门户：大标题 + 一个主按钮 + 暗场视觉卡 + 四步流程，**不再塞实验列表**；
- `/experiments` 用 A 的分组台账；
- `/exp/[id]` 用 B 的暗场舞台 + C 的图注 + A 的步骤/参数台账。

## 最丑的一处，以及改了什么

初版 A 的首页把 10 个实验直接铺成一张大表：标题、按钮、表格三层抢注意力，学生第一眼不知道点哪。

改法：首页只保留“课程名 + 一句话 + 进入实验”的一个动作，视觉卡承担气氛；实验清单下放到 `/experiments`，用分组行 + 44px 台账，把“信息密度”留在该留的页面。

## 已知风险

1. **暗场可读性**：暗场上 12px 以下正文容易发灰；已把正文提到 14px、关键数字 28–72px，并用亮描边玻璃而不是降低背景黑度。
2. **移动端图注**：引线在 390px 宽会压住器皿；已在 `<=760px` 隐藏引线，只保留图注文字。
3. **表格化回潮**：A 的台账一旦铺到首页就会变成后台；约定“表只出现在目录/报告/教师端”，操作台用卡片和刻度。
4. **字体加载**：霞鹜文楷 97 个 subset，首页只加载需要的分片；离线环境要确认 `public/fonts` 已随包。
