# MOTION —— 交互反馈参数表

> 唯一来源：`app/styles/motion.css`（CSS 变量 + 状态类）。
> 组件里**不许写死时长/缓动/缩放**，一律引用这里的变量。
> 对应决策：`.team/DECISIONS.md` §17（手感标准）、§18（成功/失败分支）、§19（反馈闭环）。

## 1. 响应时间预算（硬指标）

| 阶段 | 上限 | 说明 |
|---|---|---|
| hover 反馈 | **≤80ms** | 描边点亮 / 轻微浮起，用户一碰就有反应 |
| 按下反馈 | **≤30ms** | `scale(0.97)`，必须同帧可见 |
| 点击后的可见反馈 | **100~300ms** | 缩放 / 发光 / 轻震 / 粒子，至少一种 |
| 拖拽跟手 | 0ms | 起手即跟，`transition: none` |
| 落位吸附 | 160ms | 从 `scale(1.06)` 弹回 |

**禁止**：任何点击后 >300ms 才有可见变化；「点了没反应、只能等跳转」。

| 变量 | 值 | 用途 |
|---|---|---|
| `--press-in` | `30ms` | 按下生效 |
| `--press-out` | `120ms` | 松开回弹 |
| `--hover` | `80ms` | 悬停 |
| `--pop` | `180ms` | 数值弹一下 |
| `--snap` | `160ms` | 拖拽落位吸附 |
| `--shake` | `240ms` | 拒收抖动 |
| `--pulse` | `360ms` | 成功/失败光环 |
| `--enter` | `260ms` | 内容入场 |
| `--tint` | `600ms` | 液体变色 |
| `--ease-press` | `cubic-bezier(.4,0,.2,1)` | 按下/悬停 |
| `--ease-pop` | `cubic-bezier(.34,1.56,.64,1)` | 带弹性的回弹 |
| `--ease-snap` | `cubic-bezier(.22,1,.36,1)` | 吸附/脉冲 |
| `--scale-down` | `0.97` | 按下 |
| `--scale-up` | `1.04` | 悬停/选中 |
| `--scale-pop` | `1.06` | 落位瞬间 |

## 3. 状态类清单

| 类 / 属性 | 效果 | 用在哪 |
|---|---|---|
| `.ix` | 可交互基类（含 press/hover/focus 全状态） | 一切可点元素 |
| `.ix-snap` | 落位吸附弹一下 | 拖拽落点、投放成功 |
| `.ix-shake` | 左右抖 4px×3 | 拒收、操作错误 |
| `.ix-pulse-ok` | 绿色光环扩散 | 步骤通过、器皿正反馈 |
| `.ix-pulse-fail` | 红色光环扩散 | 事故、失败 |
| `.ix-pop` | 缩放 1.14→1 | 读数/体积数字变化 |
| `.ix-enter` | 上浮 10px + 淡入 | 步骤内容切换 |
| `.ix-step[data-current]` | 左侧 2px 河大蓝 | 步骤条当前项 |
| `[data-pressed="true"]` | 强制按下态 | 键盘/程序触发 |
| `[data-selected="true"]` | 常亮描边 | 点选路径 |
| `[data-dragging="true"]` | 跟手 + 抬起阴影 | 拖拽中 |
| `[data-drop-target="true"]` | 虚线环脉冲 + 放大 | 可投放目标 |

## 4. 降级（`prefers-reduced-motion: reduce`）

- 取消一切位移、缩放、循环动画
- **保留**描边、底色、光环的静态态（信息不能丢）
- 过渡压到 1ms，避免"卡住"的观感

## 5. 验收方法（每个可点元素都要过）

1. Playwright 遍历所有 `[data-demo-id]` 可点元素
2. 每个元素截**前后两帧**：`pointerdown` 前一张、按下后 60ms 一张
3. 断言两帧像素差 > 阈值（说明确实有可见变化）
4. 记录到 `%TEMP%\chemlab-shots\ix-<元素>.png`，汇总一份「元素 → 反馈类型 → 是否通过」表
