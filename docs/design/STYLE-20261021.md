# STYLE —— 本轮风格裁定（2026-10-21）

> 定位：把已散落在 `DESIGN-CONTRACT.md` / `MOTION.md` / `LOGIN-SCENE-GUIDE.md` / `视觉动效调研.md`
> 里的规则**收编成一套可执行的口径**，并补上此前缺的两块：**正反馈语言** 与 **错误/事故语言**。
> 冲突时优先级：本文件 > `视觉动效调研.md`；与 `DESIGN-CONTRACT.md` §2/§5/§9 冲突时以契约为准。

## 0. 一句话风格

> **白色瓷面实验记录台**：纸的底、瓷的器皿、墨的线，唯一强调色是河大蓝，唯一化学高光色是酚酞粉。
> 动效只做三件有物理意义的事：**计量、液体、精确**。不做装饰性运动。

记忆点：**滴定管的一滴粉液落进锥形瓶，液面起一圈涟漪，颜色深半度。**
全站所有页面都要能在 3 秒内让人说出这一句，说不出来就是做花了。

风格判定（每次交付自问）：
1. 缩到 50% 还认得出是玻璃器皿吗？
2. 静止时信息完整吗（不靠动画才看懂）？
3. 去掉这个动效，信息有损失吗？没有就删掉。
4. 跟 `/scene-preview` 并排看，线宽/光源/圆角一致吗？

## 2. 动效语言：三条隐喻，一套 token

任何新动效必须归到下面三条之一，归不进去就不做。

### 2.1 计量（最优先）
数字、刻度、进度 = 仪器的读数感。统一用 `--font-mono` + `tabular-nums`。

| 动效 | 参数 | 用在哪 |
|---|---|---|
| 数字滚动（odometer） | `translateY` 数字列，600~900ms `ease-out`，进入视口一次 | 分数、均分、已用体积、报告分项 |
| 刻度生长 | `scaleX(0→1)` / `stroke-dashoffset`，400ms `ease-out` | 页边刻度尺、步骤进度条、报告分节 |
| 数值弹跳 | `.ix-pop` `scale 1→1.14→1`，180ms `--ease-pop` | 读数变化、次数 +1 |

### 2.2 液体（环境循环，永远不抢注意力）
幅度小、周期长、相位对齐。

| 动效 | 参数 | 用在哪 |
|---|---|---|
| 液面呼吸 | `scaleY .99↔1.012`，3.5~5s `ease-in-out`，`transform-box: fill-box` | 锥形瓶/烧杯液面 |
| 液滴 | `translateY`，2.4s→**1.8s**，`cubic-bezier(.45,0,.9,.55)`（重力） | 滴定管尖嘴 |
| 落点涟漪 | `scale .4→2.4` + `opacity .45→0`，**与液滴同周期**，落点后 200ms 起 | 液滴落点、点击波纹 |
| 气泡 | `translateY -62px` + 淡入淡出，8s `linear`，负延迟错开 | 锥形瓶 2~3 个、烧杯 2~3 个 |
| 变色 | `filter`/填充色过渡 **600ms**（`--tint`） | 滴定终点、指示剂变色 |

### 2.3 精确（一次性编排，只播一次）
| 动效 | 参数 | 用在哪 |
|---|---|---|
| 线条描绘 | `pathLength={1}` + `stroke-dashoffset 1→0`，1.6s `cubic-bezier(.23,1,.32,1)`，错峰 120ms | 登录页首屏器皿、首页竖线 |
| 卡片入场 | `translateY(12px) scale(.96)→1`，280ms，**绝不 scale(0)** | 登录卡、结果条 |
| 双层视差 | 近景 ×(-6,-4)px、远景 ×(3,2)px，`pointermove` 只写 CSS 变量，不 setState；仅 `(hover:hover) and (pointer:fine)` | 登录页 |
| 状态延续 | 淡出 + `scale(.98)` 180ms 交叉，不做 FLIP 库 | 卡片→操作台、前测卡→答题面板 |

**时间尺度只有两档**：交互 ≤300ms（通常 100~280）；环境 1.8~12s 循环。
**禁止** 400ms~1.8s 的循环，也禁止 `transition: all`。

### 2.4 拖拽三段式（用户点名要的，最高优先级）

现在的毛病：拖进框里 → 立刻 dispatch → 步骤换掉 → 700ms 倒入动画被截断，观感"拖进去就下一步"。
必须改成**三段都有戏**：

| 段 | 时机 | 做什么 | 参数 |
|---|---|---|---|
| 1 拖动中 | `dragstart` → `drop` | 跟手 0ms；热区 `data-drop-target` 虚线环脉冲；试剂瓶轻微抬起 | 0ms / 900ms 循环 |
| 2 松手吸附 | `drop` 当帧 | 落点 `scale(1.06→1)` 弹回，**先给"我接住了"的确认** | 160ms `--ease-snap` |
| 3a 成功 | 吸附后 | 倒入动画播**完**再推进步骤（或推进时保住动画层不卸载）：瓶身倾转 300ms + 3 滴贝塞尔飞行 + 落点涟漪 + 液面抬升，总 700ms；随后 `SuccessBurst(L1)` + 读数 `.ix-pop` | 700ms + 360ms |
| 3b 失败 | 吸附后 | 试剂瓶**回弹到原位** + 拒收抖动 + 一句「为什么」；允许原地重试，不把人打回去重来 | 240ms + 240ms |

关键：**动画时序优先于状态推进**。要么把 dispatch 延后到动画结束，要么让动画层挂在状态之外不被卸载。
不做"成功后立刻静默跳步"，也不做"失败后整页重来"。

## 3. 正反馈语言（本轮新增，用户最高优先级）

原则：**正反馈要"有温度但不幼稚"**。不做撒花、不做彩带、不弹"太棒了"。
用仪器语言表达"做对了"：**器皿发光 → 现象发生 → 读数变准 → 记录落笔**。

### 3.1 三级正反馈

| 级别 | 触发 | 视觉（全部 ≤600ms，不阻塞下一步） | 音效 |
|---|---|---|---|
| **L1 微反馈**（每次操作） | 单个动作正确 | 器皿 `.ix-pulse-ok` 绿色光环 360ms + `.ix-pop` 读数弹一下 + 事件条左侧 3px 竖条转 `--jade-600` | 无 |
| **L2 步骤完成**（一步走完） | `stepIndex` 前进 | 现象动画（变色 600ms / 气泡 stagger 90ms / 沉淀缓降 900ms）+ 进度刻度生长 400ms + 下一步卡片 `.ix-enter` 260ms | 无 |
| **L3 里程碑**（实验完成/满分） | 交卷、报告生成 | 数字滚动 0→得分（800ms）+ 器皿持续 1.2s 呼吸 + 报告纸展开（刻度线先画 400ms，内容 stagger 30ms） | 无 |

### 3.2 正反馈专用组件（`components/exp/feedback/`）

| 组件 | 职责 | 规格 |
|---|---|---|
| `SuccessBurst` | 器皿周围一圈刻度环扩散 | 8~12 段短线，`opacity + scale`，360ms，`--jade-600` |
| `ScoreOdometer` | 分数/读数滚动 | 600~900ms，`ease-out`，`tabular-nums`，进入视口一次，`prefers-reduced-motion` 直接显示终值 |
| `StreakPill` | 连续正确计数 | 仅在 ≥2 连对时出现，`.ix-pop` 180ms，**不闪烁** |
| `EndingFlash` | 滴定终点/反应完成的一次性高光 | `filter: brightness(1→1.06→1)` + 液色 600ms 过渡，总 700ms |

### 3.3 正反馈的"禁止"
- 禁止全屏闪光、禁止镜头缩放（`scale` 整页）
- 禁止连续循环庆祝（只播一次，播完即静）
- 禁止用红色/橙色表达"好"
- 禁止文案堆砌（≤18 字，一句说清"对了什么"）

### 3.4 音效（用户点名要的，本轮新增）

调研文档原先把音效列进负面清单（课堂投屏），**用户口径优先，本轮要做**——但必须克制到"不打扰课堂"。

**实现方式：Web Audio API 程序化合成，不落任何音频素材文件。**
好处：零版权风险（商用关键）、零网络请求、零下发体积、可参数化。

| 音效 | 触发 | 音色 | 时长 |
|---|---|---|---|
| `ok-l1` | 单个动作正确 | 上行正弦三音（轻） | ≤120ms |
| `ok-l2` | 一步完成 | 上行正弦 + 短和弦 | ≤180ms |
| `ok-l3` | 实验完成/出分 | 更宽的上行（仍不循环） | ≤180ms |
| `fail-reject` | 拒收/顺序错 | 低频短促下行 | ≤140ms |
| `fail-incident` | 事故 L3/L4 | 低频 + 噪声包络 | ≤400ms |
| `tick` | 读数变化/刻度 | 极轻 click | ≤40ms |
| `drop` | 液滴落定 | 极轻水声质感 | ≤80ms |
| `error-system` | 网络/接口失败 | 下行两音 | ≤160ms |

**规则**：
1. 主增益很低（峰值 gain ≤0.08，约 -18dB）；单次 ≤180ms（事故 ≤400ms）。
2. **不循环、不背景音乐、不自动播放**；首个用户交互后才创建 AudioContext。
3. 必须有一键静音（`aria-pressed`，≥44px），偏好存 localStorage；静音后所有 `playSound` 静默返回。
4. 同帧最多 2 个音效并发；连续 tick 做节流（≥60ms 一次）。
5. `prefers-reduced-motion` **不**静音（音效独立），但可用静音开关关掉。
6. 音效**不承载信息**：静音时所有反馈仍能靠视觉完整理解。

## 4. 错误 / 事故语言（本轮补齐）

原则：**错误必须让人"疼一下、看懂为什么、知道怎么改"**。三件事缺一不可。

### 4.1 三级错误

| 级别 | 场景 | 视觉 | 文案结构（固定三行） |
|---|---|---|---|
| **E1 拒收**（操作不被接受） | 投错目标、拖到无效位置、步骤顺序错 | 目标元素 `.ix-shake` 240ms + 红色虚线框 1 次 + 光标回弹 | ①错在哪（≤20 字）②为什么（机理/规范）③怎么改（一句动作） |
| **E2 事故**（有后果） | 违规操作触发 8 类事故 | `FxByKey` 现有特效 + 屏幕震动分级（L1 160 / L2 220 / L3 320 / L4 460ms）+ L3/L4 暗场 + vignette + L4 粒子 | 事故名 + 后果 + 处置步骤（3 条） |
| **E3 系统错误**（环境问题） | 网络失败、接口 5xx、登录失败 | 顶部 toast 下滑 240ms + 3.5s 后自动收；关键操作失败给「重试」按钮 44px | 人话一句话 + 一个可点动作（重试/返回/联系老师） |

### 4.2 错误专用组件（`components/exp/incident/`）

| 组件 | 职责 |
|---|---|
| `RejectHint` | E1：拖到无效目标的即时拒绝提示（跟随光标，180ms 淡入） |
| `ErrorToast` | E3：顶部/底部 toast，`role="alert"`，`aria-live="assertive"`，最多同时 1 条 |
| `IncidentBanner` | E2：事故后的事件条三行式（错在哪/为什么/怎么办），不遮实验台 |
| `RetryBar` | 失败后「重做本步」条，触控 ≥44px，聚焦可见 |

### 4.3 错误文案硬规则
- 不写"操作失败"四个字了事；不写"系统错误，请联系管理员"。
- 不把技术错误码直接抛给学生（`ERR_500` → "服务器没响应，稍等 3 秒再点一次"）。
- 不用红色大面积底色（只左侧 3px 竖条 + 文字色）。
- 事故文案必须来自 `experiments/<id>/definition.ts` 的 `feedback`，UI 不得自行编化学解释。

## 5. 性能预算（本轮硬指标，改完要量）

| 指标 | 上限 | 量法 |
|---|---|---|
| 新增运行时依赖 | **0** | `package.json` diff |
| 登录页首屏编排 | ≤1.8s 全部播完 | 录帧/`performance` |
| 同屏循环动画 | ≤6 个（气泡按组算 1 个） | 数 `animation-iteration-count: infinite` |
| 单页 SVG DOM 节点 | ≤400 | `document.querySelectorAll('svg *').length` |
| 交互反馈延迟 | ≤30ms 按下 / ≤300ms 可见结果 | 截图两帧像素差 |
| 演示模式帧率 | ≥50fps（1440×900） | CDP `Performance.getMetrics` |
| 首屏 CLS | ≈0（动效不改布局尺寸） | 只用 transform/opacity |
| 移动端 390×844 | 无横向溢出、触控 ≥44px | `scrollWidth === clientWidth` |

**实现约束**
- 只动 `transform / opacity / filter / stroke-dashoffset`；`will-change` 只在动画期间加，结束移除。
- SVG 元素动 `scale` 必须 `transform-box: fill-box` + `transform-origin`。
- 粒子 ≤12；`prefers-reduced-motion` 下**完全静止**（不是变快），信息用静态描边/色块保留。
- 不做 Canvas 粒子新场景（已有 `FxParticles` 够用）；不为动效引入 WebGL。

### 5.1 UI 信息层级（用户要求"UI 太乱，要简洁、专注实验"）

操作台的加法已经做太多了。定三个层级，**默认只显示 L1**，L2 折叠、L3 按需：

| 层级 | 内容 | 默认 |
|---|---|---|
| **L1 常驻（≤4 块）** | ① 实验台场景（最大面积）② 一句大字当前指令 ③ 精简步骤点/进度 ④ 一个主操作按钮 | 显示 |
| **L2 折叠** | 参数卡、为什么（why）、老师会说、步骤详情、键盘快捷键 | 收起，点「详情」展开 |
| **L3 按需** | Dev Dock、演示浮层、诊断信息、场景 TODO | 仅开发/演示 |

规则：
1. **同屏最多 1 条提示**（一个小提示，不是告警队列）。多出来的排队，不并列。
2. 错误后只给一个动作：「重做本步」；不要同时给 3 行解释 + 3 个按钮。
3. 大字读数保留（它是 HUD 的灵魂），但只留 1 个主读数 + 1 个单位。
4. 删掉不承担信息的装饰（坐标角标、重复的状态文案、无意义的编号）。
5. 判据：学生第一眼应该看**实验台**，不是看侧栏。首屏 50% 以上面积给场景。

## 6. 第三方素材与版权策略（商用，本轮新增）

**结论：代码依赖仍为 0；允许引入"素材型"开源资源，但必须逐条登记许可证。**

### 6.1 白名单（可商用）
| 许可证 | 允许 | 条件 |
|---|---|---|
| MIT / ISC / BSD-2 / BSD-3 / Apache-2.0 | ✅ | 保留版权声明 + NOTICE |
| CC0 / Public Domain | ✅ | 建议仍署名 |
| CC-BY 4.x | ✅ | 必须署名 + 注明修改 |
| SIL OFL 1.1（字体） | ✅ | 保留 OFL 文件，不单独售卖字体 |
| CC-BY-SA | ⚠️ 仅静态素材 | 衍生作品需同许可，**不入代码** |

### 6.2 黑名单（禁入）
- GPL / AGPL / LGPL（传染性，商用风险）
- CC-BY-NC / NC-SA（禁止商用）、CC-BY-ND（禁止修改）
- 无 license / "仅学习使用" / 爬来的图片
- Google Fonts / CDN 热链（已本地化，禁止回退）
- 图库水印图、AI 生成位图冒充手绘

### 6.3 流程（缺一不可）
1. 素材落 `public/` 或 `components/` 内（不外链）。
2. 在 `docs/design/ASSET-LICENSES.md` 记：名称 / 来源 URL / 版本 / 许可证 / 是否修改 / 用途。
3. 交付包带 `NOTICE`（根目录），列全部第三方素材与许可证原文路径。
4. 校徽等学校标识：仅课程内使用，仓库 private，不单独分发（`public/brand/README.md` 已有说明）。

### 6.4 本项目的默认姿势
**优先自绘**（器皿体系已覆盖 A/B/C 三级资产），外部素材只在"自绘不划算"时引入：
- 纹理/噪点 → `feTurbulence` 自生成，**不引位图**
- 图标 → 手绘 24×24 线性图标（线宽 1.6，与 C 级资产同规格）
- 音效 → **禁用**（课堂投屏场景，见调研文档负面清单）
