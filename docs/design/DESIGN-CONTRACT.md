## 2. 色彩 token

```css
:root {
  /* 纸与墨 */
  --paper:      #F6F7F5;
  --paper-2:    #EDF0EE;
  --ink:        #16202C;
  --ink-2:      #4A5768;
  --line:       #D5DCE4;

  /* 河大蓝 */
  --river-900:  #1B2A6B;
  --river-700:  #23307F;
  --river-100:  #E6E9F7;

  /* 校徽绿（通过/安全） */
  --jade-600:   #0F7B6C;
  --jade-100:   #E3F2EE;

  /* 化学语义色（仅承载化学信息） */
  --danger:     #C0392B;  /* 危险 / L4 */
  --warn:       #D98324;  /* 警告 / L3 */
  --oxid:       #E8B33A;  /* 氧化 / L1 */
  --toxic:      #5F7A3A;  /* 有毒 */
  --corrode:    #8B5E3C;  /* 腐蚀 */

  /* 场景 */
  --bench:      #E9EEF3;  /* 实验台底（亮区备用） */

  /* 暗场实验台（主用：B 骨架） */
  --bench-ink:  #0E1620;  /* 实验台深底 */
  --bench-2:    #1A2531;  /* 实验台次级面 */
  --bench-line: #2A3644;  /* 暗场分隔线 */
  --bench-text: #C9D6E4;  /* 暗场正文 */
}
```


**使用规则**
- UI 控件只用 `--river-*` + `--ink*` + `--line`；**不得**把化学语义色用于按钮、链接、边框、标签。
- 化学语义色只出现在：液体/沉淀/气体/危险等级/事故动画。
- 一个页面最多 2 个语义色同时出现（事故页除外）。
- 禁止：渐变装饰、玻璃拟态、霓虹、彩虹色板。

## 3. 字体与字阶

| 角色 | 字体 | 用于 |
|---|---|---|
| 骨架 | 思源黑体 Noto Sans SC（400/500/700） | 标题、正文、表格、按钮 |
| 批注 | 霞鹜文楷 LXGW WenKai | 旁白、安全提示引文、演示字幕、"老师会说"注解 |
| 数字 | IBM Plex Mono | 刻度、读数、有效数字、数据表、公式 |

字阶（1.25）：`12 / 13 / 14 / 16 / 20 / 25 / 31 / 39 / 49`
- 正文 16，行高 1.65，行宽 < 80 字符；
- 表格 14，行高 1.4；
- 同屏同时出现的字号 **≤4 档**；
- 正文左对齐，**不居中**；标题也不用居中（首页台账除外）。

禁用排版：ALL CAPS 眉标、`A · B · C` 中缀元信息、单词斜体强调、装饰性编号（除非内容真是序列）。

## 4. 栅格与版式

- 12 列，内容最大宽 1200px，页边 24（移动）/ 32（桌面）。
- **签名元素：页边刻度尺**（12px 宽、0.1 小格、每 1 大格）。用于：步骤进度、报告分节、拼接流程线、实验台账编号。**全站只此一个视觉重音**，其它保持安静。
- **表格优先于卡片**：1px `--line` 细线，行高 44，表头 `--paper-2` 底纹。
- 圆角 2px；阴影只用 `0 1px 2px rgba(22,32,44,.06)`；不要大圆角、不要多层阴影。
- 间距基数 4px（4/8/12/16/24/32/48/64）。

### 4.1 双区布局（主骨架，取自方向 B）

- **左/上：暗场实验台**（`--bench-ink`）——放 SVG 器材、液滴、气泡、气体、事故动画。暗底让现象与动效最清楚，也是"仪器"的心理场。
- **右/下：亮区教学面**（`--paper`）——放台账表、判据说明、读数输入、提示卡、报告数据。所有文字阅读都在这侧。
- 分界用 1px `--bench-line`，不用阴影、不用圆角。
- 移动端：上下堆叠，实验台固定 55vh，教学面可滚动；操作按钮落底部抽屉。
- 首页例外：首页是台账（亮区为主），暗场只在 hero 的滴定管局部出现。

### 4.2 标注体系（取自方向 C）

看不见的规范必须画出来，这是"教材感"的来源：

- **callout 引线**：1px 细线 + 端点 3px 实心圆，标签文字 13px `--ink-2`，引线不交叉、不跨越器材。用于标注刻度、凹液面最低点、管尖、活塞、视线水平线。
- **图注**：器材下方一行，格式 `图 NN · <器材> <规格> · <视角说明>`，例：`图 09 · 酸式滴定管 50 mL · 正视无透视`。
- **视线/几何辅助**：读数时画出"视线水平线 + 凹液面最低点"两条辅助线，用 `--river-700` @40% 虚线，操作结束即淡出（200ms）。
- **旁注**：纪律性提示用霞鹜文楷，前缀统一为"老师会说："，只在当前步出现一条，不堆叠。

### 4.3 台账表（取自方向 A）

- 实验列表、报告数据表、教师端学情表统一为同一套表格样式：表头 `--paper-2` 底纹、1px `--line`、行高 44、数字列右对齐且用等宽字体。
- 行内状态用文字（已完成 / 进行中 / 未开始），不用彩色胶囊标签；进行中行加 2px `--river-700` 左竖条。

## 5. 绘制体系（SVG 硬规则）

| 维度 | 规则 |
|---|---|
| 视角 | 正视平视，无透视变形 |
| 描边 | 玻璃 1.4px `#16202C` @70%；金属 1.2px；**单层**，不描双层 |
| 光源 | 统一左上 45°；高光一条 2px 白 @35%；**不出现第二光源** |
| 玻璃 | `fill: rgba(255,255,255,.5)` + 1px 内阴影；不得用灰色实填充冒充玻璃 |
| 液体 | 基色 `fill-opacity .55` + 顶面椭圆 + 凹液面两条贝塞尔 + 底部 1px 深色边 |
| 沉淀 | 独立图层；6~10 个小圆（r 1~2.5）底部沉降分布；用 `translateY` 下落 |
| 气泡 | 圆 + 高光点；上升 `translateY` + 轻微 `scale`；到液面 opacity→0 |
| 气体 | 径向渐变圆群（opacity ≤.22），`scale` 扩散；**禁止**云雾笔刷 |
| 刻度 | 等宽字体，与真实量程一致（滴定管 0.1mL、移液管单标线、容量瓶单标线） |
| 阴影 | 器皿底部一条 1px 深色边，不做投影 |

### 资产分级

- **A 级（1 件）**：首页滴定管 + 滴落循环。全站最精细，允许 300~400 行 SVG。
- **B 级（10~12 件）**：滴定管、锥形瓶、烧杯、量筒、移液管、容量瓶、离心管、天平、洗瓶、滴定台、酒精灯、漏斗。同规则、参数化，10 个实验复用。
- **C 级（≤12 个）**：动作图标（洗涤/称量/滴加/摇匀/读数/离心/过滤/加热），24×24，线宽 1.6。

**不做**：写实照片拼贴、AI 生成位图、重投影、彩虹渐变、装饰性流体。

## 6. 动效表

| 场景 | 属性 | 时长 | 曲线 |
|---|---|---|---|
| 按压 | `scale(.97)` | 120ms | `cubic-bezier(.23,1,.32,1)` |
| 悬停（仅 `hover:hover` + `pointer:fine`） | transform / opacity | 140ms | `ease` |
| 浮层 / tooltip（origin 跟随触发器） | opacity + transform | 180ms | `cubic-bezier(.23,1,.32,1)` |
| 抽屉 / 讲解卡 | `translateY(100%)→0` | 260ms | `cubic-bezier(.32,.72,0,1)` |
| 液面 | `scaleY` + mask | 240ms | `cubic-bezier(.77,0,.175,1)` |
| 液滴下落 | `translateY` | 380ms | ease-in（**仅物理下落允许**） |
| 读数滚动 | `translateY` 数字列 | 160ms | ease-out |
| 事故震动 | `translate` 4 帧 | 240ms | 阶梯 |
| 气体扩散 | `scale(.4→2.2)` + opacity | 1200ms | ease-out |
| 碎片粒子 | transform + opacity | 600ms | ease-out |
| 首屏编排 | 刻度尺画线 400ms + 表格 30ms stagger | 单次 | ease-out |

**禁用**：`transition: all`、UI 用 `ease-in`、`scale(0)` 入场、动画 `width/height/top/left`、键盘触发动画、每张卡片都 fade-in。
**降级**：`prefers-reduced-motion: reduce` → 保留颜色/透明度，去掉位移与粒子。
**性能**：只动 `transform/opacity`；粒子 ≤12；入场用 `@starting-style`，不写 `mounted` hack。

### 7.1 操作台 = 实时 HUD（强交互形态，参照成熟样例结构）

操作台不是"表单 + 下一步"，是**实时仪表**。四块固定：

| 区 | 内容 | 规格 |
|---|---|---|
| 左上 | **大字实时读数** | 72~96px `--font-mono` `tabular-nums`；单位 24px，比数字浅一档；下方一行小字说明当前在测什么 |
| 右上 | 步骤进度 | `第 03 步 / 共 06 步` + 一条细进度条（刻度尺语言，不用圆角胶囊） |
| 中部 | 实验台 | 暗场 + 器材 SVG + 液滴/气泡/颜色，占最大面积 |
| 右栏 | **live 参数卡 ×4** | 每卡：12px 小标题 + 28px 等宽大数字 + 单位；超阈值时描边切 `--warn` 并在右上挂 12px 标签（如"接近阈值"） |
| 底部 | **事件条** | 44px 整宽；左侧图标 + 主文案 + 右侧倒计时（`--font-mono`）；三态用**左侧 3px 竖条 + 文字色**表达，不用大面积底色：info `--river-700` / warn `--warn` / danger `--danger` |

- 参数卡候选：当前读数、已用体积 V、允许误差、指示剂颜色（色块）、温度、平行次数。
- 事件条与提示阶梯联动：H1 级以上提示、事故预警、强制重做都在这里出现，**同一时刻只显示一条**。
- 移动端：实验台固定 55vh，参数卡横向滚动成单列，事件条吸底。
- 禁止：整屏弹模态、大面积红色块、抖动整个页面（只抖实验台局部）。

## 8. 视觉验收（每个增量必做）

### 8.1 流程

```pwsh
npm run shots                    # 全量：3 视口 × 全部页面与关键状态
npm run shots -- exp09           # 只跑某个实验相关页面
```

- 工具：项目内 Playwright（**禁止**用 browseros-neo 开 localhost）。
- 视口：1440×900 / 768×1024 / 390×844。
- 状态：首页默认与有进度、预学（引入/前测答错）、操作台（初始/正确一步/L2/L4 定格/讲解卡）、报告、拼接（空/错/对）、演示（播放/提词器）、教师端（有数据/空态）。
- 落盘：`%TEMP%\chemlab-shots\<YYYYMMDD-HHmm>\`；当期金标准复制到 `docs/design/baseline/`。

### 8.2 Rubric（12 条，任一不过 = 未完成）

1. 首屏有"一眼记住"的东西（刻度尺 / 滴定管）
2. 无禁用模式（卡片墙 / 渐变装饰 / 大写眉标 / 正文居中 / 等圆角）
3. 同屏字号 ≤4 档；同权重主按钮 ≤2 个
4. 化学语义色未越界到 UI 控件
5. 器皿描边/光源/圆角/阴影与 token 一致
6. 液体、沉淀、气体各自只有一种表达方式
7. 移动端无横向溢出、触控 ≥44px、抽屉可用
8. 动效无禁用项；UI 时长 ≤300ms
9. 正文对比度 ≥4.5:1；键盘焦点可见
10. `prefers-reduced-motion` 下仍可完整操作
11. 报告页可打印成一页 A4
12. 空态 / 错误态 / 加载态都有设计

### 8.3 每张图自问六句

1. 缩到 50% 还认得出是什么器皿？
2. 描边、光源、圆角与全站一致？
3. 液体/沉淀/气体是否混用了表达方式？
4. 静止状态下信息已完整（不靠动画才看懂）？
5. 有没有不承担信息的装饰（有就删）？
6. 跟上一版基线比，是变好还是变花？

## 9. 禁止清单（汇总）

- 组件库 / 动画库 / 图表库 / 公式库 / CSS-in-JS
- 渐变装饰、玻璃拟态、霓虹、彩虹色板、重投影
- 大圆角卡片墙、每卡同阴影、每卡 fade-in
- 奶油底 + 衬线大标题 + 陶土色；纯黑底 + 荧光绿
- ALL CAPS 眉标、中缀元信息、装饰性编号
- `transition: all`、UI 用 ease-in、`scale(0)` 入场
- 校徽改色/拉伸/加特效；外链学校资源
- 用 browseros-neo 打开 localhost
