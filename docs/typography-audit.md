# 全站排版层级审计（2026-10-23）

一句结论：六页的字号从「9/10/11/12/12.5/13/13.5/14/15/16/17/18/20/22/25/26/28/32/64 随手取值」
收成 **12 / 14 / 20 / 32 四级**（数字读数保留大号，等宽 tabular），并把同一屏里 3 段以上的解释文字
拆成「标题 + 一行要点」或直接删掉；1366×768 与 1920×1080 两档均 0 横向溢出、0 控制台 error。

## 1. Token 落在哪

`app/globals.css` 的 `:root`（唯一来源，页面里只准引用变量）：

```css
--type-display: clamp(24px, 2.4vw, 32px); /* 大标题：一屏一处 */
--type-title: 20px;                       /* 中标题：区块标题 */
--type-body: 14px;                        /* 正文 */
--type-meta: 12px;                        /* 辅助：全站下限，不再出现 9/10/11px */
--sp-1..--sp-7: 4/8/12/16/24/32/48        /* 间距刻度 */
--lh-tight / --lh-meta / --lh-body: 1.25 / 1.5 / 1.65
```

`--text-12 … --text-49` 保留为兼容别名（值不变），新代码一律用语义档。
首页 hero 仍是 40–56px：落地页放大的是同一档角色，不是第 5 级。

## 4. 明确不改的

- **仪器上的数字**（天平 `0.0000 g`、pH `7.00`、量杯 80/40 刻度）：属装置图形的读数/标记，不是 UI 文案；只把最小值抬到 10px。
- **数字读数字号**：总分 56、三段分 32、评分 100 用等宽 tabular 数字，字号随读数放大，不进四级字阶。
- **拖拽与动画逻辑**：本轮只动样式、布局、token 与文案结构。
