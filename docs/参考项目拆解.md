### 1.4 gate 守卫的三段式（这段逻辑值得原样搬到我们的路由守卫里）

`ref: src/contexts/StageContext.tsx:187-247`：

1. **本地判定**：目标 `stageIndex > stageIndex(unlockedStage)` → 拦；`FREE_STAGES = ['cover','data']` 白名单直接放行；`debugUnlockAll` 放行。
2. **临界复核**：目标恰好是 `nextStage(currentStage)` 时，`fetch('/api/progress')` 复核一次服务端进度再决定——防止「刚达成、本地还没同步」被误杀。
3. **失败回落**：普通拦截一律回落到 `session.currentStage`。

同时用 `sessionRef`（`StageContext.tsx:122-125`）而不是闭包里的 `session`，注释写明原因：`setProgress` 后同一拍 `navigate` 会读到旧值。

### 1.5 会话与恢复

- `localStorage['hud_platform_session']` 存整个 `SessionInfo`（含 token、experimentNo、currentStage、unlockedStage、tutorialState、groupType、teacherMode）。
- 挂载时解 token 的 `exp` 判断过期（`StageContext.tsx:90-99`），过期就清键回登录。
- `restored` 之前 `return null` 不渲染（`:373`），避免闪一下封面。
- token 单独再写一份 `hud_auth_token`（`:180-181`），因为部分组件直接读它。

### 1.6 对我们的意义（别照搬的部分）

我们是**多路由**（`/`、`/login`、`/experiments`、`/exp/[id]`…），**不要**引入 `StageContext` 这套 SPA 状态机。该抄的是：

- 一张顺序数组 + `stageIndex/nextStage` 纯函数（我们已有 `lib/engine.ts` 的步进与 `lib/catalog.ts`，可加 `lib/flow.ts` 放「预习 → 操作 → 报告」三段顺序）。
- gate 守卫的**三段式**：本地判断 → 服务端复核 → 回落。我们的 `/exp/[id]/report` 未做，正好用这套。
- `unlockedStage` 这种「一个字段表达进度」的存法：我们有 `lib/persist/runs.ts` + `db/schema.ts`，加一列 `unlocked_step` 即可，不要搞 10 张进度表。

```

  ├─ {dark && <div className="fixed inset-0 z-0 blueprint-grid"/>}        // 装饰，z-0，pointer-events-none
```

**这套骨架的三个硬约束**（照抄时别漏）：
1. 全部 `min-h-0`：Flex 子项默认 `min-height:auto`，不加这一条，canvas/video 会把中段撑爆，页面就会整体滚动。本文件里出现 9 次 `min-h-0`。
2. 外层 `h-[calc(100vh-3.5rem)]` 而不是 `h-full`：因为顶栏是兄弟节点、高度写死 56px。我们改 `h-dvh` 时要把顶栏挪进 grid 行里算。
3. 右栏宽写死（288/320），**只有场景区弹性**。这一条决定了「窗口变窄时先压场景、不压读数」。

**我们不该抄的**：三张卡全部 `glass-panel` + `shadow-card`（卡片墙 + 同阴影，违反 `docs/design/DESIGN-CONTRACT.md` §9）；`bg-red-600/70` 大面积红条（契约 §7.1「禁止大面积红色块」）；`animate-pulse` 白点（`@keyframes` 是 Tailwind 内置的 opacity 动画，可留，但要统一到我们 token）。

## 3. 交互手法清单

> 「让页面像应用」的手法，逐条给「效果 → 实现 → 代码位置」。标 ⚠️ 的是**参考项目里存在但没被任何页面引用**的死代码，别以为它真在用。

### 3.1 拖拽：拉丁方排序 `LatinSquareDrag`

- **效果**：6 张试次卡从上方「可用池」拖进 3×2 网格；落进已占槽位时把原卡弹回池；点网格里的卡可移回；池空才允许「完成并继续」；点完成先跑 4 条约束校验。
- **实现**：纯 **HTML5 原生拖放**（`draggable` + `onDragStart/onDragOver/onDrop`），**没引任何拖拽库**。`ref: src/components/LatinSquareDrag.tsx`
  - 拖源：`:244-249` `draggable onDragStart={()=>handleDragStart(card)}`，样式 `cursor-grab active:cursor-grabbing`、hover 换边框色。
  - 落点：`:271-296` `onDragOver={e=>e.preventDefault()}`（**必须 preventDefault 才允许 drop**）、`onDrop`、`onClick` 三合一；空槽 `min-h-[80px] border-2`，有卡 `bg-primary/10 border-primary cursor-pointer`。
  - 交换逻辑：`:70-93`，若槽位有卡 → `setAvailableCards(prev=>[...prev, existingCard])`，再从池里 filter 掉被拖的，最后写进 grid（用"复制行→换列→换行"的不可变更新）。
  - 校验 4 条（`:115-219`）：① 完整性 `new Set(ids).size!==6`；② 位置均值差 `max-min > 1.0`；③ 标准差 `< 1.0`（两次出现挨太近）；④ 三种方案的事件序列 `JSON.stringify` 全相同。任一条失败只 `setValidationResult({isValid:false,message})`，**不阻止拖拽，只解释为什么不行**。
  - 提交流：`:43-62` `notifyOrderChange` 把 grid 压平成 `['A-X','B-Y',...]` 回传父组件 → 父组件 `PrepOrderStage.tsx:45-61` 写进 prep 数据（`latinSquareOrder`）。
- **迁移价值**：这是我们 `/lab/design`（拼接式方案）的正解。注意两点改进：① 触屏上 HTML5 DnD 基本不可用 → 必须同时给「点选 → 点目标」路径（`bench.tsx:71-80` 已经这么做了）；② 落点判定用坐标而不是 `onDrop` 命中，做「插入到第 N 位」时会不够。

### 3.2 滚动入场：`ScrollReveal` ⚠️

- **效果**：元素进入视口一次后，按 variant 从隐藏态过渡到显示态。
- **实现**：`IntersectionObserver` + 两个类名（`scroll-fx-*` 初始态 / `is-visible` 终态），动画参数全在 CSS。`ref: src/components/ScrollReveal.tsx:25-45`（`threshold: 0.12`、`rootMargin: '0px 0px -6% 0px'`，命中即 `observer.disconnect()`，只播一次）；过渡在 `ref: src/app/globals.css:542-583`。
- **⚠️ 事实**：全仓库没有任何文件 `import` 它（只有它自己 + CSS 注释提到 `scroll-fx`）。实际页面用的是**加载即播**的 `.reveal` 系列。
- **对我们的判断**：我们已有等价且更省的 `components/motion/reveal.tsx`（`Reveal` + `CountUp`，SSR 直接渲染终值，`prefers-reduced-motion` 直出），**继续用我们自己的**。它这套 `scroll-fx` 唯一值得借鉴的是 `clip` 变体（`clip-path: inset(16% 0 16% 0)` 帷幕揭开），可作为我们 `Reveal` 的第 3 个 variant。

### 3.3 粒子背景：`ParticleGrid` ⚠️

- **效果**：Canvas 上一层 60px 网格 + 50 个慢速漂移粒子 + 距离 <120px 连线。
- **实现**：单个 `requestAnimationFrame` 循环；`canvas.width = parent.clientWidth`（跟着父容器而不是视口，**这点是对的**）；粒子出界取模回绕；连线透明度按距离线性衰减；卸载时 `cancelAnimationFrame`。`ref: src/components/ParticleGrid.tsx:25-121`。
- **⚠️ 事实**：同样**无任何引用**；CSS 里还有一条 `[data-theme="bright-academic"] .particle-grid{display:none!important}`（`globals.css:900`）说明它曾经在亮区被禁用——即"作者自己也觉得它吵"。
- **对我们的判断**：**不抄**。契约 §9 禁霓虹/装饰，且 Canvas 逐帧只为装饰不划算。我们 `lib/scene/fx` 的 8 个事故特效是**内容性**动画，优先级远高于背景粒子。若真的想要氛围，用 CSS 静态刻度网格（`--bench-line` 1px、48px 栅格、6% 透明度）即可，零 JS。

### 3.4 左侧环节导航（10 节点 + 三态 + 锁）

- **效果**：常驻左侧 224px，10 个环节节点，已完成打绿勾、当前项金黄描边、未解锁变淡带锁；点击即跳。
- **实现**：数据是常量数组 `FLOW_NODES`（`GlobalNavigation.tsx:31-42`，每项 `{key,label,icon}`），状态由
  `unlocked = stageIndex(key) <= stageIndex(session.unlockedStage)`、
  `completed = nodeIdx < stageIndex(session.currentStage)`、
  `active = stage === key || (key==='experiment' && (stage==='post-survey'||stage==='prep-device'))` 三个布尔算出（`:88-93`）。**没有额外的进度表**，全部派生。
- **值得抄的是这三行派生逻辑**：把「阶段顺序数组」当唯一真相，UI 只做 index 比较。我们 `app/experiments/page.tsx` 的 `playable` 判定、`components/app/shell.tsx:60-77` 的侧栏，都可以用同一套。

### 4.4 降级兜底（这段直接抄结构）

`ref: src/app/globals.css:385-437`：一个 `@media (prefers-reduced-motion: reduce)` 块里，① 把所有动画类 `animation:none!important`；② 把所有入场类强制 `opacity:1; transform:none; filter:none; clip-path:none`；③ 把 `.scroll-fx` 的 transition 关掉；④ 把 `.card-sweep::before` / `.card-interactive` 的 transition 关掉。

**这段比逐个类写 media query 划算得多**，我们的 `app/globals.css` 可以照这个「一次性归零」的写法补一段（注意我们的 `--reveal-i` 是 CSS 变量驱动的 transition-delay，同样要在此块里清掉）。

#### 6.2.6 这一页的动效预算（别超）

同屏允许同时跑动的动画**最多 4 组**：

| 允许 | 时长 | 触发 |
|---|---|---|
| 液面 `fill` 过渡（契约特批例外） | 600ms | 加试剂 |
| 一种现象动画（气泡/沉淀/放热/雾气，**同一时刻只一种**） | 1200~2000ms | `resolveDrop` 命中 |
| 数字读数变化（`tabular-nums`，无动画，只换字） | — | 每步 |
| 事件条左竖条状态切换（只换 `border-left-color`，无动画） | — | 事件 |
| 事故特效（**唯一允许全屏**的） | 1200~2000ms 或循环 | incident |

**禁止**：粒子背景、卡片扫光、按钮循环光泽、多处 glow —— 在事故特效正在播的时候，页面其它地方一律静止。

|---|---|---|---|
| 1 | `lib/scene/fx-adapter.ts` + 单测 | 无 | `npm run test` 绿；4 条映射断言 |
| 2 | 操作台场景替换（`workbench.tsx` 左侧 + `.app` 改 grid） | 1 | 1440/768/390 三视口不横滚；exp09 第 1 步事故能播 |
| 3 | HUD 浮层化（读数块/参数列 z-index 分层） | 2 | 契约 §7.1 四块齐全；截图对比 |
| 4 | `/exp/[id]/report`（3 列骨架 + 内联 SVG + `@media print`） | 评分接口（已有 `lib/pedagogy/scoring.ts`） | 打印 A4 一页 |
| 5 | `/lab/design`（拖放 + `lib/plan/rules`） | 无 | 空/错/对三态截图 |
| 6 | 预学段 `/exp/[id]/prep`（3 列 + gate 条） | 4 的骨架 | 前测不过不能进台 |
| 7 | 教师端补双轴 sticky 矩阵 | 数据已就绪 | 1440 下 10 列不横滚 |
| 8 | DevPanel（非生产） | 全部 | 可跳到任意步、放任意特效 |

**风险**：

1. **`min-height:0` 遗漏**是最常见的破版原因。实验执行页任何一层 flex/grid 子项不加它，SVG 就会把页面撑出滚动条。排查口诀：从根到叶子，凡是"要收缩"的容器都加。
2. **`position:fixed` 在入场动画祖先里会失效**（§2.4）。我们的 `Reveal` 用 `transform`，所以浮层一律 `createPortal` 到 body，或确保浮层不在 `Reveal` 内。
3. **拖放在触屏不可用**：必须双路径（拖 + 点选），且 `reagent-rack.tsx` 的 `setData` 不能省（Firefox）。
4. **特效时长双源**：`bench-scene.tsx` 的 `FX_MS` 与 CSS keyframes 时长必须同步，改一处就改两处——收敛前先用注释互相指认。
5. **`prefers-reduced-motion` 下事故特效只剩终态**：`terminate` 的文案与事件条必须独立能看懂（不能只靠动画传达"爆炸了"）。
6. **我们的 `lib/scene/**` 是 asset-pipeline 独占目录**（`lib/scene/resolve.ts:1` 注释写明）。加 `fx-adapter.ts` 前先跟该模块 owner 打招呼，避免写作用域冲突。
