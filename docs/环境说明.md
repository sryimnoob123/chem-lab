## 真 PostgreSQL（可选，验 schema 用）
```bash
# 初始化（只做一次）
E:\TOOLS\pgsql\bin\initdb.exe -D E:\TOOLS\pgsql\data -U postgres -E UTF8 --locale=C

# 起 / 停（端口 5432，避开系统默认）
E:\TOOLS\pgsql\bin\pg_ctl.exe -D E:\TOOLS\pgsql\data -o "-p 5432" -l E:\TOOLS\pgsql\pg.log start
E:\TOOLS\pgsql\bin\pg_ctl.exe -D E:\TOOLS\pgsql\data stop
```

## 为什么开发用 PGlite
扣子给你的是托管 PostgreSQL，部署时只同步 schema、不同步数据。所以本地要做的是**把 schema 和迁移做干净**，
而不是去模拟生产的数据量。PGlite 与真 PG 同引擎，SQL 一致；等要验真实 schema 时再起上面的 5432 实例。
切换点只有 `lib/db/index.ts` 一处（换 postgres.js 驱动 + 平台注入的连接串）。
