## 四、视觉基准与风格

- **唯一基准**：`preview/drag-pour.html`（单文件 606 行，双击即开）。改台面质感就照它，另起炉灶必返工。
- 已知缺陷：**瓶口朝向**（`pour.tsx` 118° 倾角/瓶口挂原点）——要修到瓶口真正朝下、液柱垂直落不断线。
- 风格：**柔和**。缓动 `cubic-bezier(.22,1,.36,1)`；阴影大而淡；低饱和；不用纯黑纯白；禁止弹跳/霓虹/科幻风/数据仪表盘。
- 粒子只做**有物理意义**的（气泡、粉末溶解、白雾、液滴、玻璃高光），不做随机漂浮。
- 排版：**不许堆叠说明文字**，用字号层级 + 留白 + 对齐说话；说明收进点击展开。
- 引导：**不遮罩**。拖尾光带（stroke-dashoffset 游走，0.6~1.2s）+ 虚拟手指先演一遍 + 气泡 ≤12 字。学生端和教师端都要。

## 七、已知坑

- **多 agent 抢同一仓库会互相覆盖**（出现过 `index.lock` 和 20+ 个 stash）。同一时间只让一个 agent 改 chem-lab。
- `kanban edit` 不支持 `--workspace`；`kanban comment` 没有 `--body-file`，要用 `"$(cat file)"`。
- 扣子部署丢过东西、数据库不兼容，线上只当保底，源码以本地为准。
- 素材块 `data-demo-id` 用 slug（`demo-design-piece-sodium-carbonate`），不是 pieceId——e2e 写错会静默落空。
