## G. 已知问题（不藏）

1. 纯拖拽/点选投放本身不进 run 时间线，只在下一个动作时把 `inputMode` 写进去
2. 实验页点选时，器皿「可投放高亮」未生效（投放本身成功、文案正确）
3. 键盘那条验收是弱断言（步号没变，靠事件条判过），需单独确认
4. 演示里的结果页显示"最新一条已完成记录"，不一定是演示刚做的那次
5. 视频只有 webm（ffmpeg 缺 mp4 封装器），要 mp4 得另找转码器
