# 视觉与动效调研（跨领域参考 + 可落地方案）

> 调研时间：2026-10-21 · 方法：`web_search` 检索设计媒体与开源规范文档
> 目的：回答「登录页/首页的动效怎么做得更有设计感」——不限于同类教育产品，也从科学品牌站、平面设计、微交互规范里借手法。
> 读者：设计/前端接手者。所有结论都标注了**怎么在本项目落地**（纯 CSS、≤300ms、`prefers-reduced-motion` 可关）。

---

## 一、先定基调：什么算「有设计感的动效」

三家做科学/实验室品牌视觉的站点给出的共同答案（都是公开案例）：

| 参考 | 做法 | 可借的点 |
|---|---|---|
| **Formula Type**（意大利字体厂牌，a-g-o-f.com/formula-type） | 用"化学实验"隐喻做字体动画：**细而精确的线缓慢汇聚成字**，呼应"结构 + 实验" | **线条生长**（stroke-dashoffset）比"元素位移"高级；慢速（3~6s）比快速更显精密 |
| **FutureFields**（生物科技品牌，orrbitt.com） | 用**3D 果蝇飞行**做叙事载体，配色取中世纪印刷 + 现代生物科技 | **一物贯穿全场**做叙事锚点，比"每个区块各自动画"统一 |
| **Oh Lab**（宾州州立高分子膜实验室） | "**几何形态呼应分子骨架 + 流体插画让不可见变可见**" | 器皿/分子用**几何化插画**（不是写实照片、也不是工程线稿），液体用**流体形变**表达 |
| **Radix Labs**（实验室自动化） | 抛弃灰黑，换成**每个产品线一个颜色**；用 Lottie 演示工具在动 | **颜色分工**比"全局一个蓝"更有辨识度 |

**结论 1**：现在登录页的问题是「器皿是静止的工程线稿」——三个参考都在做**"让不可见的东西可见"**：液体流动、分子运动、线条生长。这就是我们要补的动效方向。

## 二、六类可落地的动效手法（按性价比排序）

### 1. 线条生长 / 描边绘制（stroke-dashoffset）
- **参考**：Formula Type 的"细线汇聚成字"、南昌大学官网 banner"线条勾画建筑"、深大官网线条动效
- **怎么做**：`stroke-dasharray: L; stroke-dashoffset: L → 0`，1.2~2.4s，`ease-out`
- **用在哪**：登录页器皿"画出"的过程（首屏一次性，1.5s 内画完 3~4 件）；首页实验清单左侧竖线的生长
- **注意**：只在**首屏加载**触发一次，不要滚动重复触发（会显廉价）

### 2. 液体层形变（liquid morph）
- **参考**：Oh Lab 的"流体插画让不可见变可见"、D&G Velvet 用 shader 做水面反射
- **怎么做**（纯 CSS，不用 WebGL）：液面用 `border-radius: 45% 55% 52% 48%` 配合 `rotate` 做"呼吸"，或 SVG `<path>` 加两个 keyframe 的 `d` 属性切换（现代浏览器支持 `d` 过渡）
- **用在哪**：锥形瓶/烧杯液面（现在只有 `scaleY .98↔1.01`，太微弱）→ 改成**液面边缘缓慢起伏 + 液色微变**
- **时长**：3~5s 循环，`ease-in-out`

### 3. 液滴/气泡的物理感（gravity + easing）
- **参考**：FWA 上的实验性站点普遍用"加速度曲线"而非 linear
- **怎么做**：液滴 `translateY` 用 `cubic-bezier(.45,0,.9,.55)`（模拟重力加速）；气泡用 `cubic-bezier(.2,.8,.3,1)`（模拟浮力减速）
- **用在哪**：滴定管滴液（已有，2.4s/滴，可加密到 1.8s 并让 2 滴错开 0.6s，更有"在滴定"的连续感）
- **加分**：液滴落到液面时，液面做一个 120ms 的 `scaleY 1→1.04→1` 涟漪

### 4. 视差景深（parallax depth）
- **参考**：多数 Awwwards 获奖站的双层视差；国内高校 banner 的"向下滑动背景动效"
- **怎么做**：两层器皿（近景/远景）在滚动或鼠标移动时用**不同速率**位移，幅度极小（≤12px）
- **用在哪**：登录页（鼠标 `pointermove` 让远景层跟 12px、近景层跟 24px，`transition: transform .6s`）；首页校园图（滚动时图位移 20px）
- **注意**：移动端不做鼠标视差，改滚动视差或直接关掉

### 5. 数字/读数滚动（odometer / count-up）
- **参考**：Labster、ilab-x 都用"数字"承载说服力；微交互规范里 100~150ms 数字反馈
- **怎么做**：`transform: translateY` 竖向滚动数字条，或 `requestAnimationFrame` 数到目标值（600~900ms）
- **用在哪**：交卷出分（总分从 0 滚到 82）、教师端雷达图旁的均分、首页统计（10 实验 / 36 学时）
- **约束**：只在**进入视口**时触发一次

### 6. 状态切换的"延续感"（continuity）
- **参考**：interaction-design 规范强调"Orientation: 元素从哪来、到哪去"
- **怎么做**：用**共享元素过渡**的思路——同一个元素在状态间移动而不是消失重画（`view-transition-name` 或手写 FLIP）
- **用在哪**：实验卡片 → 操作台的进入动效（现在只是页面切换）；BOPPPS 前测从"卡片"展开成"答题面板"
- **MVP 做法**：不加 FLIP 库，用"淡出 + 缩放 0.98 → 目标页淡入"的 180ms 交叉即可拿到 70% 的效果

## 三、微交互的时长与状态规范（可直接抄进代码）

综合开源 `interaction-design` / `interaction-patterns` 规范，与项目现有 `app/styles/motion.css` 对齐后定下表：

| 场景 | 时长 | 曲线 | 备注 |
|---|---|---|---|
| hover / 按下反馈 | **100~150ms** | ease-out | 按下 `scale(0.97)`，本项目已统一 |
| 开关、下拉、tab 指示条 | **180~220ms** | `cubic-bezier(.23,1,.32,1)` | 指示条用 `translateX` 不要用 `left` |
| 卡片/弹层入场 | **240~300ms** | 同上 | 从 `translateY(12px) scale(.96)` 起，**绝不从 scale(0)** |
| 页面切换 | **300~400ms** | ease-out | 超过 400ms 会显慢 |
| 编排型动画（首屏叙事） | **600~1500ms** | ease-in-out | 只允许一次 |
| 循环环境动效（液面、气泡） | **3~8s** | ease-in-out | 幅度要小，不能抢注意力 |
| 数字滚动 | **600~900ms** | ease-out | 到位后停，不循环 |

**硬约束（与 `AGENTS.md` 一致）**
- 只动 `transform` / `opacity`（外加 `stroke-dashoffset`、`filter` 少量）——不动 `width/height/top/left`
- 动画库默认不引（GSAP / Lottie / framer-motion 不引；`motion.dev` 仅限弹簧、布局/共享元素、退场、可打断手势），常规动效一律 CSS keyframes + WAAPI
- 所有动效必须在 `prefers-reduced-motion: reduce` 下**完全静止**（不是变快）
- 移动端触控区 ≥44px，动效不改变布局尺寸（避免 CLS）

## 四、给 chem-lab 的落地方案（按页面）

### 登录页（当前最需要补的）
1. **首屏编排 1.5s**：3~4 件主器皿用 `stroke-dashoffset` 依次"画出来"（间隔 120ms），画完液面开始呼吸
2. **滴定连续滴液**：1.8s 一滴、双滴错开 0.6s，落点液面 120ms 涟漪
3. **双层视差**：鼠标移动时近景 24px / 远景 12px 位移（`(hover:hover) and (pointer:fine)` 才启用）
4. **气泡**：锥形瓶 + 烧杯各 2~3 个，8s 上浮，不同负延迟
5. **卡片**：保持 280ms 入场；tab 指示条 160ms 滑动

### 首页
1. **校园图轮播**：保留 5s / 700ms 交叉淡入；在图片底部加一条**2px 进度线**随停留时间生长（5s 走满），比圆点更能表达"还要等多久"
2. **实验清单**：hover 行时左侧 3px 竖线从 0 长到 100%（160ms），箭头右移 2px
3. **统计数字**：进入视口时 10 / 36 从 0 滚上去（700ms）

### 实验操作台
1. **每步操作的三段反馈**已有（实时/结果/下一步）——补"结果条"的数字滚动
2. **事故特效**（爆炸/烟雾/玻璃破碎）已有多档；补"事故后画面 120ms 抖动（`translateX ±3px`）"增强后果感
3. **滴定终点**：颜色突变的瞬间加 **300ms 的颜色过渡 + 一次轻微闪光**（`filter: brightness`）

### 教师端
1. **雷达图**：进入视口时 5 个维度从中心**展开**（600ms，`transform: scale` + 路径动画）
2. **表格行**：hover 时行背景 80ms 过渡即可，不加位移

## 五、不要做的（负面清单）

- ❌ 全屏粒子 / WebGL 大场景（构建体积大、移动端掉帧；three.js 试点已验证 189KB gzip）
- ❌ 每个区块都 fade-and-slide-up 入场（AI 生成页面的最典型特征）
- ❌ 器皿整体"漂浮"（无物理意义，看着像贴纸）
- ❌ 超过 400ms 的常规交互过渡
- ❌ 动效里带音效（课堂投屏场景不合适）
- ❌ 用 `scale(0)` 入场、用 `left/top` 做位移
