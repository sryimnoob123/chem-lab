## 4. 修掉的回归

### 4.1 操作台右上角挂着一个空边框（exp01 第 1 步就有）
- 现象：`.rail`（实时读数栏）这一步既没有读数也没有失败详情，`aside` 里一个子元素都没有，只剩 232×26 的一圈边框挂在台面右上角。
- 根因：`rail` 的空壳由 CSS 提供（边框/内边距/背景），JSX 里内容为 `null` 时容器仍然渲染。
- 改法：`app/exp/[id]/workbench.module.css` 加 `.rail:empty { display: none; }`。
- 复测：`05-s1-exp01-bench.png` 右上角干净了；`?force=1` 十个实验首屏不再出现空框。

### 4.2 页脚写着「按 1~9 选择动作」，但界面上没有 1~9 的动作列表
- 现象：建议动作卡在 2026-10-22 下线后，页脚仍宣传「按 1~9 选择动作」，学生无从知道 1 是哪一步 → 死提示。
- 改法：`app/exp/[id]/workbench.tsx` 页脚改为「H 提示 · R 重做 · Enter 交卷」（三个键都真的可用且屏幕上能找到对应按钮/说明）。
- 复测：`05-s1-exp01-bench.png` 右下角。

### 4.3 教师端口令填了不生效：导出学情 CSV 永远 403
- 现象：`/login?passcode=1` 填 2026 能进后台，但 `GET /api/teacher/export` → `403 {"error":"FORBIDDEN"}`，导出按钮提示「请先在右上角教师解锁」。
- 根因：登录页 `enter()` 只 `router.push`，没有任何请求，`chem_teacher` cookie 从来没种过；后端 `requireTeacher()` 自然是 403。
- 改法：`app/login/page.tsx` —— 教师登录时把填的口令 POST 到 `/api/teacher/unlock`（口令错 → 本页红字「口令不对，再试一次」；留空 → 照旧直接进，演示不弹口令）。
  后端口令校验逻辑一行未动。
- 复测：S6 四项全绿（BOM/40 行/表头/无乱码/界面回执 4 KB）。

### 4.4 教师端在 390×844 下横向溢出 9px、按钮只有 32/36px
- 现象：移动端 `/teacher` 右侧多出 9px 横向滚动；「教师解锁」32px、「导出学情 CSV」36px 低于 AGENTS §3 的 44px。
- 改法：`app/globals.css` 给 `.tch-page-head__side` 加 ≤640px 换行规则；`components/teacher/export-button.tsx` 的 `minHeight` 36→44。
- 复测：S7 `m-teacher.png` 溢出 0px、无矮按钮。

### 4.5 实验台「演示」按钮 30px、底部实验 dock 38px（触屏偏小）
- 改法：`app/exp/[id]/workbench.module.css` ≤640px 下 `.coachButton` / `.dockItem` 撑到 44px。
- 复测：S7 exp01 一行由「演示:30 / :40」变为「无（≥44）」。

## 5. 观察项（本次未改，建议下轮处理）

1. **`.pgdata` 被并发打开后损坏**：dev :3000 与 prod :3001 若共用同一个 `PGLITE_DIR`，PGlite 会 `RuntimeError: Aborted()`，此后 `/api/experiments` 恒 500、首页「读取失败」。
   本次已把坏目录删除、用 `node db/init.mjs && node db/seed-demo.mjs` 重建；验收全程改走真 PG。
   建议：本地双端口时给 dev/prod 各自的 `PGLITE_DIR`（prod 脚本已用 `.pgdata-prod2`），或统一接真 PG。
2. **一进实验就落一条 `in_progress` 运行记录**，离开不回滚：教师端「进行中」会把只点开过页面的学生算进去；跨夜没交卷的 run 交卷后「用时」= 墙钟（本次实测出现 273 分钟）。
   建议：进入时若已有超过 2 小时的 `in_progress` run 就新开一轮，或把「用时」改成首末事件时间差。
3. **新场景底座只覆盖 4 个实验**：exp05/06/07/10 仍是旧器材视图（`lab-apparatus`，0 台 scene 器皿），器皿库/工具托盘/液体系统在这 4 个实验上不存在——不是回归，是覆盖范围问题。
4. **交卷是「末步做完自动跳报告」**，但顶部按钮仍叫「交卷」，学生没机会在末步自己确认。可考虑末步按钮改「完成并交卷」。
5. `/plan` 主题卡的情境句单行省略（`…` 截断），悬停才看全；卡片右侧只剩三个难度短杠，信息偏少。
6. 交互方式三键（拖拽/点选/键盘）与音效键实测 39–40px，桌面无碍，触屏略低于 44px。

## 6. 复现命令

```bash
# 1) 起真库（后台常驻）
/e/TOOLS/pgsql/bin/postgres -D .pgdata-pg -p 55432 &
DATABASE_URL='postgres://postgres@127.0.0.1:55432/chemlab' node db/init.mjs

# 2) 构建 + 起生产口（注意：构建前必须先停掉 :3001，否则 .next/standalone 被占用报 EBUSY）
npm run build
rm -rf .next/standalone/.next/static .next/standalone/public
mkdir -p .next/standalone/.next && cp -r .next/static .next/standalone/.next/static
cp -r public .next/standalone/public && cp .env.production .next/standalone/.env.production
cd .next/standalone && PORT=3001 HOSTNAME=127.0.0.1 \
  DATABASE_URL='postgres://postgres@127.0.0.1:55432/chemlab' node server.js

# 3) 三段回归（需要给 Playwright 指到本机已装的浏览器）
export PLAYWRIGHT_BROWSERS_PATH="$LOCALAPPDATA/ms-playwright"
node scripts/regression-main.mjs           # S1–S4
node scripts/regression-plan-teacher.mjs   # S5–S6
node scripts/regression-mobile.mjs         # S7
```

三段脚本失败即 `exit 1`，会把失败项与 console/pageerror 一起打印出来。
